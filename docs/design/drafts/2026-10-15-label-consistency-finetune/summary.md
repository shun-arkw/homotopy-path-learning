# 要約：ラベルの一貫化と微調整の改善の進め方（n4-d3333，基準線：第1周FT，試験500目的系で ΔJ = −30.33%）

草案（2026-10-15，改訂3）．実装・実験は未着手．本書は `design-code-changes.md` と3つの事前登録草案の読み方をまとめる．

## 1．背景（診断の要点）

記号：目的系の係数ベクトルを $\boldsymbol{x}$，ネットワーク出力を $\boldsymbol{\mu}(\boldsymbol{x})$，方策 $k$ の出力から探索したラベルを $\boldsymbol{a}^*_k$，移動ベクトルを $r_k=\boldsymbol{a}^*_k-\boldsymbol{\mu}_k(\boldsymbol{x})$，ステップ数を $J$，線形パスのそれを $J_{\rm lin}$，削減率を $\Delta J$ とする．「推定」と記した量は，測定値からの近似計算で，直接の測定ではない．

- **ラベルの不整合（n4-d3333，第1周，EXP-0038，実測）：** 同じ目的系に対する3回の探索（第0周の3方策の出力から各100評価）のラベルは，互いにL2で0.95離れ（ノルム2.0），$r_k$ の相互コサインは0.15．移動は目的系の関数として線形には予測できない（決定係数≈0）．
- **教師あり学習は重心に近づく（実測）：** 出力は，ラベル本体（距離0.74）より3ラベルの重心（0.51）と第0周3方策の平均出力（0.32）に近い．検証MSEは25エポックで頭打ち（最良67エポック）になり，訓練損失だけが下がる．**容量が主因ではない可能性が高い**．ラベル間分散（推定：対距離0.95から1座標あたり0.011）が検証MSE 0.018の約6割を占めるとみられる．
- **感度（実測，学習データ先頭100目的系）：** $J$ は等方的な誤差に敏感（$\sigma=0.05$ で+2.1，$0.10$ で+6.9ポイント）だが，ネットワークの誤差は同じノルムの乱数の半分の害（+5.1対+10.4）．第1周の2ラベルの中点は+2.7ポイント．差の内訳（谷内の位置ずれ2〜3ポイント，重心の当てはめ誤差2〜3ポイント）は，これらの整合性からの**推定**．
- **D3（主セッションの結果，n4-d2222，ゼロからの探索のラベル，ほぼ最適な最遠対343組）：** 2点を結ぶ線分上 $\lambda=1/6,\dots,5/6$ での「悪い方の端点からの超過」は平均 0.2 / 4.7 / 7.6 / 4.6 / 0.1%（$J_{\rm lin}$ 比）．対照（端点を対の距離の半分だけ乱数方向に動かす）は平均14.1%，中央値11.9%．**23%の対で中点が乱数の対照より悪い．** 地形は混合で，大半は1本の谷（中点が乱数よりずっと良い），約1/4は分かれた谷．第1周のラベル（方策出力の近傍）は中点+2.7対乱数+10.4で，1本の谷に収まる割合がさらに高いと見込む（未測定）．
- **微調整の頭打ち（記録値）：** 検証 $\Delta J$ が最良になる反復は1100，1300，1250（EXP-0038の3seed，`metadata.json` の `best_iteration`）．seed 0の検証曲線は反復600以降 −29.3〜−30.7% の範囲で揺らぎ，傾向がない（`val_metrics.csv`）．推定量の信号対雑音比は約0.3（推定：コストが行動の線形関数という近似，$A=40$，$P=4$．整数化の雑音は含まない），$\sigma=0.05$ の平滑化によるずれは約2ポイント程度と見込む（推定：ラベルの等方摂動の悪化量から．ずれ自体は未測定）．

## 3．判断の規則

### 3.1．目的系の集合の使い分けと，組み合わせの追試験（EXP-A，EXP-B）

| 集合 | seed | 使い道 |
|---|---|---|
| 検証 | 9600000〜9600199（200） | 微調整で採用する反復の選択 |
| 開発（新設） | 9310000〜9310499（500） | 腕の比較と選択（第1段）．n4-d3333で未使用のseed範囲であることを記録と `outputs/` のrun名で確認した |
| 試験 | 9300000〜9300499（500） | 選んだ腕と基準線の最終比較（第2段，各実験で1回だけ） |
| **第2の試験（予約）** | **9320000〜9320499（500）** | **組み合わせ（A＋B）の確認，1回だけ**．未使用のseed範囲であることを同様に確認した |

第1段：各腕 vs 基準線（開発集合で評価し直す）を「差 $\le-1.0$ ポイントかつ対応ありブートストラップ95%区間が0を含まない」で判定．候補のうち改善が最大の腕を選ぶ（0.5ポイント以内の差なら簡単・安価な腕）．第2段：選んだ腕だけを試験集合で基準線と比べ，同じ規則で採用を決める．候補がなければ試験集合は使わない．EXP-AとEXP-Bは別の実験で，試験集合は合計2回使う（正直に記録する）．

**組み合わせの追試験（事前宣言）：** EXP-AとEXP-Bの両方で腕が採用された場合，「Aの採用腕＋Bの採用腕」の構成はどちらの実験でも試験されていないので，**本実験だけでは採用しない**．別の実験（EXP-00XX，仮）として，その構成を3seedで学習・微調整し，第2の試験集合 9320000〜9320499 で EXP-0038 の第1周の基準線に対して同じ規則（差 $\le-1.0$ ポイント，95%区間が0を含まない）により**1回だけ**比べ，満たせば標準手順にする．満たさなければ，単独で採用した腕のうち試験集合での改善が大きい方だけを標準にする．片方の実験だけで採用があった場合は，この追試験は行わない（その腕が標準）．

### 3.2．D4 の結果と EXP-A／EXP-B の優先順位

記号：$\overline{\Delta J}_{\rm pool}$ はD4で固定32目的系に到達した削減率の**反復1501〜2000の記録点の平均**（最良値は副次的に併記），$\Delta J_{\rm label}\approx-35\%$ は同じ32目的系の教師データ，$\Delta J_{\rm ft}\approx-30\%$ は第1周FT **seed 0**（seedを揃える）．しきい値は2ポイント．しきい値を $\Delta J_{\rm ft}-2$ と $\Delta J_{\rm label}\pm2$ に固定しているため，見込みの値では「中間」の帯は約1ポイントしかなく，判定は実質的に二値である（意図したもの）．

**解釈の非対称性：** 固定プールでは1目的系あたりの追跡回数が $2P\times$反復数（$P=4$ で約16000回）で，ラベル探索（100〜300回）より桁違いに多い．「届かない」は推定量・最適化が律速であることの**強い**証拠，「届く」は推定量が十分であることの**弱い**証拠．追跡回数がラベルの予算と同程度の反復（$P=4$ で反復13と38，$P=16$ で反復4と10）の値も参照する．

| D4-aの結果 | 解釈 | 優先 |
|---|---|---|
| $\overline{\Delta J}_{\rm pool}\ge\Delta J_{\rm ft}-2$ | 推定量または最適化が律速（強い証拠） | 切り分け：D4-bがD4-aより2ポイント以上良ければ推定量の雑音 → **EXP-B**（$P$ 増加を重視）．D4-c（発散時は予備のD4-c′，$\eta=3\times10^{-4}$）が教師データに**届くか上回り**，D4-aが届かなければ歩幅・反復数 → EXP-Bに学習率の腕B5を条件付きで追加（$\eta$ は判定に使った腕と同じ）．D4-cもD4-c′も発散すれば歩幅については判定不能 |
| $\Delta J_{\rm label}-2\le\overline{\Delta J}_{\rm pool}\le\Delta J_{\rm label}+2$ | 追跡回数を十分使えば推定量は足りる（弱い証拠）．汎化が律速の可能性がある | **EXP-Aを先に**．反復13・38の時点でラベルから5ポイント以上離れていれば，EXP-B第1段も行う |
| $\overline{\Delta J}_{\rm pool}<\Delta J_{\rm label}-2$ | 探索（予算100〜300）は最適点に達しておらず，教師データの質が上限 | EXP-Aの利得は教師データの質で頭打ち．**EXP-B（微調整を主役に）と探索予算の増加・EXP-Cを優先** |
| 中間（約1ポイント幅） | 両方 | EXP-AとEXP-Bを並行（スレッドを分ける） |

### 3.3．D3 の結果（混合）の含意

| 観察 | 含意 |
|---|---|
| 大半の対は1本の谷 | A1（重心）とA2（最近傍）の両方に見込み．A1が候補なら最も簡単 |
| 約1/4の対は分かれた谷（ゼロからの探索のラベル，n4-d2222） | A1はその目的系で重心が峰に乗る．第1周のラベルでは割合が小さいと見込むが未測定．A2は谷が分かれていても成り立つ |
| 結果の読み方 | A1だけ候補にならずA2が候補 → 分かれた谷の影響が示唆される．両方候補で差が0.5ポイント以内 → 簡単なA1 |

### 3.4．EXP-B の否定的な結果の読み方

第1段で候補がなければ，「試した範囲（$P\le16$，$\sigma\in[0.02,0.05]$）では $P$ と $\sigma$ は主要な要因ではない」とだけ結論する．残る可能性は，歩幅・反復数（D4-c／D4-c′で切り分ける），効果が1ポイント未満であること，検証200目的系での反復選択の揺らぎ（±0.5ポイント）．「汎化が律速」とは結論しない．

### 3.5．n5 への展開の前の関門（追跡なし）

n4-d3333で採用した腕をn5-d22222・n5-d33333（EXP-0037の出力を入力）に移す**前に**，次を計算する（順伝播と保存済みファイルだけで済む）．

1. 同じ目的系に対する3回の探索の移動ベクトル $r_k$ の相互コサイン $c$（n4-d3333では0.15）．
2. 第1周BCの検証MSEの分解：ラベル間分散 $V$（同じ目的系の3ラベルの重心からの平均二乗距離）と残差（出力と重心の距離）．n4-d3333では $V=0.011$ 対 残差0.007（1座標あたり），$V$ は検証MSE（0.018）の約6割．

| $c$ と $V$ | 判定 |
|---|---|
| $c<0.3$ かつ $V\ge$ 検証MSEの半分 | 同じ構図．n4-d3333の採用腕をそのまま移す |
| $c<0.3$ かつ $V<$ 検証MSEの半分 | 定義していない組み合わせ（ラベルは不整合だが分散が小さい）．**判断保留**．値を報告し，ユーザーと相談して決める |
| $0.3\le c<0.5$ | **判断保留**．自動では移さない．値を報告し，ユーザーと相談して決める |
| $c\ge0.5$ | n5では学習可能な成分が大きい．容量・データ側（教師データの件数，ネットワークの大きさ）を先に疑う |

## 4．それぞれの実験の最小構成

- **EXP-D4**（診断）：1seed（BC seed 0），3腕（D4-a $P=4,\eta=10^{-4}$；D4-b $P=16$；D4-c $\eta=10^{-3}$）＋D4-cが発散した場合のみ予備のD4-c′（$\eta=3\times10^{-4}$），固定32目的系，主統計量は反復1501〜2000の平均，参照値はseed 0どうし，統計検定なし．
- **EXP-A**：2腕（A1 重心ラベル，A2 最近傍ラベル損失），各3seed，第1周と同じ微調整．開発集合で選び，試験集合で1回だけ確認．組み合わせは単独では採用しない．
- **EXP-B**：4腕（B1 $K=8,P=16$；B3 $\sigma$ 0.05→0.02；B2 $K=32,P=16$；B4 $\sigma=0.025,P=16$）＋条件付きB5（学習率）．B1・B3・B5はローカル，B2・B4は外部サーバ．追跡数が同じ腕を優先採用．副次的に B4−B2（$\sigma$ の分離），B2−基準線（$P$ の分離），B1−B2（$K$ の分離）を開発集合で記述的に報告．組み合わせは単独では採用しない．
- **組み合わせの追試験**（条件付き）：A＋Bの構成，3seed，第2の試験集合で1回だけ基準線と比較．

1. **開発集合 9310000〜9310499 と第2の試験集合 9320000〜9320499** の採用（いずれも未使用を確認済み）と，試験集合の使用回数（本来の試験集合2回，第2の試験集合1回）の扱い．
2. **D4のしきい値（2ポイント）**，主統計量（反復1501〜2000の平均），補助規則（反復13・38で5ポイント以上離れていればEXP-B第1段も行う），中間の帯が約1ポイントで実質二値であること．

4. **A2の非目標**（目的系ごとに $K$ が異なるデータには対応しない）と，候補の切り替わり率の記録列（`min` のときだけ）．

7. **EXP-Cの近接型探索**と**温間開始**は付録に設計だけ置き，EXP-A・Bの結果が出るまで実装しない方針．

## 6．不確実な点

- 診断はn4-d3333の第1周，学習データの先頭100〜500目的系に基づく．差の内訳は推定．
- D3はn4-d2222のゼロからの探索のラベルでの結果で，第1周のラベルでの「分かれた谷」の割合は未測定．
- A1（重心）は，ラベルの $J$ を2.7ポイント分犠牲にして分散を減らす．当てはめ誤差の減少がそれを上回るかは分からない．
- A2（最近傍）は，学習の初期に選ばれる候補が偶然で決まり，固定化する可能性がある（切り替わり率で観察．判断基準には入れない）．
- EXP-A・Bの各腕は，検証200目的系の揺らぎ（±0.5ポイント）に対して最良反復の選択が不安定．検証の目的系数を増やすのは別の変更になるので，本実験では変えない．開発集合500目的系での腕の選択にも同程度の揺らぎがあり，第2段で再現しない可能性がある．
- 組み合わせ（A＋B）の効果は加法的とは限らない（両方がラベル分散の同じ部分を減らす場合は重なる）．追試験で確かめる．
