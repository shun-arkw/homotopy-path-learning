# ADR-0003：最初の実験ではPham型サポートを固定する

## 状態

Proposed．

## 背景

多項式系ごとにサポートを変更すると，係数ベクトル，観測，行動，Julia評価器の次元が変化する．最初の多変数実装では，追跡器と学習環境の正しさを優先する必要がある．

## 決定

変数数，方程式数，次数，候補指数集合を実験開始時に固定し，各サンプルでは自由係数だけを変更する．

## 理由

- 観測次元と行動次元が一定になる．
- Julia側の多項式構造と作業バッファを再利用できる．
- サポート変化の影響と係数変化の影響を分離できる．
- 実験結果を解釈しやすい．

## 影響

- 学習済み方策は，原則として同じサポートをもつ問題にのみ適用できる．
- 複数サポートへの一般化は後続課題となる．
