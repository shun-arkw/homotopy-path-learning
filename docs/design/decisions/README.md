# Architecture Decision Records

本ディレクトリには，実装へ大きな影響を与える設計判断をADRとして記録する．

## 状態

- `Proposed`：採用候補であり，実装前に確認が必要である．
- `Accepted`：採用済みである．
- `Superseded`：後続ADRにより置き換えられた．
- `Rejected`：採用しないことを決定した．
