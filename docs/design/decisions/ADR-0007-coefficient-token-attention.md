# ADR-0007：係数トークンによる，置換に同変なattentionモデル

## 状態

Accepted（第1段階のみ）．

EXP-0017（n4-d2222，$d_b=2$）とEXP-0018（n4-d3333の予備調査）の結果を受けて，第1段階（1次の項と定数項のサポートに限った行列版）の設計・実装に進むことを2026-10-13に決定した．実装設計は`docs/design/implementation/attention_policy.md`にある．第2段階（一般のサポート）と系の大きさをまたぐ学習は，第1段階の結果を見て改めて判断する．

## 背景

- 現在の標準パイプラインは次の3段階である．
  1. oracleによる教師データの生成
  2. 対称性による拡張つき教師あり学習
  3. 追跡コストによる微調整
- 方策ネットワークは単純なMLPである．自由係数の実部と虚部をそのまま並べたベクトルを入力とし，全結合3層（256ユニット，tanh）を通して，中間制御点の潜在行動を出力する（EXP-0012）．
- このパイプラインは，n3-d222（$\Delta J=-20.4\%$），n2-d33（$-31.1\%$），n3-d333（$-19.2\%$）で機能した．一方，4変数のn4-d2222では到達率0.45にとどまり，律速は教師あり学習の段階だった（EXP-0014）．
- Pham型系の対称性（変数と方程式の同時置換，1の冪根倍，複素共役）は，追跡コストの意味でほぼ厳密に成り立つ（EXP-0011，`docs/design/mathematics/symmetry.md`）．
  - 現在は，教師データをランダムな対称変換で拡張して，MLPにこの対称性を「見せて」覚えさせている．
  - 拡張の効果は群が大きいほど大きい（n3-d222で+0.15，n3-d333で+0.17，n4-d2222で+0.18）．
  - 群の大きさは$n!\prod_j d_j\cdot 2$で急速に大きくなる（n4-d3333で3888）．大きな群では，拡張のサンプリングで群全体を覆うことが難しくなる．
- MLPの入力次元は系ごとに固定である．そのため，系（変数の数，次数，サポート）が変わるたびに，別のモデルを一から学習する必要がある．

## 提案

目的系を**係数トークンの集合**として表し，**関係つきのattention**で処理するモデルを導入する．置換の対称性を構造として満たし，任意のサポートと系の大きさに対応させる．

### トークン

| 種類 | 1トークンが表すもの | 特徴量 |
|---|---|---|
| 係数トークン | 方程式$i$の単項式$x^\alpha$の自由係数$a$ | 係数の値（実部・虚部），指数$\alpha$の情報（自分の方程式の変数の指数，次数など） |
| 変数トークン | 変数$x_j$ | 次数$d_j$ |
| 方程式トークン | 方程式$i$ | 次数$d_i$．開始系$x_i^{d_i}-1$により，方程式$i$と変数$i$は対応する |

- 変数の番号そのもの（$x_1$か$x_2$か）は特徴量に入れない．変数との関係は，「どの変数トークンと，どの指数で結びつくか」というつながりだけで表す．
- これにより，変数と方程式を同時に並べ替えると，出力も同じように並べ替わる（置換に同変）．
- 先頭係数（固定値1）はトークンにしない．あるいは，方程式トークンの特徴として扱う．

### モデルの形：Transformerエンコーダー

モデルは，標準的なTransformerのエンコーダーとする．attentionの部分だけを取り出したモデルではない．

```text
入力：トークンの集合（係数トークン，変数トークン，方程式トークン）
  ↓ 埋め込み（係数の値・次数などの特徴 → d次元ベクトル）
[ブロック] × L層
   ├ 多頭attention ＋ 残差接続 ＋ LayerNorm
   └ トークンごとのMLP（feed-forward）＋ 残差接続 ＋ LayerNorm
  ↓
出力：係数トークンごとに，中間制御点での摂動
```

言語モデルのTransformerとの違いは次のとおり．

| 点 | 言語モデル | 本提案 |
|---|---|---|
| 位置埋め込み | あり | なし．トークンの順番（変数・方程式の番号）は問題の本質ではないため．これにより置換に同変になる |
| attentionの範囲 | 全トークン（＋因果マスク） | 全トークン間に加え，係数トークンと方程式・変数のつながりを，attentionのバイアスや辺の特徴として与える（グラフTransformerに近い） |
| 生成 | 1トークンずつ逐次生成 | なし．1回の順伝播で全係数の摂動を同時に出す |
| 規模 | 巨大 | 小さい．例えば4層，128次元，4ヘッド程度で，現在のMLP（約15万パラメータ）と同程度 |

- トークンごとのMLPは，各トークンの表現を非線形に変換する役割を持つ．
- 残差接続とLayerNormは，層を重ねても学習を安定させる．EXP-0012では，MLPを深くするだけで性能が上がった．

### attention

- 係数トークンは，自分の方程式トークンと，単項式に現れる変数トークン（指数を辺の特徴とする）に結びつく．
- これらのつながりにもとづく関係つきのattentionと，全トークン間のattention（位置埋め込みなし）を組み合わせる．
- 係数の値は連続値の複素数である．実部と虚部を，値に比例する形で埋め込む（xValのように，値×学習済みベクトル）か，線形層で埋め込む．
- 1次の項と定数項だけのサポートでは，係数は$n\times n$の行列$A$と定数ベクトルに整理できる．置換は$A\to PAP^\top$となるので，行方向・列方向のattention（axial attention）でも実現できる．これは本提案の特殊な場合として，最初の検証に使える．

### 出力

- 係数トークンごとに，中間制御点（$d_b-1$個）でのその係数の摂動（実部・虚部）を出力する．すなわち，係数空間での摂動$\delta$を直接出力する．
- 全次元の行動空間では，潜在行動は$z=U^\top\delta$（$U$は正方の直交行列）で得られる．既存の環境・追跡・評価はそのまま使える．
- 先頭係数は摂動しない（ADR-0004）．ゼロ出力は線形パスに一致する．

### 置換以外の対称性

- 1の冪根倍では，各係数に指数に応じた位相$\prod_j\omega_j^{\alpha_j}$がかかる．複素共役では，全係数が共役になる．
- これらはattentionの並べ替えの性質では満たせない．当面は，現在の教師データの拡張で補う．
- 位相を扱う複素数の層などで構造的に満たす方法は，将来の研究課題とする．

## 関連する表現：CALTの系列表現との違い

CALT（Keraら，arXiv:2506.08600，<https://github.com/HiroshiKERA/calt>）は，多項式を系列としてトーカナイズし，Transformerで記号計算を学習するライブラリである．

- **CALTの表現：**
  - 単項式は，係数トークン1つと，変数ごとの指数トークンの並び（例：$x_1^2x_2^3\to$ (C1, E2, E3)）．
  - 多項式は単項式を「+」「−」でつなぎ，複数の多項式は「|」で区切る．
  - 変数は，指数トークンの位置で区別する．
  - 係数は離散トークン（整数・有限体）である．
  - モデルは，入力系列から出力の記号式を逐次生成する．

| 観点 | CALT | 本提案 |
|---|---|---|
| 目的 | 記号計算の答えを式として生成する | 係数の摂動（連続値）を1回の順伝播で回帰する |
| 入力の形 | 系列（項の並べ方と変数の位置に意味がある） | 集合・グラフ（並べ方に意味はなく，関係だけを使う） |
| 変数の扱い | 指数トークンの位置で区別する | 変数トークンとのつながりで区別する |
| 置換の対称性 | 構造では満たさない | 構造で満たす |
| 係数 | 離散トークン | 連続値の複素数の埋め込み |

- **取り入れる点：**
  - 単項式を「係数＋指数ベクトル」で表す考え方
  - 連続値の係数の埋め込み（CALTの論文が触れているxVal）
- **比較の基準として使う：** CALT型の系列表現（位置埋め込みあり）にTransformerエンコーダーを組み合わせたモデルは，実装が単純である．これを比較対象に加えると，効果を次の2つに分けて測れる．
  - **attention構造そのものの効果**：MLPとCALT型の系列表現の比較
  - **置換の対称性を構造で満たす効果**：CALT型の系列表現と本提案の関係つきトークンの比較

## 期待される効果

1. **データ効率の向上**：置換の対称性を構造で満たすので，同じ教師データからより多くを学べる．群の大きいn4系で特に効くと期待する．
2. **任意のサポートへの対応**：1次の項だけの系も，2次の項を含む系（n2-d33-denseなど）も，同じモデルで扱える．
3. **系の大きさをまたぐ学習**：重みがトークン数に依存しない．n3とn4，d222とd333を1つのモデルで扱える可能性がある．小さい系で学習し，大きい系で微調整するといった，規模拡大の手段になり得る．
4. **推論コスト**：トークン数は係数の数程度（n4-d2222で20個）であり，追跡に比べて計算は無視できる．推論時の制約（順伝播1回と追跡1回）は変わらない．

## 懸念とリスク

- 実装量が大きい．トークンとつながりの構成，関係つきattention，係数空間での入出力，教師あり学習・微調整・checkpointへの組み込みが必要である（行列版で半日〜1日，一般版はさらに大きい）．
- 小規模な系では，MLP＋拡張と差が出ない可能性がある．効果は，律速となっているn4系で確かめる必要がある．
- 系の大きさをまたぐ汎化は，期待であって保証はない．係数の分布や改善の仕方が系ごとに大きく異なれば，効果は限定的になる．
- 1の冪根倍と共役は引き続き拡張に頼るため，対称性の扱いは部分的な改善にとどまる．

## 検証の進め方（採用する場合）

1. **行列版（1次の項と定数項のサポート）**をn4-d2222で実装する．EXP-0014・EXP-0017と同じ教師データで，次の3つを比べる．比較は追跡コスト（$\Delta J$，到達率）で行う．
   - MLP＋拡張（現在の標準）
   - CALT型の系列表現＋Transformerエンコーダー＋拡張
   - 関係つきトークン＋Transformerエンコーダー＋拡張
2. 効果があれば，**一般版（係数トークン）**に拡張し，n2-d33-denseなど2次の項を含む系で確かめる．
3. **系の大きさをまたぐ学習**を試す．例えば，n3系で学習したモデルをn4系で微調整する．

## 判断の時期

EXP-0017とEXP-0018の結果が出た後に判断する．その時点で，n4系の律速を緩める他の手と比べて優先度を決める．他の手には，$d_b$の選択と，教師データ・学習量の増加がある．
