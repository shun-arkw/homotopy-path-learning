# ADR-0001：同一リポジトリを多変数中心へ再編する

## 状態

Accepted.

## 背景

現在のリポジトリは一変数実験から始まったが，研究の主対象は多変数多項式系である．別リポジトリを作成する案もあるが，研究テーマは一貫して係数空間上のホモトピーパス最適化であり，リポジトリ名も一変数へ限定されていない．

## 決定

新しいリポジトリは作成せず，現在の`homotopy-path-learning`を多変数中心の構成へ再編する．一変数実験は既存ブランチまたはタグとして保存する．

## 理由

- 一変数と多変数でPPO，ベジェ制御点，Julia連携などを共有できる．
- 研究の履歴を1か所で追跡できる．
- リポジトリ名が多変数研究にも適用できる．
- 重複するCI，Docker，依存関係管理を避けられる．

## 影響

- 既存コードを壊さず，新しい`src/`と`julia/`へ段階的に移植する必要がある．
- 一変数専用のファイルを新しいコア設計へ混在させない．
