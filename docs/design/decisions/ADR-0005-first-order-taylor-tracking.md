# ADR-0005：初期追跡実装では1階Taylorデータを使用する

## 状態

Accepted.

## 背景

多変数ベジェホモトピーでは，係数パスの高階Taylor係数を，
ベジェ制御点の前進差分から計算できる．

Phase 3では高階Taylor係数の評価を実装し，単体テストによって
その正しさを確認した．一方，HomotopyContinuation.jl 2.6.4では，
数学的には高階微分が0となる線形ベジェパスにおいて，
浮動小数点の丸め誤差により高階前進差分が微小な非零値となり，
予測子が不安定になる場合が確認された．

## 決定

初期の逐次パス追跡では，HomotopyContinuation.jlへ渡す
ホモトピーの最大Taylor階数を1に制限する．

高階Taylor係数を計算する実装および単体テストは削除せず，
将来の検証のために維持する．

## 理由

- 線形ベジェパスにおける丸め誤差の影響を回避できる．
- 初期実装では，追跡速度よりも数値的な安定性と正しさを優先する．
- 高階Taylor係数の実装を保持することで，将来の高階予測子の検証に利用できる．

## 影響

- 初期実装では，高階予測子による追跡効率の改善を利用しない．
- 高階Taylor係数の計算機能と，実際の追跡器で使用する階数が異なる．
- 将来，高階Taylorデータを追跡に使用する場合は，
  微小な高階差分を0へ丸める基準や，
  HomotopyContinuation.jlの予測子設定を再検証する必要がある．

## 再検討条件

以下のいずれかを満たした場合，本決定を再検討する．

- 高階差分の安定した丸め処理を導入できた場合．
- HomotopyContinuation.jlの予測子設定によって問題を回避できた場合．
- 高階Taylorデータを使用した追跡について，
  線形パスと非線形ベジェパスの双方で十分な回帰テストを追加できた場合．
