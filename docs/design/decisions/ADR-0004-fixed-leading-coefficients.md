# ADR-0004：先頭係数をパス全体で1に固定する

## 状態

Proposed．

## 背景

Pham型サポートの構造を明示的に保ち，開始系$G_i=x_i^{d_i}-1$から目的系へ移動する必要がある．先頭係数を変化させると，モニックな部分族から外れ，係数表現と$\gamma$-trickの扱いが複雑になる．

## 決定

すべての制御点において，各方程式の先頭単項式$x_i^{d_i}$の係数を$1$に固定する．潜在摂動は先頭係数成分を変更しない．初期実装では$\gamma$-trickを使用しない．

## 理由

- パス全体で先頭単項式が固定される．
- 固定サポートと係数ベクトルの意味が明確になる．
- 実装とテストを単純化できる．
- 多変数化の初期検証に集中できる．

## 影響

- 既存一変数実装の$\gamma$による開始多項式全体のスケーリングは，そのまま移植できない．
- $\gamma$-trickを導入する場合は，先頭係数も係数パスへ含める別設計が必要である．
