# ADR-0008：目的系を部分空間の族に限る設定を加える

## 状態

Accepted（2026-11-06）．設計の経緯と実験計画は`docs/design/drafts/2026-11-05-subspace-family/plan.md`にある．

## 背景

- 自由係数の数$D_{\mathrm{free}}=n(n+1)$（今の系の種類）は，変数の数$n$の2乗で増える．
- EXP-0059では，目的系は一般のまま行動をランダムな部分空間に絞っても，探索は速くならなかった．一方，微調整の後のネットワークは目的系ごとの探索を大きく上回った．大きい系での難しさは，学習の側にある可能性がある．
- そこで，目的系そのものを低次元の部分空間（族）に限ったとき，学習が易しくなるかを調べたい．そのために，目的系の生成と行動の基底を，今の一様分布・ランダムな基底とは別に選べるようにする．

## 決定

1. 目的系の生成に`gaussian_subspace`を加える．
   - 自由係数を$\boldsymbol{c}_{F,\mathrm{free}}=W\boldsymbol{u}$とする．$W\in\mathbb{C}^{D_{\mathrm{free}}\times k}$は列が正規直交な行列で，`family_seed`から決定的に作る（複素ガウス行列の縮約QR分解のQ．列$l$に$R_{ll}$を正の実数にする位相を掛ける）．
   - $\boldsymbol{u}\sim\mathcal{CN}(0,s^2I_k)$，$s^2=(D_{\mathrm{free}}/k)\cdot 2b^2/3$（$b$は`sampler.bound`）．係数と$W$について平均した$E|c_j|^2$は一様分布と同じ$2b^2/3$になる．係数ごとの分散は，$W$の行のノルムの2乗に比例する．
   - $k=D_{\mathrm{free}}$では，自由係数は独立な$\mathcal{CN}(0,2b^2/3)$に従う（一般（ガウス））．
   - 先頭係数は$1+0\mathrm{j}$のまま．開始系$x_i^{d_i}-1$は変えない．
2. 行動の基底の選び方`path.basis`を加える．
   - `random`（既定）：今と同じく`basis_seed`から作るランダムな基底．
   - `family`：$W$の実数化$U_W=\begin{pmatrix}\mathrm{Re}W&-\mathrm{Im}W\\\mathrm{Im}W&\mathrm{Re}W\end{pmatrix}$．`latent_dim`は$2k$に固定．
3. 対称性による拡張は，目的系の分布が群の作用で変わらず（一様分布，または$k=D_{\mathrm{free}}$のガウス分布），基底が正方のときだけ許す．
   - $k<D_{\mathrm{free}}$のランダムな部分空間は，群の作用で閉じない．
   - 一様分布は，各3次の系では1の3乗根倍（120°の回転）で変わる分布ではない（回転後に正方形の外へ出る係数が約15.5%）．しかし，これまでのすべての実験で拡張に使ってきたので，従来どおり許す．
4. checkpointに目的系の族の情報（生成器の種類，$k$，`family_seed`，`path.basis`）と，基底のSHA-256を保存し，評価や微調整で照合する．
   - 形式の版は上げない．
   - 族の情報がない古いcheckpointは，一様分布・`random`の基底とみなす．
5. attentionと系列Transformerの方策は，列が正規直交な非正方の基底を受け付ける．このとき$u_k=U^\top\delta_k$は，係数空間の摂動の射影になる．

## 理由

- 既存の`CoefficientSampler`のプロトコルと，基底による摂動の仕組みの上に，最小の変更で載せられる．
- $k=D_{\mathrm{free}}$のガウス分布を，同じ生成器で$k$だけを変えた比較の基準にできる．
- ランダムな$W$は，特定の構造を仮定しない最初の選び方である．群全体で閉じた族は，$k$が$n$に比例する大きさでは「対角＋1つの数による結合」に縮退する（2回目の敵対的検証）．そのため，まずランダムな$W$で調べる．

## 影響

- AGENTS.mdの不変条件（Pham型の先頭単項式，先頭係数1，開始系，行動0で線形パス，端点の固定）は保たれる．
- 既存の設定ファイルとcheckpointの動作は変わらない（新しい項目はすべて省略可能で，既定値は今の動作）．
- 族で学習したネットワークは，その族（同じ$W$）の目的系にしか使えない．結果は，一般の目的系には転用できない．
