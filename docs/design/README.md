# Design Documents

本ディレクトリは，多変数多項式系に対するホモトピーパス最適化の設計仕様を管理する．

## 構成

- `mathematics/`：多項式系，係数パス，追跡コストなどの数学的定義である．
- `architecture/`：Python，Julia，Gymnasium，PPOの責務分担とデータフローである．
- `implementation/`：クラス，関数，配列形式，実装手順などの具体的な仕様である．
- `decisions/`：採用候補または採用済みの重要な設計判断をADR形式で記録する．

## 設計上の中心方針

1．研究の主対象は$n$変数$n$本の多変数多項式系である．
2．最初の対象族として，固定したPham型サポートをもつモニックな多項式系を扱う．
3．係数空間上のベジェ曲線をPPOで最適化する．
4．学習，問題生成，報酬計算はPythonで実装する．
5．多項式評価，ヤコビ行列評価，全解パス追跡はJuliaとHomotopyContinuation.jlで実装する．
6．一変数実験は予備実験として保存し，多変数実装のコア設計には混在させない．
