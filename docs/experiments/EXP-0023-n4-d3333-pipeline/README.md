## 2．目的

- 変数4つ，次数3の系（n4-d3333，81パス）で，標準パイプライン（oracleの教師データ → 拡張つき教師あり学習 → 微調整）を初めて実行する．
- MLPとattention方策の両方で行い，比べる．EXP-0020の改善がより大きい系でも得られるかを調べる．

## 3．多項式系

**n4-d3333**（$n=4$，次数$(3,3,3,3)$，$N_{\mathrm{path}}=81$，観測次元40）

- 開始系：$g_i=x_i^3-1$（$i=1,\dots,4$）
- 目的系：$f_i=x_i^3+a_{i,1}x_1+a_{i,2}x_2+a_{i,3}x_3+a_{i,4}x_4+a_{i,5}$（$i=1,\dots,4$）

係数$a_{i,j}$は問題ごとに，実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．ベジェ次数は$d_b=2$（行動40次元）．EXP-0018で，予算1000のoracleの改善余地が$d_b=2$と$d_b=3$で同等（$-22.90\%$と$-22.82\%$）だったため，行動の次元が小さい$d_b=2$を選ぶ．対称群の大きさは3888．

## 4．方法（事前登録）

### 4.1．教師データと比較用oracle

- 教師データ：20分割×500件（計1万件）．`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0`．評価seedは9000000+500k（$k=0,\dots,19$）．
- 比較用oracle（評価100問題，評価seed 40000〜40099）：EXP-0018の$d_b=2$のoracle（予算3000，4分割）を連結して使う．

### 4.2．教師あり学習

| 方策 | 構成 | エポック | 学習率 | seed |
|---|---|---:|---:|---|
| MLP | 全結合3層，256ユニット | 5000 | $10^{-3}$ | 0〜2 |
| attention | $d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256 | 300 | $10^{-3}$ | 0〜2 |

いずれも対称性による拡張つき，バッチ256，検証10%．

### 4.3．微調整

両方策とも，2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題（検証seed 9600000），訓練seed 9700000．

### 4.4．試験問題

- これまで使っていない評価seed 9300000〜9300499の500問題．
- 試験問題でoracle（全次元，予算$B=1000$）を求め，到達率の分母にする．
- 4つの方策（MLPとattentionの，教師あり学習と微調整．各3seed）を試験問題で評価し，`compare_runs.py`で比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整後の$\Delta J$の差（attention−MLP，試験500問題）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → n4-d3333でもattention方策は有効．
- **副基準：** 教師あり学習の段階の到達率の差（attention−MLP，試験500問題）が+0.05以上．
- 参考：教師データ1万件の平均$\Delta J$が，EXP-0018のoracleの予算500付近（約$-22.5\%$）と整合することを確かめる．
