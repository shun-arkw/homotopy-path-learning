## 2．目的

- EXP-0057では，`β_ω_p`を0.5より下げても1歩の幅は大きくならず，棄却が増えただけだった．取りこぼしは，6変数・各3次の線形パスの1つの目的系だけで，学習したパスとの差は調べられなかった．
- 本実験では，Newton法の収束の判定を緩めて（`a`を大きくして）追跡を大胆にし，線形パスと学習したパスの取りこぼしを数える．EXP-0057と同じ2つを調べる．
  1. 同じ追跡の設定で，学習したパスは線形パスより取りこぼしにくいか．
  2. それぞれが取りこぼさない範囲でステップ数が最も少ない設定を使うと，学習したパスの削減率はどう変わるか．
- EXP-0057では，2つ目の比較を「取りこぼしのない最も小さい`β_ω_p`」どうしで行ったため，ステップ数が最も少ない設定どうしの比較にならなかった．本実験では，取りこぼしのない設定の中でステップ数が最も少ないものどうしで比べる．

## 5．判断基準（実行前に固定）

**取りこぼしの判定（系の種類ごと）：** EXP-0057の5節と同じ（ある設定で差（線形 − 学習）が正で95%区間が0を含まず，負で0を含まない設定がなければ「学習したパスのほうが取りこぼしにくい」．逆は「取りこぼしやすい」．どちらもなければ「差なし」．両方あれば「混在」）．12の設定で判定するので，偶然に区間が0を含まなくなる設定が出やすいことを，結果の読み方の限界として書く．

**取りこぼしをそろえたステップ数の比較：**

- 取りこぼしのない最も少ない設定：線形パスと学習したパスのそれぞれで，開発集合で追跡の失敗も取りこぼしも0の設定（学習したパスは3つのネットワークのすべてで）の中で，平均ステップ数$\bar J$が最も小さいもの．なければ「なし」．
- 取りこぼしをそろえた削減率：$(1-\bar J_\text{学習}(\text{学習したパスの設定})/\bar J_\text{線形}(\text{線形パスの設定}))\times100$．
- これと，新しい追跡の設定（W0.8-A0.125）での削減率の差を求め，EXP-0055と同じ規則で判定する：+1.0ポイント以上で95%区間が0を含まなければ「良い」（取りこぼしをそろえると，学習したパスの利点が増える），−1.0ポイント以下で0を含まなければ「悪い」，それ以外は「差なし」．
- 開発集合で設定を選ぶので，開発集合での差は大きめに出る．テストデータの値（開発集合で選んだ設定を使う）を主な結果とし，テストデータで選んだ設定に取りこぼしがあればそれを明記する．

**全体の読み方（記述的）：**

- 「学習したパスのほうが取りこぼしにくい」系の種類があり，「取りこぼしやすい」系の種類がなく，テストデータでも同じ向きなら，「追跡を大胆にしても，学習したパスは線形パスより解を取りこぼしにくい」と書く．
- 取りこぼしをそろえた比較が，テストデータで「良い」の系の種類が多ければ，「取りこぼしをそろえると，学習したパスの利点は同じ追跡の設定での削減率より大きい」と書く．
- 判断は開発集合だけで行う．テストデータの結果を見て判断を変えることはしない．テストデータでも同じ規則で判定し，記録する．

### 7.3．考察

- **大きい系では，追跡を大胆にすると，線形パスが先に取りこぼし始める．** n5-d33333とn6-d333333では，開発集合とテストデータの両方で，学習したパスの方が取りこぼしの割合が低い設定があり，逆の設定はなかった．n6-d333333のW0.8-A0.6では，線形パスは目的系の37%で解を取りこぼし，学習したパスは20%だった．小さい系の種類では，最も大胆な設定でも取りこぼしがほとんど起きず，差は調べられなかった．
- **同じステップ数で比べると，学習したパスの方が取りこぼしにくい．** 7.2節の最後の表で，n6-d333333の学習したパスはW0.8-A0.3で$\bar J$=8.63，取りこぼし0.33%である．線形パスで取りこぼしが同じ程度（0.20〜0.80%）になるのは$\bar J$=11.13〜12.67で，ステップ数は約1.3〜1.5倍になる．線形パスで$\bar J$を8.63付近まで下げると（W0.3-A0.6で8.39），取りこぼしは46%になる．n5-d33333でも，学習したパスはW0.3-A0.3で$\bar J$=7.49，0.13%，線形パスはW0.8-A0.3で10.33，0.20%である．ステップ数と取りこぼしの兼ね合いでは，学習したパスが線形パスより一様に良い．
- **それでも，取りこぼしをそろえた削減率が下がったのは，線形パスも`a`を大きくすると速くなるからである．** `a`を大きくすると，どちらのパスもステップ数が減り，線形パスの方が多く減った（例：n2-d33で，W0.8-A0.125からW0.3-A0.5へ，線形パスは9.45から5.87，学習したパスは5.83から4.51）．小さい系の種類では，どちらも最も大胆な設定まで取りこぼさないので，比べたのは「両方とも大胆な設定」での削減率になる．新しい追跡の設定での削減率の一部は，線形パスにとって慎重すぎる追跡の設定から来ていたことになる．ただし，取りこぼしをそろえても，学習したパスのステップ数は9つの系の種類のすべてで線形パスより少なかった（削減率2.9〜27.5%）．
- **「悪い」の大きさは，取りこぼしの有無の定め方に強く左右される．** n5-d22222では，開発集合で学習したパスに目的系1個の取りこぼしが小さい`a`から出たため，学習したパスの設定がW0.8-A0.2に限られ，削減率は2.86%になった．テストデータでは，学習したパスはW0.3-A0.6でも取りこぼさなかった．逆に，開発集合で選んだ設定でも，テストデータで取りこぼしが出た系の種類が3つあった．500個で「取りこぼし0」を求める定め方は，境目の設定を偶然で選ぶ．
- **限界**：
  - ネットワークは新しい追跡の設定（`a`=0.125）で微調整したもので，大胆な設定に合わせて学習し直していない．EXP-0055とEXP-0056では，新しい追跡の設定に合わせて微調整し直すと削減率が戻った．大胆な設定で微調整し直せば，取りこぼしをそろえた削減率も上がる可能性がある．ただし，微調整の目的はステップ数だけで，取りこぼしを含まない．大胆な設定で微調整すると，乗り移りやすいパスを学ぶおそれがある．
  - 12の設定で判定したので，偶然に区間が0を含まない設定が出やすい．n5-d33333とn6-d333333では，開発集合とテストデータの両方で，いくつもの設定で区間が0を含まなかったので，偶然とは考えにくい．

### 7.4．結論と次の実験

- 5節の規則による判断（開発集合）：
  - 取りこぼし：n5-d33333とn6-d333333で「学習したパスのほうが取りこぼしにくい」，ほかの8つは「差なし」．テストデータでも同じ向きだった（n6-d222222の判定は丸めによるもので，実質は差なし．7.2節の注）．5節に従い，「追跡を大胆にしても，学習したパスは線形パスより解を取りこぼしにくい」と書く．ただし，差が見えたのはパスの数が243と729の2つの系の種類だけである．
  - 取りこぼしをそろえたステップ数：比べられた9つの系の種類のすべてで「悪い」（テストデータでも同じ）．「取りこぼしをそろえると，学習したパスの利点は同じ追跡の設定での削減率より大きい」とは言えない．
- まとめ：
  - 同じステップ数で比べると，大きい系では学習したパスの方が取りこぼしにくい．ステップ数と取りこぼしの兼ね合いでは，学習したパスが良い．
  - 一方で，線形パスも`a`を大きくすると安全なまま速くなる．新しい追跡の設定での削減率は，線形パスとの差をいくらか大きく見せている．
- 次の実験の候補（ユーザーと決める．本実験では行わない）：
  - (a) 大胆な追跡の設定（例：`a`=0.3）で微調整し直し，取りこぼしとステップ数を，同じ設定の線形パスと比べる．
  - (b) 取りこぼしをそろえた比較を，「取りこぼし0」ではなく，取りこぼしの割合の上限（例：1%）で定めて，ステップ数と取りこぼしの兼ね合いの曲線どうしで比べる．本実験の出力から計算できるが，事前登録していないので，行うなら別の実験として登録する．
