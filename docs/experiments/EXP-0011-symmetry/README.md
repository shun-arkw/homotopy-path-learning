## 2．目的

EXP-0010では，oracleの行動を教師とする回帰でも，係数から最適行動への写像の到達率はn3-d222で約0.2，n2-d33で約0.47にとどまった．この写像が学びにくい理由として，学習器が問題族の対称性を知らないことを疑う．Pham型系族には，変数と方程式の同時置換，各変数への1の冪根のスケーリング，係数の複素共役という有限群が作用する（位数はn3-d222が96，n2-d33とn2-d33-denseが36）．対称な問題では最適行動も対応して変換されるはずなので，この群で訓練データを拡張すると，実質的なデータ量が増え，写像が学びやすくなると予想する．数学は`docs/design/mathematics/symmetry.md`に定義した．

## 3．方法・設定

### 3.1．対称性の検証

`symmetry_check.py --random-actions 2 --action-seed 0`．n3-d222，n2-d33，n2-d33-denseのそれぞれで，評価100問題について，ゼロ行動と一様乱数の行動2個のベジェ制御点を追跡し，恒等元以外のすべての群の元で変換した制御点も追跡して，コストを比較する．

### 3.2．フル潜在空間のラベル

群の作用が潜在空間で閉じるには$m=2D$（全潜在空間）が必要である．n3-d222（行動次元48）とn2-d33（行動次元24）について，`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0`を20シャード×500問題実行した（計10000問題）．評価seedの基点は，n3-d222が1100000，n2-d33が2100000．

### 3.3．BC

`behavior_cloning.py --latent-dim full --hidden-sizes 256,256 --epochs 300 --batch-size 256 --learning-rate 1e-3 --val-fraction 0.1`．`--seed`∈{0,1,2}．対称性による拡張なし（noaug）と，ミニバッチの各標本に群の元を独立に一様抽出して観測・行動を変換する拡張あり（aug，変換後の行動は箱へクリップ）を比較する．訓練9000件，検証1000件．評価は既定の100問題で，比較対象はEXP-0009のフル潜在oracle（$B=1000$，同じ評価seed）である．

### 3.4．kNN診断（追跡なし）

フル潜在ラベルの末尾1000件をテスト，先頭$N\in\{1000,3000,9000\}$件を訓練とし，$k\in\{5,10,20,50,100\}$のkNN回帰の最良の$R^2$を求める．拡張ありでは，訓練観測と訓練行動にすべての群の元を作用させた集合を訓練に用いる．$R^2$はテスト行動の全座標の二乗和に対して計算した．

## 4．判断基準（実行前に固定）

- 不変性の検証で99%以上のペアがコスト差1%以内 → 対称性はほぼ成立
- 拡張ありの到達率が拡張なしより0.10以上改善 → 対称性が学びにくさの主因
- 改善が0.05未満 → 主因ではない（入力特徴量やBC→PPO微調整を検討）

## 6．観察

- 3つの系すべてで，対称変換の前後の追跡コストの差は，全ペアで1%以内だった．置換と共役だけの変換では完全に一致した．スケール変換を含む場合のみ，n3-d222の約2割でわずかな差（平均0.02ステップ）が出た．
- 全次元の行動空間でのBCは，拡張なしでも，EXP-0010の$m=4$のBCより大きく改善した．$\Delta J$は，n3-d222で約$-4.8\%$から$-7.75\%$，n2-d33で約$-11.4\%$から$-21.89\%$になった．
- 対称性による拡張は，1500エポックでn3-d222の到達率を0.298から0.447に，n2-d33を0.718から0.812に上げた．n3-d222では，3seedの範囲が拡張の有無で重ならない．
- 拡張なしの最良エポックは，n3-d222で51〜67，n2-d33で155〜204だった．300エポックより十分前に検証損失が最小になっている．拡張ありは1500エポックでも最良エポックが1392〜1499で，まだ飽和していない．
- 検証損失（行動の二乗誤差）は，拡張の有無やエポック数でほとんど変わらなかった．それでも，評価時のコストは大きく改善した．
- $k$近傍の$R^2$も，拡張で上がった．n3-d222で0.016から0.037，n2-d33で0.127から0.184である．

## 7．考察

### 7.1．判断基準との照合

- **不変性**：全ペアで1%以内であり，基準（99%以上）を満たす．対称性は，追跡コストの意味でほぼ成立する．
- **拡張の効果**：
  - n3-d222では到達率が+0.149改善し，基準の0.10を超える．したがって，**対称性を知らないことは，n3-d222の学びにくさの主因の一つ**と判断する．
  - n2-d33では+0.094で，中間（0.05〜0.10）にあたる．
- 拡張ありだけを1500エポックで再実行しているため，エポック数の効果が混ざる懸念がある．しかし拡張なしは，早期打ち切りで選ばれた最良エポックが300よりずっと前にある．エポック数を増やしても改善は見込めない．比較は実質的に公平と考える．

### 7.2．対称性の効果の大きさ

- 群の大きいn3-d222（96）の方が，n2-d33（36）より改善幅が大きい．これは仮説と整合する．
- 変数の数$n$が増えると，群の大きさは$n!\prod_j d_j\cdot2$で急速に大きくなる．したがって，対称性の利用は規模拡大でより重要になる見込みである．

### 7.3．行動空間の影響

- EXP-0009では，oracle同士で比べると，$m=4$と全次元の差は4〜6ポイントにすぎなかった．
- しかし学習した方策では，全次元にするだけで$\Delta J$がn2-d33でほぼ倍になった．ランダムな4次元部分空間への射影は，到達できる改善量をあまり減らさない．その一方で，係数から最良行動への写像を学びにくくしていたと考えられる．

### 7.4．評価指標について

- 行動の二乗誤差（検証損失）や$R^2$は，拡張の有無でほとんど変わらないのに，コストは大きく改善した．
- コストが行動の一部の方向にしか敏感でないためと考えられる．教師行動の誤差は，コストの良い代理指標ではない．今後の比較は，追跡コストで行うべきである．

### 7.5．これまでの到達点

n3-d222の$\Delta J$の推移は次のとおり．

| 手法 | $\Delta J$ |
|---|---:|
| PPO（$m=4$，EXP-0007の3seed平均） | $-2.1\%$ |
| BC（$m=4$，EXP-0010） | $-4.8\%$ |
| BC（全次元，拡張なし） | $-7.75\%$ |
| BC（全次元，拡張あり，1500エポック） | $-11.62\%$（最良seedで$-13.37\%$） |

n2-d33では，$-10.2\%$（PPO）から$-24.74\%$になった．推論時の計算は，どれも方策の順伝播1回と追跡1回で変わらない．拡張は学習時にのみ使う．

### 限界

- 拡張なしの1500エポックでの再実行はしていない（7.1節の理由による）．
- seedは3つで，対象は小規模な2系のみである．
- EXP-0010（$m=4$）との比較は，oracleの基準が異なるため，$\Delta J$で行った．
- 拡張ありの学習は1500エポックでも飽和していない．

## 8．実行中の問題

段階2までの全runは正常終了し，ログにエラーはなかった．5.6節の追加検証は，初回の起動（`stage3.sh`）が，未追跡の記録ファイルのため作業ツリーがdirtyと判定されて即座に失敗した（run directoryは作成されていない．`outputs/EXP-0011/stage3_*`と`logs/*-e1500-seed*.log`にその痕跡が残る）．記録をコミットして作業ツリーをcleanにしたうえで，`stage3b.sh`で再実行した（`stage3b_*`，`logs/*-e1500b-seed*.log`）．

## 9．結論

- Pham型系の対称性（置換，1の冪根倍，共役）は，追跡コストの意味でほぼ厳密に成り立つ．
- 全次元の行動空間で，対称性による拡張つきの教師あり学習を行った．n3-d222では到達率が0.45，$\Delta J$が$-11.6\%$に達し，PPO（$-2.1\%$）を大きく上回った．
- 学びにくさの主な要因は，次の2つだった．
  - ランダムな低次元の行動部分空間
  - 学習器が問題の対称性を知らないこと
- 拡張ありの学習はまだ飽和しておらず，さらなる改善の余地がある．

## 10．次の実験

優先度の高い順に挙げる．

1. **学習の飽和の確認**（低コスト）：拡張ありで，エポック数（例：5000）とネットワークの大きさを増やす．
2. **コストを直接使った微調整**：行動の二乗誤差はコストの良い代理指標ではない（7.4節）．そこで，BCの方策を初期値に，コストを直接最適化する．
   - 候補は，全次元の行動空間でのPPOや，同じ問題で複数の行動を比べる学習である．
   - 対称性による拡張も併用する．
3. **規模拡大での検証**：n3-d333，n4-d2222などで，同じ手順（全次元，拡張つきBC）を試す．
   - 群が大きくなる分，対称性の効果が増すかを確かめる．
   - 教師データ生成のコスト（oracle探索）が増えるため，予算の見直しも必要である．
4. **対称性を組み込んだネットワーク**：拡張でなく，不変性・同変性を構造として持つネットワークや，正準化を検討する．大きな群では，拡張によるサンプリングが群を覆いにくくなるためである．
