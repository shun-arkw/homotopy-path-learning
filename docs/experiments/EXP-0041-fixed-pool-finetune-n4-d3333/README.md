## 2．目的

- 微調整（対称な有限差分で$J$の勾配を推定し，方策の重みを更新する）が弱い理由を切り分ける．候補は，(i) 推定量の雑音が律速，(ii) 最適化の歩幅・反復数が律速，(iii) 目的系ごとの改善が目的系間で一貫しておらず，ネットワークでは表せない（汎化が律速）．
- 固定した少数の目的系だけで微調整すると，(iii)の制約がほぼ外れる．目的系ごとの探索では，同じ目的系で$\Delta J\approx-35\%$（EXP-0038の教師データ，1目的系あたり100評価×3方策）に届くことが分かっている．
- **解釈の非対称性：** 固定プールでは1目的系あたりの追跡回数が$2P\times$反復数になる（$P=4$，2000反復で16000回，$P=16$で64000回．ラベル探索は100〜300回）．したがって「プールでもラベルに届かない」は(i)または(ii)の**強い**証拠だが，「届く」は推定量が十分であることの**弱い**証拠にすぎない．これを補うため，1目的系あたりの追跡回数がラベルの予算と同程度になる反復での値も記録する（4節）．(i)と(ii)は，$P$を増やす腕と学習率を上げる腕で切り分ける．

## 4．方法

記号：$K$は1反復の目的系数，$P$は目的系ごとの摂動対の数，$\sigma$は摂動幅，$N$はプール（固定した目的系の集合）の大きさ，$\eta$は学習率．$\Delta J_{\rm pool}$はプールでの削減率（目的系ごとの$J$の平均から計算）．

- **プール：** 学習データの先頭32目的系（評価seed 9000000〜9000031）．$N=K=32$．各反復で同じ32個を使う．
- **初期値：** EXP-0038の第1周の教師あり学習（best-of-3ラベル）のcheckpoint，seed 0（診断なので1seed）．
- **共通設定：** $\sigma=0.05$，$\lambda=0$（教師項なし），2000反復，8ワーカー．検証は従来どおり検証seed 9600000からの200目的系（50反復ごと）．
- **腕：**

| 腕 | $P$ | $\eta$ | 追跡/反復 | 狙い |
|---|---:|---|---:|---|
| D4-a | 4 | $10^{-4}$ | 256 | 基準の設定で固定プール |
| D4-b | 16 | $10^{-4}$ | 1024 | 推定量の雑音を1/4にする |
| D4-c | 4 | $10^{-3}$ | 256 | 歩幅を10倍にする（雑音は同じ） |
| D4-c′（予備） | 4 | $3\times10^{-4}$ | 256 | **D4-cが発散（6節）した場合にだけ実行する**（事前登録した予備の腕．D4-cが発散しなければ実行しない） |

- **プールの記録：** `pool_metrics.csv`に，反復1〜50は毎反復，以後50反復ごとに$\Delta J_{\rm pool}$と1目的系あたりの追跡回数$2P\times$反復を記録する．特に次の反復の値を参照点として報告する．
  - $P=4$（D4-a，D4-c）：反復13（$2P\times13=104$回，ラベル1方策分の予算100に相当），反復38（304回，3方策分300に相当）．
  - $P=16$（D4-b）：反復4（128回），反復10（320回）．
- **主統計量：** $\overline{\Delta J}_{\rm pool}$＝反復1501〜2000の記録点（1550，1600，…，2000の10点）の$\Delta J_{\rm pool}$の平均．2000反復中の最良値は副次的な数値として併記する（最良値は揺らぎで楽観的になるため，判断には使わない）．
- **参照値（追跡は不要）：** 同じ32目的系での，教師データ（best-of-3）の$\Delta J_{\rm label}$，第1周BC seed 0の$\Delta J_{\rm bc}$（反復0の値と一致するはず），第1周FT seed 0の$\Delta J_{\rm ft}$．
- **比較の方法：** $\Delta J_{\rm pool}$の推移と$\overline{\Delta J}_{\rm pool}$．統計検定は行わない（32目的系・1seedの診断）．

## 5．判断基準（実行前に固定）

しきい値は2ポイント．各腕の$\overline{\Delta J}_{\rm pool}$（1501〜2000反復の平均）を使う．$\Delta J_{\rm label}\approx-35\%$，$\Delta J_{\rm ft}\approx-30\%$の見込み．

注意：しきい値は$\Delta J_{\rm ft}-2$と$\Delta J_{\rm label}\pm2$に固定しているので，見込みの値では結果1（$-32\%$以上）と結果2（$-33\%$以下）の間の「中間」の帯は約1ポイントしかなく，判定は実質的に二値である．これは意図したものである（中間の帯を広げると，どちらとも言えない結果が増える）．

**D4-a（基準の設定）について：**

1. $\overline{\Delta J}_{\rm pool}\ge\Delta J_{\rm ft}-2$ポイント（第1周FT seed 0から2ポイント以内しか改善しない）→ 推定量または最適化が律速（**強い証拠**）．D4-b・D4-cで切り分ける（下記）．
2. $\Delta J_{\rm label}-2\le\overline{\Delta J}_{\rm pool}\le\Delta J_{\rm label}+2$ポイント（教師データに2ポイント以内で届く）→ 追跡回数を十分に使えば推定量と最適化は足りる（**弱い証拠**）．汎化（目的系間の一貫性）が律速の可能性がある．EXP-0042を優先する．ただし，反復13・38の時点でラベルから5ポイント以上離れていれば，「同じ追跡回数では探索より効率が悪い」ことを併記し，EXP-0043の第1段も行う．
3. $\overline{\Delta J}_{\rm pool}<\Delta J_{\rm label}-2$ポイント（教師データより2ポイント以上良い，$-37\%$以下）→ 予算100〜300の探索は目的系ごとの最適点に達しておらず，教師データの質が上限を決めている．EXP-0042の利得は教師データの質に制約されるので，微調整を主役にする方向（EXP-0043）と，探索予算の増加・EXP-Cを優先する．
4. 中間（1と2の間）→ 両方が効いている．EXP-0042とEXP-0043を並行する．

**切り分け（D4-aが1または4のとき）：**

- D4-bがD4-aより2ポイント以上良い → 推定量の雑音が効いている．EXP-0043では$P$の増加（B1，B2）を重視する．
- D4-cが教師データに**届くか上回り**（上の2または3の範囲），D4-aが届かない → **歩幅・反復数が律速で，推定量ではない**．EXP-0043に学習率の腕B5（$K=32$，$P=4$，$\sigma=0.05$，$\eta$はこの判定に使った腕と同じ：D4-cなら$10^{-3}$，D4-c′なら$3\times10^{-4}$）を**条件付きで追加する**（本記録で事前に宣言した追加であり，結果を見てからの変更ではない）．
- D4-cが発散（6節）した場合は，予備の腕D4-c′（$\eta=3\times10^{-4}$）を実行し，同じ判定をD4-c′で行う．D4-c′も発散した場合は，「歩幅が律速ではない」とは結論しない（判定不能として報告する）．

## 6．中断の条件

- いずれかの腕で$\Delta J_{\rm pool}$が反復0の値より5ポイント以上悪化した場合，その腕を発散として止める（他の腕は続ける）．D4-cは学習率が大きいので発散しうる．D4-cが発散した場合に限り，予備の腕D4-c′を実行する．
- 損失の発散，追跡失敗．
- 判断基準を結果を見てから変えない．

## 7．計算量の見積もり（ローカル，28スレッド）

- D4-a，D4-c：各$2PK=256$追跡/反復＋プール評価32回（反復1〜50は毎反復，以後50反復ごと）．EXP-0038の微調整（8ワーカー，2000反復）が39分なので，各約45分．
- D4-b：$2PK=1024$追跡/反復で約4倍．8ワーカーで約2.6時間，12ワーカーで約1.8時間．
- D4-c′（D4-cが発散した場合のみ）：D4-aと同じ，約45分．
- 3腕を同時に実行できる（8＋8＋12ワーカー＝28スレッド）．GPUは使わない．合計の壁時計時間は約2時間（D4-c′を実行する場合は約2.8時間）．

- **切り分けは行わない．** 5節の切り分け（D4-b，D4-c，D4-c′）は，D4-aが結果1または4のときに行うと決めていた．D4-aが結果3なので，この判定には使わない．

### 8.4 観察（記述）

- **同じ32目的系だけなら，微調整は教師データを大きく超える．** D4-aとD4-bはどちらも約−38.9%で頭打ちになり，教師データ（−35.25%）より3.6〜3.7ポイント良い．$P$を4倍にしても到達点は変わらなかった（差0.1ポイント）．
- **追跡回数あたりでは，序盤は探索の方が効率がよい．** 1目的系あたり約100回の追跡で，探索1回は−33.3〜−34.5%，D4-aは−31.5%（反復13），D4-bは−30.1%（反復4，128回）だった．約300回では，教師データ（探索3回）−35.25%に対し，D4-aは−33.1%（反復38），D4-bは−31.4%（反復10，320回）だった．同じ追跡回数なら$P=4$の方が$P=16$より速く進んだ．
- **プールに合わせるほど，検証データでは悪くなる．** D4-aとD4-bの検証の$\Delta J$は，反復0の−29.0%から約−27%に悪化した．毎反復新しい目的系で学習した第1周FTは，同じ期間で−29.5〜−30%を保った．32目的系への過学習である．
- **学習率$10^{-3}$は不安定．** D4-cは最初の更新でプールの値が約4.5ポイント悪化し，終盤にも一度崩れた．検証の値は−21.4%まで悪化した．

### 8.5 考察

- 結果3は，「ネットワークがこの32目的系に対して教師データより良いパスを表現でき，微調整の推定量と最適化でそこへ到達できる」ことを示す．これは事前登録で想定した解釈のうち，「探索予算100〜300の教師データは目的系ごとの最適点に届いていない」と整合する．
- ただし，この診断は32目的系への当てはめ（過学習）であり，検証データでは悪化した．したがって「目的系が毎反復変わる通常の微調整で，テストデータの値がどこまで伸びるか」には直接は答えない．通常の微調整がテストで約−30%にとどまる原因として，推定量の雑音や最適化よりも，目的系をまたいだ汎化の方が効いている可能性は，この結果と矛盾しない．
- $P$を増やして推定量の雑音を減らしても，固定プールでは到達点も序盤の追跡回数あたりの進みも良くならなかった．EXP-0043の腕B1（$K=8$，$P=16$）が基準線より悪かったこととも整合する．
