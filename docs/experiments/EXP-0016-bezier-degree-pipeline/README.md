## 2．目的

EXP-0009〜0013のn3-d222（$d_b=3$）では，フル潜在空間のoracleが$\Delta J=-25.99\%$（$B=1000$），BC＋微調整が$-18.66\%$（延長・アンサンブルで$-20.36\%$）だった．ベジェ次数$d_b$が小さいと行動次元が減って探索と学習が容易になる一方，表現できるパスは狭くなる．$d_b$を変えたとき，oracleと標準パイプライン（ラベル → 拡張つきBC → 微調整）がどう変わるかを調べる．

## 3．方法・設定

### 多項式系

**n3-d222**（$n=3$，次数$(2,2,2)$，$N_{\mathrm{path}}=8$，観測次元24）

- 開始系 $G=\{g_1,g_2,g_3\}$：
  $$g_1=x_1^2-1,\qquad g_2=x_2^2-1,\qquad g_3=x_3^2-1$$
- 目的系 $F=\{f_1,f_2,f_3\}$：
  $$f_1=x_1^2+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}x_3+a_{1,4}$$
  $$f_2=x_2^2+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}x_3+a_{2,4}$$
  $$f_3=x_3^2+a_{3,1}x_1+a_{3,2}x_2+a_{3,3}x_3+a_{3,4}$$

係数$a_{i,j}$は問題ごとに異なる．実部と虚部を，それぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数は1に固定する．

### 3.1．数学的な注意：$d_b=2$のパスは$d_b=3$で厳密に表現できる

$d_b=2$の制御点を$P_0,P_1,P_2$とし，線形パスの中点を$M=(P_0+P_2)/2$，摂動を$\delta$として$P_1=M+\delta$とする．次数上げ（degree elevation）により，同じ曲線の$d_b=3$の制御点は
$$Q_0=P_0,\quad Q_1=\frac{P_0+2P_1}{3},\quad Q_2=\frac{2P_1+P_2}{3},\quad Q_3=P_2$$
となる．$d_b=3$の線形パスの制御点を$L_k=P_0+\frac{k}{3}(P_2-P_0)$とすると，$Q_1=L_1+\frac23\delta$，$Q_2=L_2+\frac23\delta$である．すなわち，同じ基底$U$のもとで，$d_b=2$の潜在行動$\boldsymbol{z}$は$d_b=3$の潜在行動$\boldsymbol{z}_1=\boldsymbol{z}_2=\frac23\boldsymbol{z}$に対応し，箱$[-1,1]$の内側に収まる．したがって，$d_b=3$の真の最適値は$d_b=2$の真の最適値以下である．本実験で$d_b=3$のoracleの値が$d_b=2$より高い（5.1節）のは，表現力ではなく，行動次元が大きいことによる**探索の難しさ**（有限の予算）を反映している．

### 3.2．予備oracle

$d_b=2$と$d_b=4$について，EXP-0009のn3-d222と同じ評価問題（32000〜32099）で，フル潜在空間，予算$B=3000$のoracleを実行した（`--n-random 100 --search-seed 0`，2 shard×50問題）．$d_b=3$の参考値は，EXP-0009のn3-d222のフル潜在oracle（$B=1000$の`exp-0009-n3-d222-full-20261012T072240Z`と，$B=3000$の`exp-0009-n3-d222-full-b3000-20261012T072240Z`）である．$\Delta J$は各問題のoracleコストの先頭$B$評価の最小値で求めた．

### 3.3．標準パイプライン（$d_b=2$）

EXP-0011（ラベル），EXP-0012のC2（BC），EXP-0013（微調整，$\lambda=0$）と，ベジェ次数以外は同一である．

- ラベル：`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0 --num-instances 500`，評価seedの基点は1100000＋500k（k＝0〜19，EXP-0011と同じ問題seed），計10000問題．

## 6．観察

- **oracle：** 全次元のoracleの改善余地は$d_b=2$が最も大きく（予算1000で$-33.05\%$），$d_b=3$（$-25.99\%$），$d_b=4$（$-23.23\%$）の順だった．

  - $d_b=4$は予算3000でも改善が続いていた．
- **教師データ：** $d_b=2$のラベルの平均$\Delta J$は$-32.23\%$で，$d_b=3$のラベル（EXP-0011，$-25.26\%$）より約7ポイント良かった．
- **学習した方策：** $d_b=2$は，教師あり学習で$-17.15\%$（$d_b=3$は$-15.04\%$），微調整後で$-20.29\%$（$d_b=3$は$-18.66\%$）だった．どの段階でも$d_b=3$を上回った．

- **oracleとの差：** 学習した方策とoracle（予算1000）の差は，$d_b=2$で約12.8ポイント，$d_b=3$で約7.3ポイントと，$d_b=2$の方が大きかった．到達率は$d_b=2$で0.614，$d_b=3$で0.718である．

## 7．考察

### 7.1．なぜ$d_b=2$のoracleの方が良いのか

- 3.1節のとおり，$d_b=3$は$d_b=2$のすべてのパスを表現できる．したがって，$d_b=3$の真の改善余地は$d_b=2$以上である．
- それでも$d_b=2$のoracleが良いのは，探索の難しさのためである．行動の次元が24から48，72と増えると，有限回の探索で良い行動を見つけにくくなる．
- 「どれだけ良いパスが存在するか」と「どれだけ良いパスを見つけられるか・学べるか」は別の問題であり，現在の性能を決めているのは後者である．

### 7.2．学習した方策への効果

- $d_b=2$にすると，教師データの質が大幅に上がり（約7ポイント），行動の次元も半分になる．その結果，学習した方策も約1.6〜2ポイント良くなった．
- ただし，教師データの改善幅（約7ポイント）に比べて，方策の改善幅は小さい．oracleとの差はかえって広がった．
- 考えられる理由は，$d_b=2$の最良行動の方が問題ごとの違いが大きく，学習しにくいことである．これは推測であり，確かめていない．

### 7.3．$d_b$の選び方について

- 本実験の結果は，n3-d222の1系での比較にすぎない．EXP-0006（$m=4$とPPO）でも，$d_b=2$と$3$の優劣は問題の設定によって入れ替わった．
- $d_b=2$の中間制御点は1つなので，パスは1回しか大きく曲がれない．係数の範囲が広い問題や，判別式の近くを大きく迂回する必要がある問題では，$d_b=3$以上が必要になる可能性がある．
- したがって，**$d_b$を一律に$2$へ切り替えるのではなく，系ごとに選ぶハイパーパラメータとして扱う．** 選ぶ際は，oracleの予備調査（安価）で改善余地と収束の速さを比べるのが有効である．

### 限界

- 1系（n3-d222），3seed，評価100問題での比較である．
- $d_b=2$では，延長とアンサンブルは行っていない．
- $d_b=4$は，oracleの予備調査のみで，パイプラインは適用していない．

## 9．結論

- n3-d222では，$d_b=2$の方が$d_b=3$より良い結果になった．
  - oracleの改善余地：$-33.1\%$対$-26.0\%$
  - 微調整後の方策：$-20.3\%$対$-18.7\%$
- 理由は表現力ではなく，探索と学習の次元が小さく済むことにある（$d_b=3$は$d_b=2$を含む）．
- この結果は1系での比較であり，$d_b$は系ごとに選ぶハイパーパラメータとして扱う．
