# EXP-0035：方策を初期値にした探索による上限の目安の測り直し（n5）

## 2．目的

- EXP-0033では，探索（多点スタート，$d_b=2$と$3$）で上限の目安を測り，4条件とも$-40\%$に届かなかった（n5-d22222：難しい問題$-39.1\%$，通常$-35.9\%$．n5-d33333：難しい問題$-25.0\%$，通常$-24.2\%$）．
- 一方，EXP-0034では，n5-d33333の微調整後の方策が試験500問題で$-24.84\%$となり，探索によるoracleを大きく上回った．探索で求めた上限の目安は，実際より低めである可能性が高い．
- 微調整後の方策の行動を初期値にして探索し，上限の目安を測り直す．今の設定（係数パスの形，開始系，追跡の設定）で50%削減に届くかを，改めて判定する．

## 3．多項式系

EXP-0033と同じ（n5-d22222とn5-d33333，$d_b=2$）．

## 4．方法（事前登録）

- **問題：** EXP-0033 4.2節と同じ80問題．
  - 難しい問題：各系の難しい試験問題の先頭20問題．
  - 通常の問題：n5-d22222は評価seed 9520000〜9520019，n5-d33333は9510000〜9510019．
- **初期値にする方策：** attention＋微調整（2000反復，通常の分布で学習）の seed 0〜2．
  - n5-d22222：EXP-0031の方策．
  - n5-d33333：EXP-0034の方策．
- **探索：** 全次元（$d_b=2$，60次元），予算3000．
  - 評価の順は，零行動（線形パス），方策の行動，その後は最良の点からの(1+1)進化戦略である（一様乱数の標本は使わない．`--n-random 2`）．
  - 進化戦略の初期の幅は，行動の上限の0.05倍とする（`--initial-sigma 0.05`．微調整の探索の幅$\sigma=0.05$に合わせる）．幅はこれまでと同じ1/5規則で調整する．
  - 方策 seed $k$の行動を初期値にし，探索seedも$k$とする（$k=0,1,2$）．問題ごとに，3回のうち最良をとる．
- **上限の目安：** 問題ごとに，EXP-0033の上限の目安と，本実験の3回の探索の最良のうち，良い方とする．
- **確認：** 方策の行動のコスト（探索の2番目の評価）が，既存の評価のコストと一致することを確かめる．比較できるのは，n5-d22222の難しい問題と通常の問題（EXP-0031の方策の評価）と，n5-d33333の通常の問題（EXP-0034の比較用100問題での評価）である．一致しない場合は止めて報告する．
- 計算量：n5-d33333は1問題を1ジョブ，n5-d22222は5問題を1ジョブとし，8並列で行う（EXP-0036と同時に実行するため）．

## 5．判断基準（実行前に固定）

- **上限（参考の判断，EXP-0033 5節と同じしきい値）：** 系と問題の種類ごとに，上限の目安の平均$J$での$\Delta J$を報告する．
  - $-50\%$以下 → 今の設定で，その分布では平均50%削減に届く．
  - $-40\%$より大きい → 今の設定では50%削減は難しい．係数パスの形，開始系，追跡の設定の見直しを検討する．
- あわせて，次を報告する．20問題なので，差の判定はしない．
  - 50%以上削減できた問題の数．
  - EXP-0033の上限の目安からの変化と，本実験の探索の方が良かった問題の数．
  - 方策の行動そのもの（3 seedの平均と最良）と，探索後の最良の差（探索で上積みできる量）．
