## 2．目的

- 変数5つ，次数3の系（n5-d33333，243パス）で，初めて教師あり学習と微調整まで通し，パイプラインが通用するかを確かめる．
- ここで得る方策は，EXP-0033 4.4節（n5-d33333の難しい問題の分布）の比較の基準（通常の分布で学習した方策）にもなる．

## 3．多項式系

開始系は$g_i=x_i^3-1$，目的系は$f_i=x_i^3+a_{i,1}x_1+\dots+a_{i,5}x_5+a_{i,6}$（$i=1,\dots,5$，EXP-0028の3節）．係数は実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．$d_b=2$，観測・行動は60次元，パスは243本，対称群の大きさは58320．

## 4．方法（事前登録）

- **教師データ：** EXP-0028で生成した1万件（探索seed 0，予算500，評価seed 11000000〜11009999）．
  - EXP-0028 6.1節では，1回の探索の1万件と多点スタートの2000件のどちらを使うかを，EXP-0030の結果で決めるとした．EXP-0030では，微調整後の$\Delta J$は1回の探索の1万件（$-24.20\%$）の方が多点スタートの2000件（$-23.12\%$）より小さかった．よって1回の探索の1万件を使う．多点スタートの2000件は，教師データの質の参考値として記録する．
- **比較用oracle（評価100問題）：** EXP-0028の予備調査のoracle（予算3000，評価seed 9510000〜9510099）を連結して使う．
- **教師あり学習：** attention（既定の大きさ，300エポック，GPU），対称性による拡張，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．
- **微調整：** 2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題（検証seed 11600000），訓練seed 11700000．追跡は10ワーカーで並列に行う（`--workers 10`．結果はワーカー数によらない）．
- **試験問題：** これまで使っていない評価seed 9530000〜9530499の500問題．oracle（全次元，予算1000，探索seed 0）を求め，到達率の分母にする．EXP-0023の補足で，1回の探索のoracleは多点スタートより弱いことが分かっているため，到達率は参考の値とする．
- MLP方策は省く（EXP-0031で，n5-d22222ではattentionの方が大きく良かったため）．
- 比較は`compare_runs.py`で行う（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．
- 開始の条件：EXP-0028（教師データ）が終わり，かつEXP-0033の微調整が終わった後（CPUの空き）．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整後の$\Delta J$（試験500問題，3seedの問題ごと平均）が$-20\%$以下 → パイプラインはn5-d33333にも通用する（参考：2000反復で，n5-d22222は$-20.87\%$，n4-d3333は$-28.57\%$）．
- **副基準：** 微調整後−教師あり学習の$\Delta J$の差が$-1.0$ポイント以下で，かつ95%区間が0を含まない．
