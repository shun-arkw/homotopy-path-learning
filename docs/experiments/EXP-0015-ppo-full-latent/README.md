## 2．目的

EXP-0013では，BCと微調整により，n3-d222で$\Delta J$が$-18.66\%$（到達率0.72）に達した．これらはフル潜在空間（行動次元48，$m=24$）で学習しており，EXP-0007のPPO（$m=4$，行動次元8，3seed平均$-2.09\%$）とは行動空間が異なる．BC＋微調整の優位が，全次元の行動空間を用いたことだけで説明できるのかを確認するため，同じn3-d222の系で，PPOを全次元の行動空間（$m=24$）で学習する．

## 3．方法・設定

EXP-0007のn3-d222と同一の系・追跡設定・PPO設定である（ネットワークは隠れ層$(64,64)$，50万ステップ，ロールアウト長250）．変更点は潜在次元だけで，$m=4$を全次元の$m=24$（行動次元$(d_b-1)m=48$，基底は24×24の正方直交行列）にした．ベジェ次数は$d_b=3$．3seedで学習し，最終のチェックポイント（`last.pt`）を決定的方策で評価した．到達率の基準はEXP-0009のフル潜在oracle（$B=1000$，同じ評価seed）である．

## 4．判断基準

本実験では，事前に数値の判断基準は固定していない．比較の対象は次の2点である．

- 本実験のPPO（$m=24$）の$\Delta J$が，EXP-0007のPPO（$m=4$，$-2.09\%$）より大きく改善するか．
- 本実験のPPOが，同じ行動空間でのBC（$-15.04\%$）や微調整（$-18.66\%$）にどこまで近づくか．

## 6．観察

- 全次元の行動空間（行動48次元）では，PPOは3seedすべてで線形パスより悪化した（$\Delta J=+3.7$〜$+6.9\%$，平均$+5.34\%$）．

- explained varianceは0.13程度で，EXP-0007の$m=4$のn3-d222（約0.02）より高かった．

## 7．考察

### 7.1．PPOは何を学んだか

- 学習の初期は，48次元の行動空間でランダムに近い行動を取るため，線形パスより大幅に悪い（約22ステップの悪化）．EXP-0014の予備調査でも，ランダムな行動はほぼすべて線形パスより悪かった（予算100で約0%）．
- PPOは，この悪化を小さくする方向（行動を小さくし，線形パスに近づける方向）には学習できた．しかし，線形パスより良い方向は見つけられなかった．
- 高次元の行動空間では，線形パスより良い行動は狭い領域にしかない．確率的な探索でそこに行き当たる確率が低いためと考えられる．
- explained varianceが$m=4$より高いのは，報酬の分散の多くが「行動の大きさによる悪化」という予測しやすい成分で占められたためと考えられる．

### 7.2．BC＋微調整の優位は行動空間の違いによるものか

- 同じ全次元の行動空間で，PPOは$+5.34\%$，BC＋微調整は$-18.66\%$だった．行動空間を揃えても大差がある．
- したがって，EXP-0011以降の改善は，行動空間を全次元にしたことだけでは説明できない．
- 次の2つが，高次元の行動空間での学習を可能にしている．
  - oracleの教師データから出発すること（良い行動のある狭い領域から学習を始められる）
  - 同じ問題で対の摂動を比べる勾配推定（局所的な改善方向を安定して推定できる）
- 一方で，$m=4$ではPPOも小さな改善（$-2.09\%$）を得ていた．低次元では探索が成り立つが，高次元では成り立たない，という対比になる．

### 限界

- PPOのハイパーパラメータ（行動ノイズの初期値`actor_logstd_init=-0.5`，学習率，学習量）は，EXP-0007の$m=4$の設定のままで，全次元向けには調整していない．ノイズを小さくする，学習量を増やすなどで改善する可能性は残る．
- 評価は`last.pt`のみで，`best.pt`は評価していない．

## 9．結論

- 全次元の行動空間（48次元）では，PPOは線形パスより悪化した（3seed平均$\Delta J=+5.3\%$）．
- 同じ行動空間で，oracleの教師データから出発するBC＋微調整は$-18.7\%$に達する．BC＋微調整の優位は，行動空間の違いではなく，学習の出発点と勾配推定の方法によるものである．
