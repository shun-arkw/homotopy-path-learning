## 2．目的

- attention方策の改善は，教師あり学習より微調整の段階に集中していた（EXP-0020〜0022）．
- 教師データ（oracle）を使わずに，微調整だけで同程度の方策が得られるかを調べる．得られるなら，oracleで教師データを作る工程（n4-d3333で約1.7時間）を省ける．

## 3．多項式系

EXP-0020と同じ（n4-d2222，$d_b=2$，行動40次元）．

## 4．方法（事前登録）

- **初期値：** attention方策（既定の大きさ，$d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256）を，学習せずに初期化したままで保存する（`behavior_cloning.py --epochs 0`，seed 0〜2）．出力ヘッドの重みは標準偏差0.01で初期化されるので，初期の行動はほぼゼロ（線形パス）である．
- **微調整：** EXP-0020と同じ設定（$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 8600000，訓練seed 8700000）で，**4000反復**行う．初期値が線形パスなので，教師あり学習ありの場合（2000反復）より多くの反復を与える．検証$\Delta J$が最良の反復の重みを採用する．
- **比較：** EXP-0020の試験500問題（評価seed 41000〜）で，次と比べる．
  - attention，教師あり学習＋微調整2000反復（EXP-0020）
  - attention，教師あり学習＋微調整4000反復（EXP-0024のn4-d2222）
  - MLP，教師あり学習＋微調整2000反復（EXP-0017）
- 比較は`compare_runs.py`で行う（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整だけの方策−教師あり学習＋微調整2000反復（EXP-0020）の，試験500問題での$\Delta J$の差について，95%区間の上端が$+1.0$ポイント未満 → 教師あり学習なしでも同程度の方策が得られる．
- **参考：** 微調整だけの方策−MLP＋微調整（EXP-0017）の差も報告する．検証$\Delta J$の推移（反復0，500，1000，2000，3000，4000）も報告する．
