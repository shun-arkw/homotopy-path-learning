## 2．目的

- EXP-0053で，学習し直さずに追跡を新しい追跡の設定に変えると，線形パスも学習したパスもステップ数が約4分の1になった．8つの系の種類の開発集合とテストデータで，追跡の失敗も解の取りこぼしもなかった．
- 一方，線形パスに対する削減率は，4つの系の種類で2.7〜3.7ポイント下がった．ネットワークは今の追跡の設定で教師データを作り，微調整したものである．
- 本実験では，教師データ・教師あり学習・微調整をすべて新しい追跡の設定で行い，次の3つを調べる．
  1. 新しい追跡の設定は，探索や微調整で試す大きく曲がった係数パスでも安全か（解の取りこぼし）．探索も微調整もステップ数を最小にしようとするので，取りこぼした（別の解のパスへ乗り移った）係数パスを「良い係数パス」として選んでしまう危険がある．
  2. 新しい追跡の設定で学習し直すと，削減率は今の標準（今の追跡の設定で学習し，今の追跡の設定で評価）と同じくらいに戻るか．
  3. 教師データ作りと微調整の時間はどれだけ短くなるか．

## 4．方法（事前登録）

### 4.1．取りこぼしの判定

- 目的系ごとに，線形パスを慎重な設定（予測子は1次，HC.jl の`CONSERVATIVE_TRACKER_PARAMETERS`，`max_step_size`=0.05）で追跡した終点を参照の解とする（EXP-0053の4.2節と同じ）．参照の解がすべて追跡に成功し，重複がないことも確かめる．
- 係数パスを追跡した終点のどれからも相対誤差$10^{-6}$以内にない参照の解の数を，「取りこぼした解」の数とする．

### 4.2．第0段：安全の確認（学習データの目的系だけを使う）

1. **既存の教師データの係数パス：** 8つの系の種類で，今の$d_b=3$の教師データ（3節）の先頭500個の目的系について，教師データの係数パス（探索で見つけた中間制御点）を，今の追跡の設定と新しい追跡の設定の両方で追跡し，ステップ数，失敗，取りこぼしを記録する．
2. **探索：** n4-d3333とn5-d33333の学習データの先頭20個で，探索（予算500．4.3節と同じ設定）を今の追跡の設定と新しい追跡の設定で行い，目的系1つあたりの時間を比べる．新しい追跡の設定で見つかった係数パスの取りこぼしも調べる．2つの設定の探索は同時に，同じ数のプロセスで行う．
3. **進む条件：** 1と2の新しい追跡の設定で，失敗したパスも取りこぼした解も0であること．満たさなければ第1段に進まず，結果を報告して判断を仰ぐ．

### 4.3．第1段：標準の手順（新しい追跡の設定）

各系の種類で，設定ファイル（`exp-0055-*-db3-bw08.yaml`）を使って次を行う．追跡の設定以外は，$d_b=3$の標準の手順と同じである．

1. **環境の確認：** 開発集合の先頭20個を予算2で探索し，線形パスのステップ数が，EXP-0053で新しい追跡の設定で評価した線形パスのステップ数（`outputs/EXP-0053/dev/{系の種類}-B0.8.csv`の`Linear`の行）と完全に一致すること．
2. **教師データ：** `oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0`，20分割×500個（評価seedは学習データの先頭$+500k$）．
3. **教師データの確認：** 1万個すべてについて，教師データの係数パスを新しい追跡の設定で追跡し直し，失敗と取りこぼしを数える．線形パスのステップ数（`linear_cost`）が，同じ目的系をスクリプトで新しい追跡の設定で追跡した値と一致することも確かめる．
4. **教師あり学習：** attention（$d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256），対称性による拡張あり，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．

6. 各段階の開始と終了の時刻，プロセス数（ワーカー数）を記録する．

### 7.5．考察

- **新しい追跡の設定は，学習の各段階でも安全だった．** 探索と微調整はステップ数を減らそうとするので，乗り移った係数パスを選んでしまう危険があったが，教師データ8万個のうち取りこぼしは1個，開発集合とテストデータでは0だった．
- **新しい追跡の設定で作った教師データは悪かった．** 同じ予算の探索では，新しい設定の方が削減率の低い係数パスしか見つからなかった．新しい設定ではステップ数の差が小さく（線形パスで約8〜14歩），棄却で値がばらつくので，探索が良い係数パスを見分けにくい可能性がある（確かめていない）．
- **今の教師データで教師あり学習し，新しい設定で微調整するのが最も良かった．** 各3次の4つの系の種類では，今の標準と同じか少し良い削減率を，約4分の1のステップ数で得た．各2次の4つでは，削減率が1.7〜5.0ポイント（テストデータ）下がった．
- 次数による違いの原因は分からない．各2次では，新しい設定で線形パスのステップ数がもともと少なく（約8〜12歩），曲がった係数パスで減らせる余地が小さいことが考えられる（確かめていない）．
- 変数の数との関係（微調整だけをやり直した場合）は，各3次で+0.5（2変数）から+1.9（5変数），各2次で−4.3から−2.3と，変数が多いほど良い傾向が見えた．6変数での確認はEXP-0056で行った．

### 7.6．結論

- 5節の規則による提案（開発集合）：各3次の4つの系の種類（n2-d33，n3-d333，n4-d3333，n5-d33333）では，微調整だけを新しい追跡の設定でやり直したネットワークを，新しい追跡の設定で使う．各2次の4つ（n2-d22，n3-d222，n4-d2222，n5-d22222）では，今の追跡の設定を続ける．判断が系の種類で分かれたので，標準をどうそろえるかはユーザーと決める（未決定）．
- 新しい追跡の設定で教師データを作り直すことは勧めない（時間は約0.27〜0.29倍になるが，教師データが悪くなり，削減率も下がる）．
