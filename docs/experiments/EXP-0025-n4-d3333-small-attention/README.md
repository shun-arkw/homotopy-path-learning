# EXP-0025：n4-d3333での小さいattentionと推論時間

- 実験ID：EXP-0025
- 状態：Planned（事前登録）

- 実行環境：外部サーバ（GPU 4台のサーバ）の参照Docker`homotopy-continuation`．教師あり学習はGPU，追跡はCPU．EXP-0023と同じコミット（`760d261`）で実行する．

## 2．目的

- n4-d2222では，attentionの方策は追跡のステップ数を23%減らしたが，追跡が1問題あたり約2.3 msと軽いため，順伝播の時間を含めると線形パスより遅かった（EXP-0020，EXP-0022）．
- 追跡の重いn4-d3333（81パス）で，次の2点を調べる．
  1. 小さいattention（約10万パラメータ）で，大きいattention（約80万パラメータ）と同程度の$\Delta J$が得られるか．
  2. 順伝播の時間を含めても，学習したパスが線形パスより速く解けるか．

## 3．多項式系

EXP-0023と同じ（n4-d3333，$f_i=x_i^3+\sum_{j=1}^4a_{i,j}x_j+a_{i,5}$，$d_b=2$，行動40次元）．

## 4．方法（事前登録）

### 4.1．小さいattention

- 構成：$d_{\mathrm{model}}=64$，4ヘッド，2層，FFN 128（EXP-0022と同じ）．
- 教師あり学習：EXP-0023と同じ教師データ1万件，対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．
- 微調整：EXP-0023と同じ設定（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 9600000，訓練seed 9700000）．
- 試験問題：EXP-0023と同じ500問題（評価seed 9300000〜9300499）とそのoracle（予算1000）．

### 4.2．推論時間

- EXP-0023とEXP-0025の微調整がすべて終わり，サーバで他の計算がない状態で，1プロセス・1スレッドで計測する．
- 対象：線形パス，MLP＋微調整，attention＋微調整（EXP-0023），小さいattention＋微調整（各seed 0）．
- 問題：試験問題の先頭100問題．各問題をウォームアップ3回の後に5回測り，中央値をとる．方策はCPUで実行する．

## 5．判断基準（実行前に固定）

- **小さいモデル：** 微調整後の$\Delta J$の差（小さいattention−attention，試験500問題）の95%区間の上端が$+1.0$ポイント未満 → n4-d3333では小さいattentionで十分である．
- **推論時間：** 小さいattention＋微調整の，1問題あたりの全体の時間（順伝播を含む）の平均が，線形パスより短い → 推論時に，学習したパスが線形パスより速く解ける．大きいattentionとMLPについても同じ値を報告する．
