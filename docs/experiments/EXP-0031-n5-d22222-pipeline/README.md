## 2．目的

- 変数5つの系（n5-d22222，32パス）で，初めて教師あり学習と微調整まで通し，MLPとattention方策を比べる．

## 3．多項式系

開始系は$g_i=x_i^2-1$，目的系は$f_i=x_i^2+a_{i,1}x_1+\dots+a_{i,5}x_5+a_{i,6}$（$i=1,\dots,5$）．係数は実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．$d_b=2$，観測・行動は60次元，対称群の大きさは7680．

## 4．方法（事前登録）

- **教師データ：** EXP-0028で生成した1万件（探索seed 0，予算500，評価seed 10000000〜10009999）．
- **比較用oracle（評価100問題）：** EXP-0028の予備調査のoracle（予算3000，評価seed 9500000〜9500099）を連結して使う．
- **教師あり学習：** MLP（3層256，5000エポック，CPU）とattention（既定の大きさ，300エポック，GPU）．いずれも対称性による拡張，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．
- **微調整：** 両方策とも2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題（検証seed 10600000），訓練seed 10700000．
- **試験問題：** これまで使っていない評価seed 9520000〜9520499の500問題．oracle（全次元，予算1000，探索seed 0）を求め，到達率の分母にする．
- 比較は`compare_runs.py`で行う（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整後の$\Delta J$の差（attention−MLP，試験500問題）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → n5-d22222でもattention方策は有効．
- **副基準：** 教師あり学習の段階の到達率の差（attention−MLP，試験500問題）が+0.05以上．
