## 2．目的

n3-d222でPPOの改善が約$-2\%$にとどまる原因を切り分ける．EXP-0007の範囲では，次の3つの仮説を区別できなかった．

- H1：学習の失敗．改善余地はあるが，方策がそれを学習できていない．
- H2：改善余地が小さい．最適なパスが線形パスに近い．
- H3：行動空間が狭い．潜在次元$m=4$では，n3（自由係数の実次元24）の改善方向を表現できない．

`explained_variance`が低いことは，H2の場合にも起こりうる．報酬のばらつきの大部分が説明不能なノイズになるためである．このため，EXP-0007の結果だけではH1とH2を区別できない．

## 3．方法

方策を学習せず，評価問題ごとに潜在行動$\boldsymbol{a}\in[-1,1]^{(d_b-1)m}$を直接探索する．目的関数はベジェパスのコスト$J=N_{\mathrm{acc}}+\rho N_{\mathrm{rej}}$（失敗ペナルティ込み）である．探索は1問題あたり予算$B$回の追跡で，次の順に行う．

1. ゼロ行動（線形パス）
2. 箱内の一様乱数サンプル99点
3. 最良点からの(1+1)進化戦略．ステップ幅は初期値$0.3$で，1/5成功則で調整する．

ゼロ行動を必ず評価するため，oracleのコストは線形パスを上回らない．探索は有限回なので，oracleの改善量は到達可能な改善の**下界**である．

行動空間は次の2通りとした．

- (a) $m=4$：PPOと同じ基底$U$
- (b) full：$m=2D_{\mathrm{free}}$の正方直交基底．自由係数の全方向を張る．

## 4．多項式系

**n3-d222**（$n=3$，次数$(2,2,2)$，$N_{\mathrm{path}}=8$，観測次元24）

- 開始系 $G=\{g_1,g_2,g_3\}$：
  $$g_1=x_1^2-1,\qquad g_2=x_2^2-1,\qquad g_3=x_3^2-1$$
- 目的系 $F=\{f_1,f_2,f_3\}$：
  $$f_1=x_1^2+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}x_3+a_{1,4}$$
  $$f_2=x_2^2+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}x_3+a_{2,4}$$
  $$f_3=x_3^2+a_{3,1}x_1+a_{3,2}x_2+a_{3,3}x_3+a_{3,4}$$

**n2-d33**（$n=2$，次数$(3,3)$，$N_{\mathrm{path}}=9$，観測次元12）

- 開始系 $G=\{g_1,g_2\}$：
  $$g_1=x_1^3-1,\qquad g_2=x_2^3-1$$
- 目的系 $F=\{f_1,f_2\}$：
  $$f_1=x_1^3+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}$$
  $$f_2=x_2^3+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}$$

**n2-d33-dense**（$n=2$，次数$(3,3)$，$N_{\mathrm{path}}=9$，観測次元24）

- 開始系 $G=\{g_1,g_2\}$：
  $$g_1=x_1^3-1,\qquad g_2=x_2^3-1$$
- 目的系 $F=\{f_1,f_2\}$：
  $$f_1=x_1^3+a_{1,1}x_1^2+a_{1,2}x_1x_2+a_{1,3}x_2^2+a_{1,4}x_1+a_{1,5}x_2+a_{1,6}$$
  $$f_2=x_2^3+a_{2,1}x_1^2+a_{2,2}x_1x_2+a_{2,3}x_2^2+a_{2,4}x_1+a_{2,5}x_2+a_{2,6}$$

係数$a_{i,j}$は問題ごとに異なる．実部と虚部を，それぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数は1に固定する．

## 5．係数パス・追跡設定

EXP-0007と同一である．$d_b=3$，`action_limit=1.0`，tracker設定，$\rho=1$，失敗ペナルティ$10^5$．行動次元は，$m=4$で8，fullでn3-d222が48，n2-d33が24，n2-d33-denseが48．

## 6．判断基準（実行前に固定）

- n3-d222の(a)で，oracleが大きく改善する（$-8\%$以下）→ H1
- (a)は小さく，(b)が大きく改善する → H3
- (a)，(b)とも小さい（$-2$〜$-4\%$程度）→ H2
- 探索の妥当性確認として，n2-d33のoracleがPPO（$-10.17\%$）以下になること

## 7．評価指標

- $\Delta J := (\overline{J}_{\text{method}}-\overline{J}_{\mathrm{lin}})/\overline{J}_{\mathrm{lin}}\times100$（%，負が改善）
- Positive rate：その手法のコストがLinearより小さかった問題の割合
- 到達率：$(\overline{J}_{\mathrm{lin}}-\overline{J}_{\mathrm{PPO}})/(\overline{J}_{\mathrm{lin}}-\overline{J}_{\mathrm{oracle}})$．oracleの改善量のうち，PPOが得ている割合．

PPOの値は，EXP-0007の各runの`evaluation/evaluation.csv`（決定的方策，同じ100問題）から取った．すべてのrunで，ゼロ行動のコストは線形パスのコストと完全に一致した．追跡失敗はLinear，oracleとも0件だった．

## 9．観察

- n3-d222にも，n2-d33と同程度の改善余地がある（$m=4$で$-22\%$，fullで$-26\%$以上）．oracleはほぼ全ての問題で線形パスを上回った．
- $m=4$とfullの差は4〜6ポイントである．$m=4$の行動空間でも，改善余地の大部分に到達できる．
- PPOの到達率は，n2-d33で0.35〜0.47，n2-d33-denseで0.17〜0.18，n3-d222で0.04〜0.20である．EXP-0007で問題のなかったn2-d33でも，PPOはoracleの半分以下しか取れていない．
- $m=4$の探索は$B=300$でほぼ飽和している．fullは$B=3000$でもまだ改善している．
- 最良行動の向きは問題間でほぼ無相関である．全問題に共通の良い行動は存在せず，問題ごとに異なる行動が必要である．共通成分がやや大きいn2-d33で，PPOの到達率も最も高い．

## 10．考察

事前に固定した判断基準によれば，n3-d222の結果は**H1（学習の失敗）**に該当する．

- **H2は棄却される．** 最適なパスは線形パスに近くない．$m=4$の範囲だけでも，平均で$-22\%$の改善が可能である．
- **H3は主要因ではない．** $m=4$でoracleは$-22\%$に達する．PPOはその1〜2割しか得ていない．$m$の拡大は改善余地を数ポイント広げるが，現状のボトルネックではない．
- 8.4節の結果から，難しさの中身は次のように考えられる．最良行動は問題ごとに異なるため，方策は係数から行動への，問題に依存した写像を学習する必要がある．ところが，報酬はこの写像を学習するための情報として弱い．1ステップの報酬$r=\mu(J_{\mathrm{lin}}-J_{\mathrm{bez}})$は整数値に近いステップ数の差で，問題ごとのスケールも異なる．これはEXP-0007の`explained_variance`の崩壊とも整合する．
- 観測次元が24になると，到達率は$n=2$でも0.17〜0.18に下がる（n2-d33-dense）．$n=3$ではさらに下がる．これはEXP-0007 19節の結論（観測次元と$n$の両方が学習を難しくする）を，改善余地を基準にした量として裏付ける．

### 限界

- oracleは有限回の探索なので，改善余地の下界である（fullは$B=3000$でも未収束）．
- 最良行動の類似度は，見つかった1つの解についての値である．同程度に良い行動が問題ごとに複数ある場合，類似度は低く出る．
- 各設定でoracleの探索seedは1つだけである．$m=4$では基底seedの異なる3runの範囲が$-21$〜$-24\%$に収まっている．

## 12．結論

- n3-d222の不調は，改善余地が小さいためではない．PPOが問題ごとの最良行動を学習できていないためである．
- $m=4$の行動空間でも，平均で約$-22\%$の改善が可能である．PPOの$-2\%$は，その1〜2割にとどまる．
- n2-d33でも，PPOはoracleの4割程度しか得ていない．学習側の改善は，変数数拡大に限らず，全体の性能向上につながる可能性がある．

## 13．次の実験

改善の対象は，問題設定ではなく学習（方策がoracleに近づけるか）である．候補は次のとおり．

- **報酬の正規化**：問題ごとのスケールを揃える．例えば，比率$J_{\mathrm{bez}}/J_{\mathrm{lin}}$を報酬にする．
- **観測の正規化・特徴量**：係数の標準化．n3で崩壊した価値関数の改善を狙う．
- **oracleを教師とした学習**：oracleの最良行動を教師データとして，方策を教師あり事前学習する（behavior cloning）．学習が難しい原因が探索にあるのか，表現にあるのかを切り分ける．
- **評価指標**：今後の実験では，PPOの$\Delta J$に加えて到達率を報告する．
