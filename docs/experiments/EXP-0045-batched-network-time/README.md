# EXP-0045：複数の目的系をまとめたときのネットワークの計算時間

> 本記録の1〜6節は，実験の実行前（2026-10-16 JST）に書いた事前登録である．結果を見た後に1〜6節を変更する場合は，変更した箇所と理由を明記する．

## 1．基本情報

- 実験ID：EXP-0045
- 状態：Planned（事前登録）
- 実行環境：メインの作業環境の参照Docker`homotopy-continuation`．1プロセス・1スレッド（スレッドの環境変数を1にする）で，他の計算がない状態で計測する．ネットワークはCPUで計算する．
- コードの変更：なし．計測は実験フォルダに置くスクリプト（`outputs/EXP-0045/scripts/batch_forward.py`）で行う．ネットワークの読み込みと入力の作り方は`experiments/multivariate_pham/timing.py`と同じ．

## 2．目的

- EXP-0040とEXP-0044は，目的系を1つずつ解く場合（バッチの大きさ1）のネットワークの計算時間（1.2〜1.9 ms）を測った．
- ネットワークは複数の目的系をまとめて（バッチで）計算できる．多くの目的系を一度に解く使い方で，目的系1つあたりのネットワークの計算時間がどこまで小さくなるかを測る．

## 3．多項式系と，ネットワーク

EXP-0044の標準の手順のネットワーク（seed 0）を全8系の種類で使う．作り直し後のネットワークは構造が同じなので測らない．入力には，各系の種類のテストデータ500個の係数を使う（計算時間の計測だけで，追跡はしない）．

## 4．方法（事前登録）

- バッチの大きさ$B\in\{1,10,100,500\}$．500個の目的系を$B$個ずつ$500/B$組に分ける．
- 1組の計測：係数から入力の配列を作る→ネットワークの計算（勾配なし）→出力をNumPyの配列に戻す，までの時間（EXP-0040の「ネットワークの計算」と同じ範囲）．
- 各組を，ウォームアップ3回の後に5回測り，中央値をとる．目的系1つあたりの時間＝（全組の中央値の和）÷500．
- $B=1$の値は，EXP-0044のネットワークの計算時間とほぼ同じになるはずである（参考の確認）．

## 5．判断基準（実行前に固定）

- 記述的な計測であり，合否の基準は設けない．
- 系の種類ごとに，$B$ごとの目的系1つあたりの時間（ms）と，$B=1$に対する比を表にする．

## 6．中断の条件

- 計測中に他の計算が動いていることが分かった場合は，その系の種類を測り直す．
- ネットワークの出力がバッチの大きさで変わる（同じ目的系で$B=1$と$B=500$の出力の最大絶対差が$10^{-5}$を超える）場合は止めて報告する．

## 7．計算量の見積もり

1系の種類あたり1分以内．合計で数分．
