# EXP-0024：attention方策の微調整の延長（2000反復→4000反復）

> 本記録の1〜6節は，実験の実行前（2026-10-13 15:10 JST頃）に書いた事前登録である．結果を見た後に1〜6節を変更する場合は，変更した箇所と理由を明記する．

## 1．基本情報

- 実験ID：EXP-0024
- 状態：Planned（事前登録）
- 対象：EXP-0020（n4-d2222，$d_b=2$）とEXP-0021（n3-d222，$d_b=2$／n3-d333，$d_b=3$）の，attention＋微調整の方策（各3seed）
- 実行環境：メインの作業環境（参照Docker`homotopy-continuation`）．追跡はCPU．実験専用の作業ツリーから起動する．

## 2．目的

- EXP-0020とEXP-0021では，attention方策の微調整の検証$\Delta J$が，2000反復の時点でもまだ改善していた（特にn3-d333では3seedとも最良の反復が1850〜2000）．
- 微調整をさらに2000反復続けると，どこまで改善するかを調べる．

## 3．多項式系

EXP-0020（n4-d2222）とEXP-0021（n3-d222，n3-d333）と同じ．

## 4．方法（事前登録）

- 各系の，attention＋微調整（2000反復）の方策（seed 0〜2）を初期値とし，同じ設定でさらに2000反復の微調整を行う（合計4000反復）．
  - 設定：$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題，50反復ごとに検証．
  - 検証seedは元の微調整と同じ（n3-d222は5000000，n3-d333は7600000，n4-d2222は8600000）．検証$\Delta J$が最良の反復の重みを採用する点も同じである．
  - 訓練seedは，元の微調整と別の値にする（n3-d222は6100000，n3-d333は7800000，n4-d2222は8800000）．同じ訓練問題を繰り返さないためである．
- 延長後の方策を，各系の試験問題（n3-d222は評価seed 9100000〜，n3-d333は9200000〜，n4-d2222は41000〜，各500問題）で評価する．
- 2000反復の方策と，`compare_runs.py`で比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

系ごとに判定する．

- 延長後−2000反復の，試験500問題での$\Delta J$の差が$-1.0$ポイント以下で，かつ95%区間が0を含まない → 2000反復では微調整が不足していた．
- 延長した2000反復のうち，検証$\Delta J$の最良が最後の500反復（反復3500以降）にある seed があれば，4000反復でも頭打ちでない可能性として報告する．
