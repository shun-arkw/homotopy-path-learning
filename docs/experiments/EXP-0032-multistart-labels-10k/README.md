## 2．目的

- EXP-0030（n4-d2222）で，件数が同じなら多点スタートの教師データの方が良く（質の効果），計算量が同じなら1回の探索で1万件を作る方が良かった（量の効果）．
- 質と量の両方をそろえた「多点スタートの1万件」で，1回の探索の1万件（EXP-0020の方策）をさらに上回るかを調べる．

## 3．多項式系

## 4．方法（事前登録）

### 4.1．教師データ

- 対象はEXP-0017の教師データと同じ1万問題（評価seed 8000000〜8009999）．
- 探索seed 0：EXP-0017の教師データ（予算500）．
- 探索seed 1〜4：評価seed 8000000〜8001999はEXP-0030の探索を使う．8002000〜8009999は新たに探索する（予算500，100問題ずつの分割）．
- 5回のうち，問題ごとにコスト$J$が最小の行動を教師とする（`best_of.py`）．

### 4.2．学習と評価

- 方策：attention（既定の大きさ）．教師あり学習は対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．
- 微調整はEXP-0030と同じ（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 8600000，訓練seed 8700000）．
- 比較相手：EXP-0020の方策（1回の探索の1万件，教師あり学習＋微調整2000反復）．EXP-0030の多点スタートの2000件の方策も参考に並べる．
- 試験問題：EXP-0020の試験500問題（評価seed 41000〜）．`compare_runs.py`で比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．到達率は，予算1000・探索seed 0のoracleと，多点スタートの試験oracle（EXP-0020の補足）の両方を分母として報告する．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整後の$\Delta J$の差（多点スタートの1万件−1回の探索の1万件，試験500問題）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → 教師データの質と量の効果は両立する．
- 参考：教師あり学習の段階の同じ差．多点スタートの1万件の教師データの平均$\Delta J$．
