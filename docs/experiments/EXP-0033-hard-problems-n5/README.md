# EXP-0033：線形パスで難しい問題と到達できる上限（n5）

> 本記録の1〜6節は，実験の実行前（2026-10-13 23:50 JST頃）に書いた事前登録である．結果を見た後に1〜6節を変更する場合は，変更した箇所と理由を明記する．

## 1．基本情報

- 実験ID：EXP-0033
- 状態：Planned（事前登録）
- 設定ファイル：
  - $d_b=2$：`experiments/multivariate_pham/configs/exp-0028-n5-d22222-db2.yaml`，`exp-0028-n5-d33333-db2.yaml`
  - $d_b=3$：`experiments/multivariate_pham/configs/exp-0033-n5-d22222-db3.yaml`，`exp-0033-n5-d33333-db3.yaml`（$d_b$以外は$d_b=2$と同じ）
- 実行環境：外部サーバ（GPU 4台のサーバ）の参照Docker`homotopy-continuation`．EXP-0028の教師データ（A）の終了後に開始する．教師あり学習はGPU，追跡はCPU．
- コード：seedリストのファイル，線形パスの選別，微調整の並列化（`docs/design/implementation/training_evaluation.md` 9節）を使う．

## 2．目的

- 追跡のステップ幅の上限（0.05）から，1パスあたりのステップ数は20以上である．n5-d22222では，下限での$\Delta J$は約$-61\%$，n5-d33333では約$-68\%$である．
- これまでの方策の$\Delta J$は，n3・n4で約$-25$〜$-34\%$，n5-d22222で$-20.9\%$（EXP-0031）である．事後の探索的な集計では，全系で，線形パスの$J$が大きい問題ほど削減率が大きかった．
- 本実験では，n5で次の2つを調べる．
  1. **到達できる上限：** 今の設定（係数パス，開始系，追跡の設定）で，強い探索を使うと，平均で50%削減に届くか．$d_b=2$と$3$で比べる．
  2. **線形パスで難しい問題の分布：** 線形パスの$J$が上位10%の問題だけからなる分布で，パイプライン（教師データ→教師あり学習→微調整）を行う．通常の分布で学習した方策（EXP-0031）より良くなるか．

## 3．多項式系

- n5-d22222：EXP-0031と同じ（$f_i=x_i^2+a_{i,1}x_1+\dots+a_{i,5}x_5+a_{i,6}$，32パス）．
- n5-d33333：次数が3であることを除き同じ（243パス）．
- 係数は実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．$d_b=2$の行動は60次元，$d_b=3$は120次元．

## 4．方法（事前登録）

### 4.1．難しい問題の選び方

- `screen_linear.py`で，連続したseedの候補について線形パスだけを追跡する．候補のseedは，n5-d22222が20000000から，n5-d33333が21000000からとする．
- `select_hard_seeds.py`で，seedの昇順に先頭5000個の候補から，線形パスの$J$の90パーセンタイルをしきい値とする．
- 残りの候補のうち，追跡に成功し，$J_{\mathrm{lin}}\ge$しきい値の問題を，seedの昇順に次の順で割り当てる．
  - 試験：500問題．
  - 検証：200問題．
  - 教師データ：10000問題．
  - 微調整の訓練：64000問題．
- n5-d33333は，まず試験と検証の分だけを選ぶ（4.4節）．後で候補を追加して選び直しても，先頭から割り当てるので，試験と検証は変わらない．これを確かめる．

### 4.2．到達できる上限（n5-d22222とn5-d33333）

- 問題：
  - 難しい問題：各系の難しい試験問題の先頭20問題．
  - 通常の問題：n5-d22222は評価seed 9520000〜9520019，n5-d33333は9510000〜9510019（EXP-0029と同じ）．
- 探索：全次元，予算3000，探索seed 0〜4の5回のうち，問題ごとに最良をとる（多点スタート）．$d_b=2$と$d_b=3$の両方で行う．
  - n5-d33333の通常の問題の$d_b=2$は，EXP-0029の結果を使う．
- 「上限の目安」は，問題ごとに，$d_b=2$と$3$の最良のうち良い方とする．

### 4.3．難しい問題の分布でのパイプライン（n5-d22222）

- 試験oracle：難しい試験500問題で，予算1000，探索seed 0〜4の多点スタート．到達率の分母にする．
- 教師データ：難しい教師データ用の1万問題で，予算500，探索seed 0の1回の探索（EXP-0031と同じ設定）．
- 教師あり学習：attention（既定の大きさ），対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．
- 微調整：2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$．
  - 訓練問題と検証200問題は，難しい問題のリストから取る．
  - 1 runあたり10ワーカーで並列に追跡する．
- 比較相手：EXP-0031のattention（教師あり学習のみ，および微調整後）．通常の分布で学習した方策である．
- 評価：
  - 難しい試験500問題：本実験の方策とEXP-0031の方策．
  - 参考：通常の試験500問題（評価seed 9520000〜）での本実験の方策．
- 比較は`compare_runs.py`で行う（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

### 4.4．条件つきの段階：難しい問題の分布でのパイプライン（n5-d33333）

- 4.3節の主基準（5節）を満たした場合に限り，n5-d33333でも同じパイプラインを行う．
- 変更点：
  - 試験oracleは，計算量のため，予算1000・探索seed 0の1回の探索とする．
  - 比較相手は，通常の分布で学習したn5-d33333のattention方策とする（別の実験として事前登録する予定）．
- 判断基準は5節の主基準と同じとする．

## 5．判断基準（実行前に固定）

- **上限（参考の判断）：** 系と問題の種類（難しい・通常）ごとに，上限の目安の平均$J$での$\Delta J$を報告する．
  - $-50\%$以下 → 今の設定で，その分布では平均50%削減に届く．
  - $-40\%$より大きい → 今の設定では50%削減は難しい．係数パスの形，開始系，追跡の設定の見直しを検討する．
  - あわせて，50%以上削減できた問題の数，$d_b=3$と$2$の差を報告する．20問題なので，差の判定はしない．
- **主基準（4.3節）：** 難しい試験500問題で，微調整後の$\Delta J$の差（本実験の方策−EXP-0031の方策）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → 難しい問題の分布で学習することは有効．
- **参考：**
  - 難しい試験500問題での，各方策の$\Delta J$，到達率，50%以上削減できた問題の割合．
  - 通常の試験500問題での，本実験の方策とEXP-0031の方策の差．
