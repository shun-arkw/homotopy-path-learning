## 2．目的

EXP-0012では，対称性拡張つきBCの到達率がn3-d222で約0.58（C2），n2-d33で約0.83まで上がったが，教師はoracleの行動であり，追跡コストそのものを最小化してはいない．そこで，BCで得た方策を，追跡コストを直接最小化して微調整し，到達率がさらに上がるかを調べる．推論は方策の順伝播1回と追跡1回のままである．

## 3．方法・設定

1ステップ問題なので，問題ごとにコスト比$r(\boldsymbol{a})=J(\boldsymbol{a})/J_{\mathrm{lin}}$の行動に関する勾配を，方策の平均$\boldsymbol{\mu}$まわりの対称な有限差分で推定する．$\boldsymbol{\varepsilon}_p\sim N(0,I)$，$\boldsymbol{a}^\pm_p=\mathrm{clip}(\boldsymbol{\mu}\pm\sigma\boldsymbol{\varepsilon}_p)$として，
$$\hat{\boldsymbol{g}}=\frac{1}{2\sigma P}\sum_{p=1}^P\bigl(r(\boldsymbol{a}^+_p)-r(\boldsymbol{a}^-_p)\bigr)\boldsymbol{\varepsilon}_p$$
とし，損失$\frac1B\sum_b\hat{\boldsymbol{g}}_b\cdot\boldsymbol{\mu}_\theta(\boldsymbol{s}_b)$（$\hat{\boldsymbol{g}}$は定数）を最小化する．`actor_mean`のみをAdamで更新する．BC項（$\lambda=$`--bc-weight`）を加える場合は，ラベルのミニバッチ（256件）に対称性拡張を施した二乗誤差を$\lambda$倍して加える．数学・実装の詳細は`docs/design/implementation/training_evaluation.md`にある．

共通設定：`--latent-dim full --batch-problems 32 --pairs 4 --learning-rate 1e-4 --train-seed 6000000 --val-seed 5000000 --val-instances 200 --val-interval 50`．訓練問題は反復ごとに新しいシード（`train_seed + (it-1)*B + b`）で生成する．検証（決定的方策，200問題）の$\Delta J$が最小の反復の重みを採用する（反復0を含む）．

- 段階1（パイロット）：n3-d222，初期方策seed 0，500反復，$\lambda=0$，$\sigma\in\{0.05,0.1,0.2\}$．事前に固定した規則：検証$\Delta J$の最良値が最も低い$\sigma$を選ぶ．同値なら小さい方．
- 段階2（本番）：n3-d222とn2-d33，初期方策seed 0,1,2，$\lambda\in\{0,1\}$（$\lambda=1$は`--augment-symmetry`と20シャードのラベルを用いる），2000反復，選ばれた$\sigma$．計12 run．

## 4．判断基準（実行前に固定）

- 微調整後の到達率が初期のBC方策より+0.05以上 → 微調整は有効
- λ=1がλ=0より+0.03以上 → BC項による正則化が有効
- 改善が+0.02未満 → 勾配推定の雑音が大きい（Pやσの見直しか，PPO型の手法を検討）

## 6．観察

- 追跡コストを使った微調整で，到達率は次のとおり上がった．
  - n3-d222：0.579から0.718（+0.139，$\Delta J$は$-15.04\%$から$-18.66\%$）
  - n2-d33：0.831から0.958（+0.127，$\Delta J$は$-25.31\%$から$-29.18\%$）
  - 両対象とも，3seedすべてで改善した．
- BC項による正則化（$\lambda=1$）は，正則化なし（$\lambda=0$）と差がなかった（n3-d222で$-0.011$，n2-d33で+0.002）．
- 検証$\Delta J$は2000反復でも下がり続けていた（n3-d222の$\lambda=0$で，1500反復の$-17.92\%$から2000反復の$-18.51\%$）．最良反復の多くは1450〜2000にあった．
- Positive rateは，微調整の前後でほとんど変わらなかった（n3-d222で0.91から0.90）．
- パイロットでは，$\sigma=0.05$と$0.1$がほぼ同等（検証$\Delta J$の差0.03ポイント）で，$0.2$はやや劣った．
- 計算量：本番1runあたり約57万回の追跡（2000反復×32問題×9回）を，12run同時実行で約20分で終えた．教師データ生成（約500万回）の1割強である．

## 7．考察

### 7.1．判断基準との照合

| 基準 | 結果 | 判断 |
|---|---|---|
| 到達率が初期のBC方策より+0.05以上 | n3-d222で+0.139，n2-d33で+0.127 | 該当：**微調整は有効** |
| $\lambda=1$が$\lambda=0$より+0.03以上 | $-0.011$，+0.002 | 非該当：正則化の効果はない |

### 7.2．なぜ微調整が効いたか

- EXP-0011・0012で，行動の二乗誤差（検証損失）は追跡コストと連動しないと分かっていた．教師あり学習は，コストに効かない方向の誤差まで等しく減らそうとする．一方，微調整はコストが下がる方向だけに方策を動かす．
- 同じ問題の中で対になる行動のコストを比べるため，問題ごとの難しさの違いが打ち消される．EXP-0007のPPOで問題になった「価値関数の崩壊」は，この手法では起こり得ない．
- 正則化が不要だったことから，初期方策から離れすぎて性能が崩れる現象は，2000反復の範囲では起きていない．

### 7.3．平均は改善したが，悪化する問題の割合は減っていない

- Positive rateがほぼ一定なので，微調整の改善は，すでに線形パスに勝っていた問題での上積みが中心と考えられる．
- n3-d222では，約1割の問題で線形パスより悪いままである．推論時に追跡せずにこれを避けるには，別の工夫（例えば，線形パスを使うべき問題を見分ける判定器）が要る．

### 7.4．oracleとの関係

- n2-d33の到達率0.958は，oracle（予算1000の直接探索）にほぼ並ぶ．
- oracleは有限回の探索による下界なので，学習した方策が平均でこれを上回る可能性もある．到達率が1に近づくと，oracleは上限の目安として機能しにくくなる．

### 7.5．これまでの到達点

| 手法 | n3-d222の$\Delta J$ | n2-d33の$\Delta J$ |
|---|---:|---:|
| PPO（$m=4$，EXP-0007，3seed平均） | $-2.1\%$ | $-10.2\%$ |
| BC（全次元，拡張，3層，5000エポック；EXP-0012） | $-15.0\%$ | $-25.3\%$ |
| ＋追跡コストによる微調整（本実験） | **$-18.7\%$** | **$-29.2\%$** |
| oracle（全次元，予算1000） | $-26.0\%$ | $-30.5\%$ |

推論時の計算は，どれも方策の順伝播1回と追跡1回で同じである．

### 限界

- 2000反復でも検証$\Delta J$は下がり続けており，飽和していない．
- 規模はn3-d222とn2-d33の小規模系のみである．
- 同じ全次元の条件でのPPOとの比較は，EXP-0015で実施中である．
- 評価は100問題のため，到達率が1に近い領域では差の判別が難しい．

## 9．結論

- 拡張つき教師あり学習の方策を初期値に，追跡コストを直接使って微調整すると，到達率はn3-d222で0.72（$\Delta J=-18.7\%$），n2-d33で0.96（$\Delta J=-29.2\%$）に上がった．判断基準の「有効」に該当する．
- BC項による正則化は不要だった．
- 現在の標準パイプラインは，次の3段階とする．
  1. oracleによる教師データの生成（全次元）
  2. 対称性による拡張つき教師あり学習（3層，5000エポック）
  3. 追跡コストによる微調整（$\sigma=0.05$，$P=4$，$B=32$，$\lambda=0$）

## 10．次の実験

1. **微調整の延長**（低コスト）：2000反復でも改善が続いているため，反復数を増やす（例：5000〜10000）．
2. **全次元の条件でのPPOとの比較**（EXP-0015，実行中）：教師あり学習＋微調整の優位が，行動空間の違いだけによるものでないかを確かめる．
3. **規模拡大**（EXP-0014，予備調査中）：予備調査の結果を見て，n3-d333，n4-d2222に標準パイプラインを適用する．
4. **悪化する問題への対策**：線形パスより悪くなる約1割の問題を，推論時に追跡せずに見分ける方法を検討する．
