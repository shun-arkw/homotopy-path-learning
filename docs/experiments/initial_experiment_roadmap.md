## EXP-0001：Julia多変数追跡のsmoke test

目的は，$n=2$，$(d_1,d_2)=(2,2)$の固定サポート系について，開始解4個から全パスを追跡できることを確認することである．PPOは使用しない．

状態：`julia/test/test_tracking.jl`（`sequential tracking smoke`，`public API tracking smoke`）で確認済み．

## EXP-0002：ゼロ行動と線形パスの一致確認

目的は，線形補間上に制御点を配置したベジェ曲線が，線形係数パスと同じ端点，解，追跡統計を与えることを確認することである．

状態：`tests/integration/test_julia_backend.py::test_zero_latent_action_matches_linear_control_points_tracking`で確認済み．

## EXP-0003：ランダム係数100問題の安定性確認

目的は，固定サポート上で100個程度の目的系を生成し，全パス追跡の成功率，残差，ステップ数分布を確認することである．

状態：`tests/integration/test_bezier_pham_env_integration.py`のランダム行動100エピソードのsmoke testで確認済み．また，EXP-0005〜0007の各問題設定では，本番学習前の事前チェックとして線形パスの追跡成功率（100件）を確認している．

## EXP-0004：短時間PPO学習

目的は，1ステップ環境とPPOの接続を確認し，学習，チェックポイント保存，評価までの一連の処理が完了することを確認することである．性能改善は主目的としない．

## EXP-0005：線形パスとの性能比較

目的は，固定評価データセットに対して，学習済みベジェパスが線形パスより追跡コストを削減できるか確認することである．

実施内容：$n=2,(2,2)$で実施．当初の比較（`bound`と学習ステップ数を同時に変更）に加え，両者の2×2要因分離を行った（記録の16，17節）．

## EXP-0006：ベジェ次数の比較

$d_b\in\{2,3,4\}$を比較する．各条件で潜在次元，学習予算，評価データを可能な限り揃える．

実施内容：n2-d22（$b=3.0$），n2-d33（$b=1.0$），n2-d33（$b=3.0$）の3つのベースで比較した（記録の1〜10節）．各条件1seedのみで，3seedでの再検証は未実施．

## EXP-0007：変数数または次数の拡大

次のいずれかを実施する．

- $n=3$，$(d_1,d_2,d_3)=(2,2,2)$
- $n=2$，$(d_1,d_2)=(3,3)$

変数数増加と次数増加を同時に行わず，計算量増加の要因を分離する．

実施内容：両方を3seedで実施した．さらに，次数拡大の継続（n2-d44，n2-d55，n2-d66）と，n3-d222の不安定さの原因調査（学習量拡大，entropy正則化，ネットワーク容量拡大，観測次元の分離）を追加した（記録の14〜19節）．
