# 初期実験ロードマップ

## EXP-0001：Julia多変数追跡のsmoke test

目的は，$n=2$，$(d_1,d_2)=(2,2)$の固定サポート系について，開始解4個から全パスを追跡できることを確認することである．PPOは使用しない．

## EXP-0002：ゼロ行動と線形パスの一致確認

目的は，線形補間上に制御点を配置したベジェ曲線が，線形係数パスと同じ端点，解，追跡統計を与えることを確認することである．

## EXP-0003：ランダム係数100問題の安定性確認

目的は，固定サポート上で100個程度の目的系を生成し，全パス追跡の成功率，残差，ステップ数分布を確認することである．

## EXP-0004：短時間PPO学習

目的は，1ステップ環境とPPOの接続を確認し，学習，チェックポイント保存，評価までの一連の処理が完了することを確認することである．性能改善は主目的としない．

## EXP-0005：線形パスとの性能比較

目的は，固定評価データセットに対して，学習済みベジェパスが線形パスより追跡コストを削減できるか確認することである．

## EXP-0006：ベジェ次数の比較

$d_b\in\{2,3,4\}$を比較する．各条件で潜在次元，学習予算，評価データを可能な限り揃える．

## EXP-0007：変数数または次数の拡大

次のいずれかを実施する．

- $n=3$，$(d_1,d_2,d_3)=(2,2,2)$
- $n=2$，$(d_1,d_2)=(3,3)$

変数数増加と次数増加を同時に行わず，計算量増加の要因を分離する．
