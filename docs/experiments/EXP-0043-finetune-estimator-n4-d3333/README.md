## 2．目的

- 現在の微調整（$K=32$目的系，$P=4$対，$\sigma=0.05$，学習率$10^{-4}$，2000反復）では，検証$\Delta J$が最良になる反復は1100，1300，1250（EXP-0038の3seed，`metadata.json`の`best_iteration`）で，seed 0の検証曲線は反復600以降$-29.3\%$〜$-30.7\%$の範囲で揺らぎ，明確な傾向がない（`val_metrics.csv`）．訓練バッチのコスト比は2000反復で0.732から0.725へ0.7ポイントしか動かない（`finetune_metrics.csv`）．
- 推定量（対称な有限差分）の目的系ごとの分散は，コストが行動の線形関数という近似のもとで$\|\nabla r\|^2(A+1)/P$（$A=40$，$P=4$で信号の約10倍，信号対雑音比約0.3）と見積もられる（推定値．整数の$J$による量子化の雑音は含まない）．また$\sigma=0.05$の等方摂動はラベルで$J$を約2.1ポイント悪化させ（$\sigma=0.025$では0.7．学習データ先頭100目的系での実測），平滑化された目的関数の最小点が真の谷底からずれると考えられる（ずれの大きさは直接は測っていない）．
- 摂動対の数$P$を増やす（分散を減らす）ことと，$\sigma$を小さくする・減衰させる（平滑化のずれを減らす）ことの効果を測る．

## 4．方法

## 5．判断基準（実行前に固定）

**第1段（開発集合，500目的系）：** 微調整後の$\Delta J$の差（腕−基準線）が$-1.0$ポイント以下，かつ95%区間が0を含まない腕を候補とする．4腕（B5を実行した場合は5腕）を独立に判定し，補正は行わない（明記する）．

**採用する腕の選択（開発集合）：** 候補のうち，追跡数が基準線と同じ腕（B1，B3，B5）を優先する．その中で改善が最も大きい腕を選び，差が0.5ポイント以内ならコード変更が不要な腕（B1，B5）を優先する．追跡数4倍の腕（B2，B4）だけが候補の場合は，「同じ追跡数で反復を4倍にした場合」と比べる追加実験（EXP-0024の延長と同型）を組んでから採用を決め，本実験では第2段に進まない．

**第2段（試験集合，500目的系，1回だけ）：** 選んだ腕だけを基準線と比べ，同じ規則を満たせば標準手順に採用する．第1段で候補がなければ試験集合は使わない．EXP-0042とEXP-0043で合計2回の試験集合の使用になることを明記する．

**組み合わせについて：** 本実験で採用した腕とEXP-0042で採用した腕を同時に使う構成（A＋B）は，本実験とEXP-0042だけでは採用しない．組み合わせの確認は，別に予約した第2の試験集合（seed 9320000〜9320499，500目的系，未使用を確認済み）で，EXP-0038の第1周の基準線に対して同じ規則により**1回だけ**行う（`docs/design/drafts/2026-10-15-label-consistency-finetune/`docs/design/drafts/2026-10-15-label-consistency-finetune/summary.md`` 3.1節の事前宣言の追試験）．

**副次的な比較（開発集合のみ，記述的，採用の判断には使わない）：**

- B4−B2：$P=16$で$\sigma$を0.05から0.025にした効果（$\sigma$の分離）．
- B2−基準線：追跡数4倍での$P$の効果（$P$の分離）．
- B1−B2：同じ$P$で目的系数$K$を1/4にした効果．

**否定的な結果の読み方：** 第1段で候補がなければ，「試した範囲（$P\le16$，$\sigma\in[0.02,0.05]$）では$P$と$\sigma$は主要な要因ではない」と結論する．これは「汎化が律速」を意味しない．残る可能性は，歩幅・反復数（EXP-0041のD4-cで切り分ける），効果が1ポイント未満であること，検証200目的系での反復選択の揺らぎ（±0.5ポイント）である．

## 6．中断の条件

- 検証$\Delta J$が反復0から5ポイント以上悪化（発散）．B5は学習率が大きいので発散しうる．発散した腕は止め，他は続ける．
- 損失の発散，追跡失敗が1%を超えた場合．
- 外部サーバの環境確認でコストが一致しない場合は，B2・B4を始めない．
- 4.3の確認で一致しない場合は，B3を始めない．
- 判断基準を結果を見てから変えない．
