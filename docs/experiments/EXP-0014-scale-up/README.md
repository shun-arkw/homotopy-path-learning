## 2．目的

EXP-0010〜0013で整えた標準パイプライン（フル潜在oracleのラベル → 対称性拡張つきBC → 追跡コストの直接最小化による微調整）が，パス数の多い系（n3-d333）と，変数数の多い系（n4-d2222）に拡大しても機能するかを調べる．対称性の群は系が大きいほど大きくなる（拡張の効果も大きくなると予想される）．

## 3．方法・設定

### 3.1．予備oracle

各系で，評価seed（38000〜38099，39000〜39099）の100問題に対し，フル潜在空間で予算$B=3000$のoracleを実行した（`--budget 3000`，4 shard×25問題）．この結果を連結して比較用のoracleとする．到達率の基準は，予算3000のoracleと，各問題のoracleコストの先頭1000評価の最小値（以下$B=1000$）の2通りで求める．

### 3.2．ラベル

`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0 --num-instances 500`を20 shard（計10000問題）．評価seedの基点はn3-d333が7000000，n4-d2222が8000000．

### 3.3．BC

`behavior_cloning.py --latent-dim full --hidden-sizes 256,256,256 --epochs 5000 --batch-size 256 --learning-rate 1e-3 --val-fraction 0.1`．対称性拡張あり（`--augment-symmetry`，seed 0,1,2）と，拡張なし（seed 0）．

### 3.4．微調整

`finetune.py --latent-dim full`．初期方策は拡張ありBCの各seed．`--iterations 2000 --batch-problems 32 --pairs 4 --sigma 0.05 --learning-rate 1e-4 --bc-weight 0 --seed s --val-instances 200 --val-interval 50`．検証seedはn3-d333が7600000，n4-d2222が8600000，訓練seedはそれぞれ7700000，8700000．EXP-0013で選んだ$\sigma=0.05$をそのまま用いた．

## 4．判断基準（実行前に固定，$B=1000$基準）

- 両系で，微調整後の到達率が0.6以上 → パイプラインは規模拡大に耐える
- 拡張ありBCの到達率が拡張なしより+0.10以上 → 群が大きい系でも対称性の効果が大きい
- 微調整後の到達率が0.4未満 → 規模拡大でボトルネックが生じた（BCと微調整のどちらが伸びていないかで原因を切り分ける）

## 6．観察

- 予備調査のoracleの改善余地は，n3-d333，n4-d2222ともに約$-28.5\%$（予算3000）で，n3-d222（$-28.5\%$）と同程度だった．線形パスの追跡成功率は両系とも100%で，oracleの収束の速さもn3-d222とほぼ同じだった．
- n3-d333（27パス）では，微調整後の到達率が0.732（$\Delta J=-19.17\%$）になった．n3-d222の同じ段階（EXP-0013，0.718，$-18.66\%$）と同等以上である．
- n4-d2222（4変数）では，微調整後の到達率は0.447（$\Delta J=-11.10\%$）にとどまった．教師あり学習の段階で0.347と低く，微調整による上積み（+0.100）はn3-d333（+0.103）と同程度だった．
- 対称性による拡張の効果は，n3-d333で+0.171，n4-d2222で+0.178（seed0）だった．
- 微調整の検証$\Delta J$は，両系とも2000反復でも下がり続けていた．拡張ありの教師あり学習も，最良エポックが4311〜4999で飽和していない．

## 7．考察

### 7.1．判断基準との照合（予算1000のoracle基準）

| 基準 | 結果 | 判断 |
|---|---|---|
| 両系で微調整後の到達率が0.6以上 | n3-d333は0.732，n4-d2222は0.447 | 非該当（n3-d333のみ該当） |
| 拡張ありが拡張なしより+0.10以上 | +0.171，+0.178 | 該当：群が大きい系でも対称性の効果が大きい |
| 微調整後の到達率が0.4未満 | n4-d2222は0.447（予算3000基準では0.389） | 非該当だが境界に近い |

- 次数の拡大（n3-d333）には，パイプラインがそのまま通用した．
- 変数の数の拡大（n4-d2222）では，性能が下がった．

### 7.2．n4-d2222で何が律速か

- 微調整の上積みは他の系と同程度なので，律速は教師あり学習の段階である．
- 行動は80次元，観測は40次元で，n3系（48次元，24次元）より写像が大きい．教師データ1万件は同じなので，入力次元あたりのデータは少ない．
- 教師あり学習も微調整も飽和していないため，学習量を増やす余地は残っている．
- 行動の次元を下げる方法として，ベジェ次数$d_b=2$（行動40次元）が候補になる．n3-d222では$d_b=2$の方が良かった（EXP-0016）．これをEXP-0017で検証する．

### 7.3．対称性の効果と群の大きさ

| 系 | 対称群の大きさ | 拡張の効果（到達率） |
|---|---:|---:|
| n3-d222（EXP-0011，1500エポック） | 96 | +0.149 |
| n3-d333 | 324 | +0.171 |
| n4-d2222 | 768 | +0.178 |

- 群が大きいほど効果が大きい傾向がある．ただし，学習条件（エポック数，seed数）が揃っていないため，傾向の目安にとどめる．
- 拡張なしの最良エポックは，n3-d333で28，n4-d2222で10と非常に早かった．拡張なしでは，すぐに過学習が始まっていることを示す．

### 限界

- seedは3つ，評価は100問題である．
- 予算3000のoracleは予算1000より強く，予算1000基準の到達率は予算3000基準より0.04〜0.06高く出る．判断基準は，n3-d222と比べるため予算1000基準とした．
- 教師あり学習・微調整とも飽和しておらず，各系の上限には達していない．

## 9．結論

- 標準パイプライン（教師データ→拡張つき教師あり学習→微調整）は，次数を上げたn3-d333（27パス）でも機能し，到達率0.73（$\Delta J=-19.2\%$）に達した．
- 4変数のn4-d2222では到達率0.45（$\Delta J=-11.1\%$）にとどまり，事前の基準（両系で0.6以上）は満たさなかった．律速は教師あり学習の段階である．
- 対称性による拡張の効果は，群が大きい系でも大きい（+0.17〜0.18）．

## 10．次の実験
