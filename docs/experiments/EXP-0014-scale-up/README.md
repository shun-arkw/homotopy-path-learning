## 記号と指標

- $J$：1問題の追跡コスト．全解パスについての$N_{\mathrm{acc}}+\rho N_{\mathrm{rej}}$の平均（$N_{\mathrm{acc}}$は受理ステップ数，$N_{\mathrm{rej}}$は棄却ステップ数，$\rho=1$）．追跡に失敗したパスには失敗ペナルティ$10^5$を課す．
- $J_{\mathrm{lin}}$：線形パス（制御点を開始系と目的系の線形補間に置いたパス．行動ゼロに等しい）の$J$．
- $\Delta J$：線形パスに対する平均追跡コストの変化率．$\Delta J=(\overline{J}_{\text{手法}}-\overline{J}_{\mathrm{lin}})/\overline{J}_{\mathrm{lin}}\times100$（%）．$\overline{J}$は対象の問題集合での平均．負の値が改善．
  - 「$\Delta J$」：評価100問題での値．
  - 「検証$\Delta J$」：検証200問題での値（微調整のモデル選択用）．
- Positive rate：評価100問題のうち，その手法の$J$が線形パスの$J$より小さかった問題の割合．
- 成功率：追跡に失敗しなかった評価問題の割合．
- 到達率：$(\overline{J}_{\mathrm{lin}}-\overline{J}_{\text{手法}})/(\overline{J}_{\mathrm{lin}}-\overline{J}_{\mathrm{oracle}})$．oracleの改善量のうち手法が得た割合．本記録では，基準のoracleを「フル潜在，予算$B=3000$」と「フル潜在，予算$B=1000$」の2通りで求め，表の見出しに併記する．1を超えるのは，手法の$J$が基準のoracleより小さいことを意味する．到達率の差は「+0.171」のように単位のない数で表す．
- oracle：学習を使わず，評価問題ごとに行動を直接探索した結果（ゼロ行動，一様乱数，(1+1)進化戦略）．有限回の探索なので改善余地の下界．
- 予算$B$：oracleが1問題に使う試し追跡の回数（最初の100回はゼロ行動と一様乱数）．「予算$B$での値」は最初の$B$回の中の最良値．本記録の評価100問題の予備oracleは$B=3000$まで実行し，$B=1000$の値は先頭1000回の最小値で求める．教師データ（ラベル）は$B=500$である．
- $n$，$d_i$，$N_{\mathrm{path}}=\prod_i d_i$：変数の数，方程式$i$の次数，追跡する解パスの数．系の名前（例：n3-d333）は「変数の数3，次数(3,3,3)」を表す．
- $a_{i,j}$，$b$：目的系の係数と，その生成範囲（実部・虚部を$[-b,b]$の一様分布から生成．本記録では$b=1.0$）．
- $D_{\mathrm{free}}$：自由な（先頭以外の）複素係数の個数．観測は$2D_{\mathrm{free}}$次元の実ベクトル（n3-d333で24次元，n4-d2222で40次元）．
- $d_b$：ベジェ曲線の次数．制御点は$d_b+1$個で，両端（開始系と目的系）は固定，中間の$d_b-1$個を行動で動かす．本記録では$d_b=3$（7.2節と10節で$d_b=2$に言及する）．
- $m$：潜在次元（中間制御点1つあたりの行動の次元）．「全次元（full）」は$m=2D_{\mathrm{free}}$（本記録では全run）．行動の次元は$(d_b-1)m$で，n3-d333で48，n4-d2222で80．
- BC：行動模倣（behavior cloning）．oracleの最良行動を正解とする教師あり学習．「拡張あり／なし」は，学習中に問題族の対称群の元を作用させて観測と行動を変換するか否か．
- 対称群の大きさ：問題族に作用する変換（変数と方程式の同時置換，各変数への1の冪根のスケーリング，係数の複素共役）の元の数．
- 微調整：BCの方策を初期値に，追跡コストを直接下げる学習（EXP-0013の方法）．
  - $\sigma$：摂動の大きさ．
  - $P$（`--pairs`）：1問題あたりの対の摂動の数．
  - $\lambda$（`--bc-weight`）：BC項の重み．本記録では$\lambda=0$（BC項なし）．
  - $K$（`--batch-problems`）：微調整の1反復あたりの訓練問題数．本記録では$K=32$．
- 最良epoch／反復：BCでは検証損失が最小のエポック，微調整では検証$\Delta J$が最小の反復．評価にはその重みを使う．
- 検証損失：教師データのうち検証用10%での，BCの出力と教師行動の二乗誤差の平均．
- seed：学習seed（BCの初期値とミニバッチ）を指す．微調整のseedは初期方策のBCのseedと一致させる．基底seed，探索seed（oracleの乱数）とは別である．
- 評価問題：各系で固定した100問題（評価seedは設定ファイルの`evaluation.seed`から連番）．検証問題（微調整のモデル選択用，200問題）や，訓練問題（微調整で反復ごとに生成する問題），教師データ（フル潜在ラベル1万件）と区別する．

## 2．目的

EXP-0010〜0013で整えた標準パイプライン（フル潜在oracleのラベル → 対称性拡張つきBC → 追跡コストの直接最小化による微調整）が，パス数の多い系（n3-d333）と，変数数の多い系（n4-d2222）に拡大しても機能するかを調べる．対称性の群は系が大きいほど大きくなる（拡張の効果も大きくなると予想される）．

## 3．方法・設定

### 多項式系

**n3-d333**（$n=3$，次数$(3,3,3)$，$N_{\mathrm{path}}=27$，観測次元24）

- 開始系 $G=\{g_1,g_2,g_3\}$：
  $$g_1=x_1^3-1,\qquad g_2=x_2^3-1,\qquad g_3=x_3^3-1$$
- 目的系 $F=\{f_1,f_2,f_3\}$：
  $$f_1=x_1^3+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}x_3+a_{1,4}$$
  $$f_2=x_2^3+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}x_3+a_{2,4}$$
  $$f_3=x_3^3+a_{3,1}x_1+a_{3,2}x_2+a_{3,3}x_3+a_{3,4}$$

**n4-d2222**（$n=4$，次数$(2,2,2,2)$，$N_{\mathrm{path}}=16$，観測次元40）

- 開始系 $G=\{g_1,g_2,g_3,g_4\}$：
  $$g_1=x_1^2-1,\qquad g_2=x_2^2-1,\qquad g_3=x_3^2-1,\qquad g_4=x_4^2-1$$
- 目的系 $F=\{f_1,f_2,f_3,f_4\}$：
  $$f_1=x_1^2+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}x_3+a_{1,4}x_4+a_{1,5}$$
  $$f_2=x_2^2+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}x_3+a_{2,4}x_4+a_{2,5}$$
  $$f_3=x_3^2+a_{3,1}x_1+a_{3,2}x_2+a_{3,3}x_3+a_{3,4}x_4+a_{3,5}$$
  $$f_4=x_4^2+a_{4,1}x_1+a_{4,2}x_2+a_{4,3}x_3+a_{4,4}x_4+a_{4,5}$$

係数$a_{i,j}$は問題ごとに異なる．実部と虚部を，それぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数は1に固定する．

### 3.1．予備oracle

各系で，評価seed（38000〜38099，39000〜39099）の100問題に対し，フル潜在空間で予算$B=3000$のoracleを実行した（`--budget 3000`，4 shard×25問題）．この結果を連結して比較用のoracleとする．到達率の分母のoracleは，予算$B=3000$のoracleと，各問題のoracleコストの先頭1000評価の最小値（以下$B=1000$のoracle）の2通りで求める．

### 3.2．ラベル

`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0 --num-instances 500`を20 shard（計10000問題）．評価seedの基点はn3-d333が7000000，n4-d2222が8000000．

### 3.3．BC

`behavior_cloning.py --latent-dim full --hidden-sizes 256,256,256 --epochs 5000 --batch-size 256 --learning-rate 1e-3 --val-fraction 0.1`．対称性拡張あり（`--augment-symmetry`，seed 0,1,2）と，拡張なし（seed 0）．

### 3.4．微調整

`finetune.py --latent-dim full`．初期方策は拡張ありBCの各seed．$K=32$（`--batch-problems 32`），$P=4$（`--pairs 4`）．`--iterations 2000 --batch-problems 32 --pairs 4 --sigma 0.05 --learning-rate 1e-4 --bc-weight 0 --seed s --val-instances 200 --val-interval 50`．検証seedはn3-d333が7600000，n4-d2222が8600000，訓練seedはそれぞれ7700000，8700000．EXP-0013で選んだ$\sigma=0.05$をそのまま用いた．

## 4．判断基準（実行前に固定，到達率は分母を$B=1000$のoracleとする．評価100問題．微調整後の到達率は3seed平均，拡張の効果はseed 0どうしの比較）

- 両系で，微調整後の到達率が0.6以上 → パイプラインは規模拡大に耐える
- 拡張ありBCの到達率が拡張なしより+0.10以上大きい → 群が大きい系でも対称性の効果が大きい
- 微調整後の到達率が0.4未満 → 規模拡大でボトルネックが生じた（BCと微調整のどちらが伸びていないかで原因を切り分ける）

注：分母を$B=1000$のoracleとする方針は，主実験の実行前に計画で決めたが，予備oracle（$B=3000$）の結果を見た後である．分母の選び方で基準3の判定が変わりうる（7.1節）．

## 6．観察

- 予備調査のoracle（フル潜在，予算$B=3000$）の$\Delta J$は，評価100問題で，n3-d333が$-28.54\%$，n4-d2222が$-28.53\%$であり，n3-d222（EXP-0009，$-28.49\%$）と同程度だった．線形パスの追跡成功率は両系とも1.00だった．oracleの収束の速さは，$B=3000$の値は同程度だが，$B=300$までは新しい2系の方が遅かった（$B=100$：n3-d222 $-2.0\%$に対しn3-d333 $-0.2\%$，n4-d2222 $-0.4\%$．$B=300$：$-24.7\%$に対し$-23.0\%$，$-22.3\%$）．$B=1000$でもn4-d2222は約1ポイント浅かった（n3-d222 $-26.0\%$，n3-d333 $-26.2\%$，n4-d2222 $-24.8\%$）．（n3-d222の値はEXP-0016 5.1節のEXP-0009の行．）
- n3-d333（27パス）では，微調整後の到達率（分母はOracle $B=1000$，評価100問題，3seed平均）が0.732（$\Delta J=-19.17\%$）になった．n3-d222の同じ段階（EXP-0013，0.718，$\Delta J=-18.66\%$，分母はEXP-0009のOracle $B=1000$）と同程度である（優劣は言えない）．系・評価問題・oracleの実行が異なり，seedごとの範囲も重なる（n3-d333は0.720〜0.739，n3-d222は0.708〜0.738）．

## 7．考察

### 7.1．判断基準との照合（到達率の分母は予算$B=1000$のoracle）

| 基準 | 結果 | 判断 |
|---|---|---|
| 両系で微調整後の到達率が0.6以上 | n3-d333は0.732，n4-d2222は0.447 | 基準1は未達（n4-d2222）．n3-d333のみ該当 |
| 拡張ありの到達率が拡張なしより+0.10以上大きい | +0.171，+0.178（seed 0同士） | 該当：群が大きい系でも対称性の効果が大きい |
| 微調整後の到達率が0.4未満 | n4-d2222は0.447（分母を$B=3000$のoracleとすると0.389） | 分母が$B=1000$では非該当，$B=3000$では該当．判定は分母の選び方に依存する |

- 次数の拡大（n3-d333）には，パイプラインがそのまま通用した．
- n4-d2222では到達率が低かった．変数の数，観測次元（40），行動次元（80），パス数（16），次数が同時にn3-d222から変わっており，原因は特定していない．

### 7.2．n4-d2222で何が律速か

- 微調整による到達率の上積みの絶対値は他の系と同程度（+0.100と+0.103）だが，BCが取り残した改善余地に対する上積みの割合は，n4-d2222の方が小さい（約0.15，n3-d333は約0.28，6節の計算）．この見方では，教師あり学習の段階の不足が示唆される．ただし，ラベル数やエポック数を変えた対照実験は行っておらず，確かめていない．
- n4-d2222の行動は80次元，観測は40次元で，n3系（行動48次元，観測24次元）より写像が大きい．教師データ1万件は同じなので，入力次元あたりのデータが少ないことが原因かもしれない．これは仮説であり，確かめていない．
- 教師あり学習も微調整も飽和していないため，学習量を増やす余地は残っている．
- 行動の次元を下げる方法として，ベジェ次数$d_b=2$（行動40次元）が候補になる．n3-d222では，$d_b=2$の方がΔJ（線形パス基準，3seed平均）が良かったが，$d_b$ごとにoracleの基準が異なる（EXP-0016）．その後のEXP-0017（n4-d2222，$d_b=2$）では，ΔJは上がった（微調整後$-13.60\%$，本記録の$d_b=3$は$-11.10\%$）が，自身のoracleに対する到達率は約0.46で本記録（0.447）とほぼ変わらなかった．これは教師あり学習の段階の不足と矛盾しないが，その証明ではない．また，EXP-0018（n4-d3333）では，$d_b=2$のoracleの優位は見られなかった．

### 7.3．対称性の効果と群の大きさ

| 系 | 対称群の大きさ（元の数） | 拡張の効果（拡張あり−拡張なしの到達率，分母はOracle full，$B=1000$） |
|---|---:|---:|
| n3-d222（EXP-0011，1500エポック） | 96 | +0.149 |
| n3-d333 | 324 | +0.171 |
| n4-d2222 | 768 | +0.178 |

- 3点（+0.149，+0.171，+0.178）は，seed 0・評価100問題の値で，0.03程度の差はノイズの範囲内である．n3-d222はEXP-0011の1500エポック（本記録は5000エポック）でエポック数が異なり（EXP-0011で再確認中），群の大きさは系の大きさとも交絡している．よって「群が大きいほど効果が大きい」という傾向は確立していない．いずれの系でも拡張の効果は+0.15以上と大きい，という範囲に限って言える．
- 拡張なしBCの最良epochは，n3-d333で28，n4-d2222で10と非常に早かった．拡張なしでは，すぐに過学習が始まっていることを示す．

### 限界

- seedは3つ，評価は100問題である．評価は固定の評価100問題・3seedで，同じ評価問題を複数の比較に繰り返し使っている．評価問題上で選んだ最良構成の値は楽観的になりうる．1ポイント前後の差は判別できない．
- 予算$B=3000$のoracleは$B=1000$より強く，分母を$B=1000$にした到達率は$B=3000$にした到達率より0.03〜0.06大きく出る（拡張なしBCで0.025〜0.038，他の手法で最大0.06）．判断基準は，n3-d222と比べるため分母を$B=1000$のoracleとした．
- 教師あり学習・微調整とも飽和しておらず，各系の上限には達していない．
