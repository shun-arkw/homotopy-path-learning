## 2．目的

- 問い：目的系を低次元の部分空間（族）に限ると，学習（教師あり学習と微調整）は易しくなるか．同じ$k$で変数の数を増やすと（n4→n5，同じ各3次），学習の質はどう変わるか．
- EXP-0060で分かったこと：
  - 族の基底の探索は，全次元の探索より改善量が大きい（$k$=4で1.25〜1.40倍）．
  - 族の目的系そのものは易しくない．線形パスの平均ステップ数も，全次元の探索の改善量も，$k$によらず一般（ガウス）とほぼ同じ（n4-d3333で17.8〜19.4%対18.6%，n5-d33333で11.7〜13.0%対12.2%）．
- 2つの見方で測る．
  1. **教師あり学習（模倣）の効率**：教師データを作ったのと同じ探索で得られる改善量のうち，ネットワークが未知の目的系で1回の推論でどれだけ再現できるか（指標1）．教師データの質（族の基底の方が良い）の違いは分母で割り引く．ただし，高次元の探索で作った教師データが目的系の関数として一貫しにくいこと（教師データの雑音）も含めた「手順全体の易しさ」であり，ネットワークの表現力だけの違いではない．
  2. **最終的な質**：微調整の後の削減率．EXP-0060で線形パスと全次元の探索の改善量が族と一般（ガウス）で同じくらいと分かっているので，すべての設定で共通の物差し$O_{\text{全次元}}(1000)$で割った値（指標2）で比べる．
- 主張の範囲：結果は「ランダムな$k$次元の部分空間で決まる系の族」についてのものであり，一般の目的系には転用できない．教師データの予算（300）と追跡の設定（新しい追跡の設定）がEXP-0055〜0058と違うので，削減率の絶対値はそれらと比べない．

## 4．方法（事前登録）

### 4.1．比べる設定（系の種類ごと）

| 設定 | 目的系 | 行動 | 対称性による拡張 | 教師データ | ネットワークのseed |
|---|---|---|---|---|---|
| 族$k$（$k$=4，8，12，16） | 族（$W$ 3つ） | 族の基底（潜在次元$2k$） | なし | その族，族の基底の探索 | $W$ごとに0，1 |
| 一般（ガウス） | $k=m$ | 全次元の行動 | なし | 一般（ガウス），全次元の探索 | 0，1，2 |
| 一般（ガウス）・拡張あり | $k=m$ | 全次元の行動 | 教師あり学習だけ | 一般（ガウス）と共通 | 0，1，2 |
| 族$k$=8・全次元の行動 | 族$k$=8，$W$ 0 | 全次元の行動 | なし | 同じ族，全次元の探索 | 0，1，2 |

- 微調整の拡張は教師データの項だけに効き，本実験の微調整は教師データの項を使わない（$\lambda=0$）ので，拡張は教師あり学習だけになる．
- 族$k$=8・全次元の行動は，「目的系を絞る効果」と「行動を絞る効果」を分けるための設定．
- 教師データの数の曲線：族$k$=4（$W$ 0），族$k$=8（$W$ 0），一般（ガウス）で，教師あり学習だけを$N$=1000，3000，9000で行う（seed 0）．$N$個は分割の先頭から取り，検証は3つの$N$で共通の固定した1000個（教師データの最後の1000個）．エポック数は更新回数が本体（1万個の90%で300エポック）とそろうように，2700，900，300．$N$=9000は，本体のseed 0とほぼ同じ学習（検証の取り方だけが違う）になる．
- run の数（系の種類ごと）：教師あり学習33＋曲線9＝42，微調整33．2つの系の種類で，教師あり学習84，微調整66．

### 4.6．評価と報告する値（`evaluate.sh`は外部サーバ，`summary.py`はメインの環境）

- 評価：開発集合（n4-d3333，n5-d33333とも500個）で，教師あり学習の後と微調整の後のすべてのrunを，新しい追跡の設定で評価する（`eval_family.py`．線形パス，参照の解，失敗，取りこぼし）．テストデータは，開発集合での判断を7節に書いた後に1回だけ評価する．
- 除外の規則（EXP-0060と同じ）：参照の解が条件を満たさない（`ref_ok`=0）か，線形パスで追跡に失敗したパスがある目的系は，その族のすべての値から除く．除外の数は記録する．
- **指標1（教師あり学習の効率．判定に使う）**：$M_1=$教師あり学習の後の削減率$/O_{\text{自分}}(300)$（開発集合）．分母は教師データを作ったのと同じ探索．
- **指標2（微調整の後の質．判定に使う）**：$M_2=$微調整の後の削減率$/O_{\text{全次元}}(1000)$（開発集合．族の基底の設定でも全次元の探索の値）．
- テストデータでも，分母は開発集合の値を使う．
- そのほか（記述）：$O_{\text{自分}}(1000)$に対する微調整の後の削減率の比，$O_{\text{全次元}}(300)$に対する教師あり学習の後の削減率の比，教師データの改善量（訓練の目的系），削減率（教師あり学習の後，微調整の後．ネットワークごとの値も），失敗と取りこぼし，微調整の検証の削減率の推移，教師データの一貫性，教師データの数の曲線，各段階の時間．
- ブートストラップ：2000回，`default_rng(0)`を1回作り，`summary.py`の順に使う．設定ごとに，目的系を復元抽出し，目的系ごとの（学習したパスの$J$，探索の$J^*$，線形パスの$J$）を組のまま使って比を計算し直す（分母も抽出ごとに計算する）．族と一般（ガウス）は目的系が違うので，差の区間は独立に抽出して求める．同じ目的系の比較（拡張の有無，行動の基底）は目的系ごとに対をとる．ネットワークのseedによるばらつきは区間に入らないので，ネットワークごとの値を併記する．

## 5．判断基準（実行前に固定．開発集合で判断する）

系の種類と$k$ごとに：

- **「族$k$では教師あり学習の効率が高い」**：3つの$W$のすべてで，$M_1$（$W$ごとに2つのネットワークの平均）が一般（ガウス）の$M_1$（3つのネットワークの平均）より0.1以上高く，差の95%区間が0を含まない．
- **「族$k$では微調整の後の質が高い」**：同じ規則を$M_2$に使う．
- 対をとる比較（削減率の差．EXP-0055の規則：差が+1.0ポイント以上で区間が0を含まなければ「良い」，−1.0ポイント以下で区間が0を含まなければ「悪い」，それ以外は「差なし」）：
  - 一般（ガウス）・拡張あり − 一般（ガウス）（教師あり学習の後，微調整の後）．
  - 族$k$=8・全次元の行動 − 族$k$=8（$W$ 0）（同上）．
- 記述（判断には使わない）：$M_1$，$M_2$と$k$の関係，n4-d3333からn5-d33333への$M_1$，$M_2$の変化を族と一般（ガウス）で比べる，教師データの数の曲線．
- 判断基準の数値（0.1，±1.0）は事前に決めた目安であり，結果を見て変えない．
