# EXP-0048：小さい系で学習したネットワークをそのままn6に使う（学習なしの転用）

> 本記録の1〜6節は，実験の実行前（2026-10-16 21:00 JST頃）に書いた事前登録である．結果を見た後に1〜6節を変更する場合は，変更した箇所と理由を明記する．

## 2．目的

- attention型のネットワークは，学習で決まる重みの形が変数の数$n$によらない（係数ごとに同じ重みを使うため）．$n$で形が変わるのは，学習しない固定の直交行列$U$（付録A）と，使っていない以前の名残りの重み（`actor_logstd`，`critic`）だけである．したがって，ある系の種類で学習したネットワークを，学習し直さずに変数の多い系の種類に使える（以下，**転用**）．
- 予備的な確認（2026-10-16，記録外）では，n5-d33333の目的系200個で，n4-d3333のネットワーク（seed 0）の転用が25.2%，n5-d33333専用のネットワーク（seed 0）が25.0%で，差は+0.2［−0.2, +0.6］ポイントだった．n3-d333からは−1.3，n2-d33からは−6.0ポイントだった．
- 本実験では，n5とn4のネットワークをn6の2つの系の種類に転用し，テストデータでの削減率を求める．
  - 規模を上げるときのボトルネックは教師データの作成（n5-d33333で学習の約7割，9時間）である．転用で十分な削減が得られれば，n6以上では教師データをゼロから作らずに済む可能性がある．
  - 本実験の値は，今後別の実験で作る**n6専用のネットワーク**（n6で標準の手順を行ったもの）と比べる基準にする（5節）．

## 3．多項式系

| 系の種類 | $n$ | 次数 | パスの数 | 動かす係数 | ずれの次元（$d_b=2$） |
|---|---:|---|---:|---:|---:|
| n6-d222222 | 6 | $(2,2,2,2,2,2)$ | 64 | 42 | 84 |
| n6-d333333 | 6 | $(3,3,3,3,3,3)$ | 729 | 42 | 84 |

- 開始系は$g_i=x_i^{d_i}-1$，目的系は$f_i=x_i^{d_i}+a_{i,1}x_1+\cdots+a_{i,6}x_6+a_{i,7}$．係数は実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．$d_b=2$．
- 直交行列$U$（84×84）は，n6の設定の`basis_seed: 0`から作る（移す元の$U$は使わない）．
- 実行前の確認として，学習用に予約した範囲の先頭5個（n6-d222222はseed 13000000〜13000004，n6-d333333は14000000〜14000004）で，線形パスの追跡ができることを確かめた（ネットワークは使っていない）．

## 4．方法（事前登録）

### 4.1．移す元のネットワーク

すべて報告（2026-10-16）3節の標準の手順のネットワークで，微調整後の3つ（seed 0〜2）を使う．

| 移す先 | 移す元 | run |
|---|---|---|
| n6-d222222 | n5-d22222 | EXP-0031 `exp-0031-n5-d22222-db2-ft-attn-seed{0,1,2}-20261013T110507Z` |
| n6-d222222 | n4-d2222 | EXP-0020 `exp-0020-n4-d2222-db2-ft-attn-lr1e-3-seed{0,1,2}-20261013T012102Z` |
| n6-d333333 | n5-d33333 | EXP-0034 `exp-0034-n5-d33333-db2-ft-attn-seed{0,1,2}-20261013T225900Z` |
| n6-d333333 | n4-d3333 | EXP-0023 `exp-0023-n4-d3333-db2-ft-attn-seed{0,1,2}-20261013T034630Z` |

- n5のseed 1と2は外部サーバで学習したもので，設定・重み・学習の記録だけを手元に写した（重みのチェックサムの一致を確認済み）．
- 移し替え（`make_transfer.py`）：n6の設定でネットワークを作り，移す元の`actor_mean`の重みのうち$U$以外をすべて写す．写さない重みがあれば止める（$U$以外の不足や余り，形の不一致はエラーになる）．こうして12個のrunを作る．
- 移し替えのあと，ネットワークの重みは一切変えない（微調整もしない）．

### 4.3．手順

1. **確認（4.4節）**
2. **移し替え：** 12個のrunを作る．
3. **評価：** 12個のrunを，開発集合とテストデータの両方で評価する（`evaluate.py`，各500個）．
   - 本実験では選択をしないので，開発集合の値は今後の実験の基準として記録するだけである．
   - テストデータは本実験で1回だけ使う．
4. **比較：** 系の種類ごとに`compare_runs.py`で比べる．3つのネットワークのステップ数を目的系ごとに平均し，目的系ごとに対応をとったブートストラップで95%区間を求める（2000回）．
   - グループは「n5から」と「n4から」．
   - 差は「n5から − n4から」．

### 4.4．実行前の確認

- **移し替えの確認：** 4つの移す元（各seed 0）について，自分自身の系の種類への移し替えを作る．目的系20個（seed 11900000〜11900019．追跡はしない）で，ネットワークの出力が元のrunと完全に一致すること（最大の差が0）．一致しなければ止める．
- **環境の確認：** EXP-0047の環境の確認（2026-10-16，同じコンテナ）で，既存の値との一致を確かめている．

### 4.5．報告する値

- 系の種類と移す元ごとに，テストデータと開発集合での削減率．seedごとの値と3つの平均（3つのネットワークのステップ数を目的系ごとに平均した値．報告の表と同じ計算）．
- 線形パスより良くなった目的系の割合．
- 差（n5から − n4から）と95%区間．
- 参考：同じ次数のn5専用のネットワークの，n5のテストデータでの削減率（報告3節：n5-d22222は20.9%，n5-d33333は24.8%）．系の種類が違うので，直接の比較ではない．

## 5．判断基準（実行前に固定）

- 本実験は記述的な計測であり，合否の基準は設けない．
- **今後のn6専用のネットワークとの比較のやり方を，ここで固定する．**
  - 比べる相手：本実験のn5からの転用（3つのseed）．重みは本実験の時点のまま変えない．
  - 比べる場所：4.2節のテストデータ（500個）．
  - 差（専用 − 転用）を，同じ方法（3つの平均，目的系ごとに対応をとったブートストラップ，95%区間）で求める．
  - 判定：差が+1.0ポイント以上で95%区間が0を含まなければ「専用の方が良い」．−1.0ポイント以下で区間が0を含まなければ「転用の方が良い」．それ以外は「同程度」．
  - 専用のネットワークを作るのにかかった時間（教師データ，教師あり学習，微調整）も記録し，転用（学習の時間0）と並べて示す．

## 6．中断の条件

- 4.4節の移し替えの確認で，出力が1つでも一致しない場合．
- 移し替えで，$U$以外に写せない重みがあった場合．
- テストデータか開発集合で，線形パスの追跡に失敗した目的系が5%を超えた場合（n6でHomotopyContinuation.jlの設定が足りない可能性があるため．その系の種類で止めて報告する）．
- 判断基準を，結果を見てから変えることはしない．
