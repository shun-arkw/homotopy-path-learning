# EXP-0044：追跡の計算時間（標準の手順のネットワークと，教師データ作り直し後のネットワーク）

> 本記録の1〜6節は，実験の実行前（2026-10-16 JST）に書いた事前登録である．結果を見た後に1〜6節を変更する場合は，変更した箇所と理由を明記する．

## 1．基本情報

- 実験ID：EXP-0044
- 状態：Planned（事前登録）
- 実行環境：メインの作業環境の参照Docker`homotopy-continuation`．1プロセス・1スレッドで，他の計算がない状態で計測する．ネットワークはCPUで計算する．
- コードの変更：なし（`timing.py`はEXP-0020で追加済み）．計測と集計は，EXP-0040のスクリプト（`outputs/EXP-0040/scripts/perpath.py`，`summarize.py`と同じ処理）を実験フォルダに写して使う．

## 2．目的

- EXP-0040は，系の種類ごとに「これまでで最も良いネットワーク」で計測した．その作り方は系の種類ごとに違う（標準の手順，微調整4000反復，探索5回の教師データ，教師データの作り直し）．
- 2026-10-16の報告で，結果1（全8系の種類，標準の手順）と結果2（教師データの作り直し）を分けて示すため，同じ設定のネットワークどうしで計算時間をそろえる．
  - 結果1：全8系の種類で，標準の手順（ゼロからの探索500回の教師データ1万件→attentionの教師あり学習→微調整2000反復）のネットワーク．
  - 結果2：教師データ作り直し後のネットワーク（n4-d3333，n5-d22222，n5-d33333）．標準の手順と同じ計測の回で測る．

## 4．方法（事前登録）

EXP-0040の4節と同じ（ウォームアップ3回の後に5回測り中央値をとる．線形パスとネットワークの両方を測る．パスごとのステップ数を記録する）．11個のネットワークを1つずつ順に測る．線形パスも，ネットワークごとに同じ回で測り直す．

## 5．判断基準（実行前に固定）

- EXP-0040と同じ値を表にして報告する．

## 6．中断の条件
