## 2．目的

- これまでの教師データは，問題ごとにゼロから探索して作っている（予算500，探索seed 0）．次元が高いと，この探索は弱い．n5-d33333では，教師データの平均$\Delta J$（$-14.1\%$）が，それで学習した微調整後の方策（試験500問題で$-24.8\%$）より悪い．
- EXP-0035では，微調整後の方策の行動を初期値にして探索すると，予算100でも大きく改善した（20問題，3seedの平均：n5-d22222の通常の問題で$-22.0\%\to-34.7\%$，n5-d33333で$-27.3\%\to-30.9\%$）．
- EXP-0036では，n5-d33333の微調整を2000反復から4000反復に延ばしても，改善は$-0.47$ポイントにとどまった．
- そこで，「方策＋探索」で教師データを作り直し，教師あり学習と微調整をやり直す（第1周）．教師データの質の改善が，最終的な方策の改善につながるかを確かめる．

## 3．多項式系

EXP-0031（n5-d22222）とEXP-0034（n5-d33333）と同じ．$d_b=2$，行動60次元．

## 4．方法（事前登録）

用語：第0周の方策は，これまでのパイプライン（ゼロからの探索の教師データ→教師あり学習→微調整2000反復）で得たattention方策である．n5-d22222はEXP-0031，n5-d33333はEXP-0034の方策（各seed 0〜2）．

- **教師データの問題：** 第0周と同じ1万問題とする（n5-d22222は評価seed 10000000〜10009999，n5-d33333は11000000〜11009999）．教師データの行動だけを変え，問題の集合による差をなくすためである．
- **教師データの作り方：** 問題ごとに，第0周の方策 seed $k$の行動を初期値にした探索を，探索seed $k$で行う（$k=0,1,2$）．
  - 各探索は予算100とする．評価の順は，零行動，方策の行動，その後は最良の点からの(1+1)進化戦略である（`--n-random 2 --initial-sigma 0.05`，EXP-0035と同じ）．
  - 問題ごとに，3回の探索のうち最良を教師データとする（1問題あたり300評価）．
- **教師あり学習：** ネットワークを初期化して，新しい教師データだけで学習する．設定は第0周と同じ（attention，既定の大きさ，対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2，GPU）．
- **微調整：** 第0周と同じ設定・同じ問題とする（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題，1 runあたり10ワーカー）．
  - n5-d22222：検証seed 10600000，訓練seed 10700000．
  - n5-d33333：検証seed 11600000，訓練seed 11700000．
- **試験問題：** 第0周と同じ．n5-d22222は評価seed 9520000〜9520499，n5-d33333は9530000〜9530499（各500問題）．到達率の分母は，それぞれの試験oracle（予算1000，探索seed 0）とし，参考の値とする．
- **比較：** `compare_runs.py`で，第1周と第0周の方策を比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．
- **実行の順：** 教師データ（n5-d22222→n5-d33333，30並列）→ n5-d22222の教師あり学習（n5-d33333の教師データの生成と並行）→ n5-d33333の教師あり学習とn5-d22222の微調整 → n5-d33333の微調整 → 評価と比較．

## 5．判断基準（実行前に固定）

系ごとに判定する．

- **主基準：** 試験500問題での，微調整後の$\Delta J$の差（第1周−第0周）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → 方策＋探索で教師データを作り直すことは有効．
- **参考：**
  - 教師データの平均$\Delta J$（第0周の教師データと比べる）．
  - 教師あり学習の段階での差（第1周−第0周）．
  - n5-d33333では，第1周の微調整後と，EXP-0036の4000反復の微調整後の差（同じ程度の追加の計算で，どちらが有効か）．
