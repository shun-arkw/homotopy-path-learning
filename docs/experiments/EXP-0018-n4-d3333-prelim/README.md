## 記号と指標

- $J$：1問題の追跡コスト．全解パスについての$N_{\mathrm{acc}}+\rho N_{\mathrm{rej}}$の平均（$N_{\mathrm{acc}}$は受理ステップ数，$N_{\mathrm{rej}}$は棄却ステップ数，$\rho=1$）．追跡に失敗したパスには失敗ペナルティ$10^5$を課す．
- $J_{\mathrm{lin}}$：線形パス（制御点を開始系と目的系の線形補間に置いたパス．行動ゼロに等しい）の$J$．$J_{\mathrm{oracle}}$：oracleの最良行動での$J$．$\overline{J}$：評価100問題での$J$の平均（表の「平均$J$」）．
- $\Delta J$：線形パスに対する平均追跡コストの変化率．$\Delta J=(\overline{J}_{\mathrm{oracle}}-\overline{J}_{\mathrm{lin}})/\overline{J}_{\mathrm{lin}}\times100$（%）．負の値が改善．本記録では評価100問題（評価seed 40000〜40099）でのoracleの値．差は「ポイント」で表す．
- Positive rate：評価100問題のうち，oracleの$J$が線形パスの$J$より小さかった問題の割合．
- 成功率：追跡に失敗しなかった問題の割合．
- oracle：学習を使わず，評価問題ごとに行動を直接探索した結果（ゼロ行動，一様乱数，(1+1)進化戦略）．有限回の探索なので改善余地の下界．
- 予算$B$：oracleが1問題に使う試し追跡の回数（最初の100回はゼロ行動と一様乱数）．「予算$B$での値」は各問題のコストトレース（`oracle_cost_traces.npy`）の先頭$B$評価の最小値．本実験の実行予算は$B=3000$．
- $n$，$d_i$，$N_{\mathrm{path}}=\prod_i d_i$：変数の数，方程式$i$の次数，追跡する解パスの数．系の名前（n4-d3333）は「変数の数4，次数(3,3,3,3)」を表す．
- $a_{i,j}$，$b$：目的系の係数と，その生成範囲（実部・虚部を$[-b,b]$の一様分布から生成．本記録では$b=1.0$）．
- $D_{\mathrm{free}}$：自由な（先頭以外の）複素係数の個数（n4-d3333で20）．観測は$2D_{\mathrm{free}}=40$次元の実ベクトル．
- $d_b$：ベジェ曲線の次数．制御点は$d_b+1$個で，両端（開始系と目的系）は固定，中間の$d_b-1$個を行動で動かす．本記録では$d_b\in\{2,3\}$．
- $m$：潜在次元（中間制御点1つあたりの行動の次元）．「フル潜在（full）」は$m=2D_{\mathrm{free}}=40$．行動の次元は$(d_b-1)m$で，$d_b=2$のとき40，$d_b=3$のとき80．
- 勝ち数：評価100問題のうち，あるoracleの$J$が他方より小さかった問題の数（同値は引き分け）．

## 2．目的

スクリプトの記述：EXP-0017のラベル段階が終わるのを待ち，n4-d3333について，フル潜在oracle（予算$B=3000$）を$d_b=2$と$d_b=3$で，評価100問題（4 shard×25問題）に対して実行する（予備調査）．EXP-0014の記録（10節）では，より大きな系（n4-d3333など）の検討を，n4-d2222の律速を解消してからとしている．本実験は学習を行わず，$d_b=2$と$d_b=3$について，予算ごとのoracleの$\Delta J$とPositive rateを求める．

## 3．多項式系

**n4-d3333**（$n=4$，次数$(3,3,3,3)$，$N_{\mathrm{path}}=3^4=81$，観測次元40）

- 開始系 $G=\{g_1,g_2,g_3,g_4\}$：
  $$g_1=x_1^3-1,\qquad g_2=x_2^3-1,\qquad g_3=x_3^3-1,\qquad g_4=x_4^3-1$$
- 目的系 $F=\{f_1,f_2,f_3,f_4\}$：
  $$f_i=x_i^3+a_{i,1}x_1+a_{i,2}x_2+a_{i,3}x_3+a_{i,4}x_4+a_{i,5}\quad(i=1,\dots,4)$$

係数$a_{i,j}$は問題ごとに異なり，実部と虚部をそれぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数（$x_i^3$の係数）は1に固定する．設定ファイルの`free_exponents`は，各方程式で$x_1,x_2,x_3,x_4$の1次項と定数項の5項である．ベジェ次数は$d_b=2$（行動40次元）と$d_b=3$（行動80次元）．

## 4．方法

### 4.1．設定

追跡設定（設定ファイル）：最大ステップ数50000，最大ステップ幅0.05，最小ステップ幅$10^{-12}$，拡張精度なし，棄却ステップの重み$\rho=1$，失敗ペナルティ$10^5$．`path.action_limit`は1.0．

### 4.2．oracle

各$d_b\in\{2,3\}$について，次を$k=0,1,2,3$の4 shardで実行した（同時に計8プロセス）．

```text
oracle.py --config experiments/multivariate_pham/configs/exp-0018-n4-d3333-db<d_b>.yaml \
  --experiment-id EXP-0018 --output-root /app/outputs --latent-dim full --budget 3000 --n-random 100 --search-seed 0 \
  --evaluation-seed $((40000 + 25k)) --num-instances 25 --run-id exp-0018-n4-d3333-db<d_b>-prelim-full-b3000-s<k>-<TS>
```

各shardは25問題（評価seed $40000+25k$〜）で，4 shardで評価seed 40000〜40099の100問題になる．本記録では4 shardを`target_seed`順に連結して集計した（連結したrunは作っていない）．$d_b=2$と$d_b=3$の評価問題と線形パスの$J$は一致する（確認済み）．「予算$B$での値」は各問題のコストトレースの先頭$B$評価の最小値から求めた．

## 7．観察

- 線形パスの平均$J$は55.02で，n4-d2222（44.04）より大きい．線形パスとoracleの成功率はどちらも1.00だった．
- oracleの$\Delta J$（評価100問題）は，予算1000で$d_b=2$が$-22.90\%$，$d_b=3$が$-22.82\%$だった．予算3000ではそれぞれ$-23.26\%$，$-24.24\%$で，差（$d_b=3-d_b=2$のoracleの$J$）の95%区間$[-1.31,+0.22]$は0を含む．
- 小さい予算では，$d_b=2$の方が早く下がった．予算300で$-19.55\%$と$-16.43\%$，$d_b=2$が良い問題は100問中74問．
- 予算100では，どちらもほぼ改善しなかった（$-0.36\%$，$0.00\%$）．
- 改善余地（予算1000で約$-23\%$）は，n4-d2222（約$-30\%$，$d_b=2$）より小さい．

## 8．考察

- n4-d3333では，十分な予算のもとで，$d_b=2$と$d_b=3$のoracleの改善余地は同等である．
- $d_b=3$は行動の次元が2倍（80次元，$d_b=2$は40次元）で探索が遅いが，予算を増やすと追いつく．
- 教師データの予算500では，$d_b=2$のラベルの方が良い（$-22.45\%$と$-20.94\%$）．行動の次元が小さい分，学習も易しいと見込まれるため，本番を行う場合の第一候補は$d_b=2$である．ただし，n3-d222やn4-d2222のような明確な差はなく，$d_b$は系ごとのハイパーパラメータとして扱う．
- n4-d2222と同程度の到達率（約0.46）にとどまれば，期待される$\Delta J$は$-10\%$程度である．

## 9．結論

- n4-d3333の改善余地（oracle，予算1000，評価100問題）は約$-23\%$で，$d_b=2$と$d_b=3$で差はない．
