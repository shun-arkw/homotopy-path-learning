## 記号と指標

- $J$：1問題の追跡コスト．全解パスについての$N_{\mathrm{acc}}+\rho N_{\mathrm{rej}}$の平均（$N_{\mathrm{acc}}$は受理ステップ数，$N_{\mathrm{rej}}$は棄却ステップ数，$\rho=1$）．追跡に失敗したパスには失敗ペナルティ$10^5$を課す．
- $J_{\mathrm{lin}}$：線形パス（制御点を開始系と目的系の線形補間に置いたパス．行動ゼロに等しい）の$J$．$J_{\mathrm{oracle}}$：oracleの最良行動での$J$．$\overline{J}$：対象の問題集合での$J$の平均（表の「平均$J$」）．
- $\Delta J$：線形パスに対する平均追跡コストの変化率．$\Delta J=(\overline{J}_{\text{手法}}-\overline{J}_{\mathrm{lin}})/\overline{J}_{\mathrm{lin}}\times100$（%）．負の値が改善．
  - 特に断らない限り，評価100問題（評価seed 39000〜39099）での値．
  - 「教師データの平均$\Delta J$」：訓練問題（教師データ1万件）での値．
  - 「検証$\Delta J$」：検証200問題（微調整のモデル選択用，検証seed 8600000）での値．
  - $\Delta J$の差は「ポイント」で表す．
- Positive rate：問題集合のうち，その手法の$J$が線形パスの$J$より小さかった問題の割合．
- 成功率：追跡に失敗しなかった問題の割合．
- 到達率：$(\overline{J}_{\mathrm{lin}}-\overline{J}_{\text{手法}})/(\overline{J}_{\mathrm{lin}}-\overline{J}_{\mathrm{oracle}})$．oracleの改善量のうち手法が得た割合．分母のoracleは必ず明記する．本記録の評価100問題では，基準を「EXP-0017の比較用oracle（フル潜在，$d_b=2$，予算$B=3000$）」と「同oracleの各問題の先頭1000評価の最小値（予算$B=1000$）」の2通りで求める（EXP-0014，EXP-0016と同じ方式）．1を超えるのは，手法の$J$が基準のoracleより小さいことを意味する．
- oracle：学習を使わず，評価問題ごとに行動を直接探索した結果（ゼロ行動，一様乱数，(1+1)進化戦略）．有限回の探索なので改善余地の下界．
- 予算$B$：oracleが1問題に使う試し追跡の回数（最初の100回はゼロ行動と一様乱数）．「予算$B$での値」は最初の$B$回の中の最良値．教師データ（ラベル）は$B=500$である．
- $n$，$d_i$，$N_{\mathrm{path}}=\prod_i d_i$：変数の数，方程式$i$の次数，追跡する解パスの数．系の名前（n4-d2222）は「変数の数4，次数(2,2,2,2)」を表す．
- $a_{i,j}$，$b$：目的系の係数と，その生成範囲（実部・虚部を$[-b,b]$の一様分布から生成．本記録では$b=1.0$）．
- $D_{\mathrm{free}}$：自由な（先頭以外の）複素係数の個数（n4-d2222で20）．観測は$2D_{\mathrm{free}}=40$次元の実ベクトル．
- $d_b$：ベジェ曲線の次数．制御点は$d_b+1$個で，両端（開始系と目的系）は固定，中間の$d_b-1$個を行動で動かす．本記録の本実験は$d_b=2$，比較対象のEXP-0014は$d_b=3$．
- $m$：潜在次元（中間制御点1つあたりの行動の次元）．「フル潜在（full）」は$m=2D_{\mathrm{free}}=40$．行動の次元は$(d_b-1)m$で，$d_b=2$のとき40，$d_b=3$のとき80．
- BC：行動模倣（behavior cloning）．oracleの最良行動を正解とする教師あり学習．「拡張あり／なし」は，学習中に問題族の対称群の元（768個）を作用させて観測と行動を変換するか否か．
- 微調整：BCの方策を初期値に，追跡コストを直接下げる学習（EXP-0013の方法）．
  - $\sigma$：摂動の大きさ（本記録では0.05）．
  - $P$（`--pairs`）：1問題あたりの対の摂動の数（本記録では4）．
  - $\lambda$（`--bc-weight`）：BC項の重み（本記録では0）．
  - $K$（`--batch-problems`）：微調整の1反復あたりの訓練問題数（本記録では32）．
- 最良epoch／反復：BCでは検証損失が最小のエポック，微調整では検証$\Delta J$が最小の反復．評価にはその重みを使う．
- 検証損失：教師データのうち検証用10%（1000件）での，BCの出力と教師行動の二乗誤差の平均．
- 試験問題：評価seed 41000〜41499の500問題．EXP-0020で追加した再評価に使う（5.7節）．

## 2．目的

n4-d2222のベジェ次数を$d_b=3$（EXP-0014，行動80次元）から$d_b=2$（行動40次元）に変え，標準パイプライン（フル潜在oracleのラベル → 対称性拡張つきBC → 追跡コストの直接最小化による微調整）を実行する．スクリプトの記述は「EXP-0014（n4-d2222，$d_b=3$）と，ベジェ次数以外は同一」である．EXP-0014の記録（10節）では，行動の次元を80から40に下げることで，n4-d2222で示唆された教師あり学習の段階の不足が緩むかを確かめる，という位置づけである．

## 3．多項式系

**n4-d2222**（$n=4$，次数$(2,2,2,2)$，$N_{\mathrm{path}}=16$，観測次元40）

- 開始系 $G=\{g_1,g_2,g_3,g_4\}$：
  $$g_1=x_1^2-1,\qquad g_2=x_2^2-1,\qquad g_3=x_3^2-1,\qquad g_4=x_4^2-1$$
- 目的系 $F=\{f_1,f_2,f_3,f_4\}$：
  $$f_i=x_i^2+a_{i,1}x_1+a_{i,2}x_2+a_{i,3}x_3+a_{i,4}x_4+a_{i,5}\quad(i=1,\dots,4)$$

係数$a_{i,j}$は問題ごとに異なり，実部と虚部をそれぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数（$x_i^2$の係数）は1に固定する．設定ファイルの`free_exponents`は，各方程式で$x_1,x_2,x_3,x_4$の1次項と定数項の5項である．ベジェ次数は$d_b=2$（中間制御点1つ，全次元の行動40次元，`latent_basis`は$40\times40$）．

## 4．方法

### 4.1．共通設定

追跡設定（設定ファイル）：最大ステップ数50000，最大ステップ幅0.05，最小ステップ幅$10^{-12}$，拡張精度なし，棄却ステップの重み$\rho=1$，失敗ペナルティ$10^5$．`path.action_limit`は1.0．

### 4.2．比較用oracle（評価100問題）

`oracle.py --latent-dim full --budget 3000 --n-random 100 --search-seed 0 --num-instances 25 --evaluation-seed $((39000+25k))`（$k=0,1,2,3$の4 shard，各25問題）．4 shardを`oracle.csv`の`target_seed`順に連結して（複製のみ）100問題の比較用oracleとした（`...-prelim-full-b3000-combined-...`）．到達率の分母は，この予算$B=3000$の値と，各問題のコストトレースの先頭1000評価の最小値（予算$B=1000$）の2通り．BC，微調整の`--oracle-run-dir`にもこの連結oracleを指定した（評価時の`Oracle`行と`captured_fraction`の分母は予算$B=3000$）．

### 4.3．ラベル

`oracle.py --latent-dim full --budget 500 --n-random 100 --search-seed 0 --num-instances 500 --evaluation-seed $((8000000+500k))`（$k=0,\dots,19$の20 shard，計10000問題，評価seed 8000000〜8009999）．問題seedはEXP-0014と同一．

### 4.4．BC

`behavior_cloning.py --latent-dim full --augment-symmetry --hidden-sizes 256,256,256 --epochs 5000 --batch-size 256 --learning-rate 1e-3 --val-fraction 0.1 --seed s`（$s=0,1,2$）．ラベルは20 shardの10000件（訓練9000件，検証1000件）．拡張なしは同じ設定から`--augment-symmetry`を除いた seed 0 のみ．

### 4.5．微調整

`finetune.py --latent-dim full --init-run-dir <BC拡張ありseed s> --iterations 2000 --batch-problems 32 --pairs 4 --sigma 0.05 --learning-rate 1e-4 --bc-weight 0 --seed s --train-seed 8700000 --val-seed 8600000 --val-instances 200 --val-interval 50`（$s=0,1,2$）．$K=32$，$P=4$，$\sigma=0.05$，$\lambda=0$．EXP-0014と同じ検証seed・訓練seed．

### 4.6．判断基準

数値の判断基準は事前に固定していない．比較の対象は，同じ系の$d_b=3$の結果（EXP-0014）である．

## 7．観察

- 比較用oracle（評価100問題，予算3000）の$\Delta J$は，$d_b=2$で$-31.65\%$，$d_b=3$（EXP-0014）で$-28.53\%$だった．教師データ（予算500）の平均$\Delta J$も，$d_b=2$で$-29.74\%$，$d_b=3$で$-24.86\%$だった．
- 学習した方策の$\Delta J$（評価100問題，3seed平均）は，$d_b=2$で教師あり学習後$-11.73\%$，微調整後$-13.60\%$だった．$d_b=3$ではそれぞれ$-8.61\%$，$-11.10\%$である．
- 一方，微調整後の到達率（分母は各$d_b$自身のoracle，予算1000）は，$d_b=2$で0.457，$d_b=3$で0.447とほぼ同じだった．
- 対称性による拡張の効果（seed 0，到達率の差，分母は予算3000のoracle）は+0.217だった．
- 微調整の検証$\Delta J$（検証200問題，3seed平均）は，反復1500で$-15.11\%$，反復2000で$-15.17\%$で，ほぼ頭打ちだった．

## 8．考察

- n4-d2222では，$d_b=2$は$d_b=3$より$\Delta J$で約2.5ポイント良い（微調整後，評価100問題）．
- ただし到達率は同程度である．$d_b=2$の利点は，主にoracleの改善余地が大きいことから来ている．学習側が改善余地を捕らえる割合は，$d_b$によらず約0.45にとどまる．
- 律速は引き続き教師あり学習の段階にある．到達率は教師あり学習後に約0.37〜0.40（評価100問題／試験500問題）で，微調整で約+0.06上がるだけである．
- $d_b$の優劣は系に依存する（n3-d222はEXP-0016，n4-d3333はEXP-0018）．このため，$d_b=2$を一般の標準とはしない．

## 9．結論

- n4-d2222では，$d_b=2$のパイプラインで微調整後の$\Delta J$が$-13.60\%$（評価100問題，3seed平均）となった．試験500問題では$-14.38\%$（3seedの問題ごと平均）である．どちらも$d_b=3$（$-11.10\%$，評価100問題）より良い．
- 到達率は約0.46で，教師あり学習の段階が律速であることは変わらない．
