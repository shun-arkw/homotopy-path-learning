## 2．目的

- EXP-0029で，oracleの1回の探索は局所解に止まりやすく，探索seedを変えた5回の探索のうち最良をとる（**多点スタート**）と，oracleの値が大きく改善することが分かった（n5-d33333で$\Delta J$が$-17.6\%$から$-23.3\%$）．
- 教師データを多点スタートで作ると，計算量は1件あたり5倍になる．同じ計算量なら件数は1/5になる．
- 教師データの「質」（多点スタート）と「量」（件数）のどちらが，教師あり学習＋微調整の結果に効くかを調べる．

## 3．多項式系

EXP-0020と同じ（n4-d2222，$f_i=x_i^2+\sum_{j=1}^4a_{i,j}x_j+a_{i,5}$，$d_b=2$，行動40次元）．

## 4．方法（事前登録）

### 4.1．教師データ

- **(iii) 1回の探索，1万件：** EXP-0017の教師データ（探索seed 0，予算500，評価seed 8000000〜8009999）．
- **(ii) 1回の探索，2000件：** (iii)のうち，評価seed 8000000〜8001999の2000件．
- **(i) 多点スタート，2000件：** (ii)と同じ2000問題で，探索seed 1〜4の予算500の探索を新たに行い，seed 0を含む5回のうち，問題ごとにコスト$J$が最小の行動を教師とする．
- (i)は20分割（各100問題×4seed）で実行し，`outputs/EXP-0030/scripts/best_of.py`で問題ごとに最良を選んでまとめる．

### 4.2．学習と評価

- 方策：attention（既定の大きさ）．教師あり学習は対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．微調整はEXP-0020と同じ（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 8600000，訓練seed 8700000）．
- (iii)はEXP-0020の方策（教師あり学習は5000エポックだが，最良のエポックは50〜65）を使う．(i)と(ii)を新たに学習する．
- 試験問題：EXP-0020の試験500問題（評価seed 41000〜）とそのoracle（予算1000）．`compare_runs.py`で比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

いずれも微調整後の$\Delta J$の差（試験500問題）で判定する．

- **質の効果：** (i)−(ii)が$-1.0$ポイント以下で，95%区間が0を含まない → 多点スタートの教師データは有効．
- **量の効果：** (iii)−(ii)が$-1.0$ポイント以下で，95%区間が0を含まない → 件数を増やすことは有効．
- **同じ計算量での比較（参考）：** (i)（2000件×5回）と(iii)（1万件×1回）は，oracleの計算量がほぼ同じである．差とその区間を報告する．
- 多点スタートの教師データの平均$\Delta J$（予算500，5回の最良）と，seed 0だけの平均$\Delta J$も報告する．
