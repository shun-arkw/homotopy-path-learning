## 2．目的

EXP-0011では，対称性による拡張つきBCの到達率が，300エポックから1500エポックで大きく上がり（n3-d222：0.367→0.447，n2-d33：0.746→0.812），最良エポックも終盤にあったため，学習が飽和していなかった．到達率を押し上げている要因が学習時間，ネットワーク容量，データ量のどれかを，1要因ずつ変えて確認する．

## 3．方法・設定

### 多項式系

**n3-d222**（$n=3$，次数$(2,2,2)$，$N_{\mathrm{path}}=8$，観測次元24）

- 開始系 $G=\{g_1,g_2,g_3\}$：
  $$g_1=x_1^2-1,\qquad g_2=x_2^2-1,\qquad g_3=x_3^2-1$$
- 目的系 $F=\{f_1,f_2,f_3\}$：
  $$f_1=x_1^2+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}x_3+a_{1,4}$$
  $$f_2=x_2^2+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}x_3+a_{2,4}$$
  $$f_3=x_3^2+a_{3,1}x_1+a_{3,2}x_2+a_{3,3}x_3+a_{3,4}$$

**n2-d33**（$n=2$，次数$(3,3)$，$N_{\mathrm{path}}=9$，観測次元12）

- 開始系 $G=\{g_1,g_2\}$：
  $$g_1=x_1^3-1,\qquad g_2=x_2^3-1$$
- 目的系 $F=\{f_1,f_2\}$：
  $$f_1=x_1^3+a_{1,1}x_1+a_{1,2}x_2+a_{1,3}$$
  $$f_2=x_2^3+a_{2,1}x_1+a_{2,2}x_2+a_{2,3}$$

係数$a_{i,j}$は問題ごとに異なる．実部と虚部を，それぞれ$[-1,1]$の一様分布から独立に生成する（複素一様分布，$b=1.0$）．先頭係数は1に固定する．

共通の設定は，`--latent-dim full --augment-symmetry --batch-size 256 --learning-rate 1e-3 --val-fraction 0.1`，比較対象はEXP-0009のフル潜在oracle（$B=1000$，同じ評価seed）である．ベースラインはEXP-0011の拡張あり1500エポック（隠れ層256,256，3seed，`TS=20261012T095728Z`）である．

- E：隠れ層$(256,256)$，5000エポック，seed 0,1,2（エポック数のみ変更）．
- C1：隠れ層$(512,512)$，5000エポック，seed 0,1,2（Eに対して幅を2倍）．
- C2：隠れ層$(256,256,256)$，5000エポック，seed 0,1,2（Eに対して深さを1層追加）．
- D：隠れ層$(256,256)$，5000エポック，seed 0，`--num-train`＝1000，3000（10000はEのseed0）．

各runは評価前に検証損失が最小のエポックの重みを採用する．同じseedの学習は決定的であり，Eの最初の1500エポックはベースラインと一致する（検証損失の曲線も一致する）．

## 4．判断基準（実行前に固定）

- E（5000エポック）が1500エポックより到達率+0.05以上 → 学習時間が効く（学習率の減衰や，さらに長い学習を検討）
- C1またはC2がEより+0.05以上 → 容量が効く（大きいネットワークを標準にする）
- D：3000件→1万件で+0.05以上 → データ量が効く（教師データの拡大を検討）
- いずれも+0.05未満 → 現手法はおおむね飽和（コストを使った微調整へ進む）
- 複数該当なら改善幅の大きい順に組み合わせる

## 6．観察

- **エポック数**：1500から5000に増やすと，到達率はn3-d222で0.447から0.516（+0.069），n2-d33で0.812から0.853（+0.042）に上がった．
- **ネットワークの深さ**：3層（256×256×256）にすると，n3-d222でさらに0.579（Eより+0.063）に上がった．n2-d33では0.831（Eより−0.022）で，3seedの範囲はEと重なる．
- **ネットワークの幅**：512×512はどちらの系でもEより低かった（−0.018）．
- **データ量**：3000件から1万件への到達率の変化は，n3-d222で−0.021，n2-d33で+0.034だった．どちらも+0.05未満で，n3-d222は3000件以降で頭打ちに見える（seed0のみ）．
- 5000エポックの18runのうち12runで，最良エポックが最終エポックの90%以降にあった．学習はまだ完全には飽和していない．
- 検証損失（行動の二乗誤差）は，エポック500から5000までほとんど下がらなかった（n3-d222のEで0.0741から0.0734）．一方で，到達率は上がり続けた．
- n3-d222の最良構成（3層，5000エポック）は，$\Delta J=-15.04\%$，Positive rate 0.91，到達率0.579だった．

## 7．考察

### 7.1．判断基準との照合（n3-d222）

| 基準 | 結果 | 該当 |
|---|---|---|
| E（5000エポック）がベースラインより+0.05以上 | +0.069 | 該当：学習時間が効く |
| C1またはC2がEより+0.05以上 | C2で+0.063，C1で−0.018 | 該当（深さのみ）：容量が効く |
| D：3000件→1万件で+0.05以上 | −0.021 | 非該当 |

- 2つの基準に該当したので，規則に従い，改善幅の大きい順に組み合わせる．
- 次の標準構成は，**3層（256×256×256）・5000エポック以上**とする．
- 教師データは1万件で足りており，当面拡大する必要はない．

### 7.2．系による違い

- 深さの効果はn3-d222でのみ見られ，n2-d33では見られなかった．
- n2-d33はすでに到達率0.85前後と高く，残りの改善余地が小さい．そのため，構成の違いがseed間のばらつきに埋もれやすい．
- 写像がより複雑なn3-d222で深さが効いたことは，「写像の学びにくさ」が主な課題だというこれまでの見方と整合する．

### 7.3．検証損失と追跡コストの乖離

- 検証損失はほぼ一定なのに，到達率は上がり続けた．EXP-0011（7.4節）で指摘した乖離が，ここでも再確認された．
- この結果から，次の2つが言える．
  - **行動の二乗誤差は，学習の打ち切りやモデル選択の基準として不適切な可能性がある．** 現在は検証損失が最小のエポックを採用しているが，追跡コストが最小のエポックとは一致しない可能性がある．
  - 追跡コストを直接使う微調整（次の段階）が有効である可能性が高い．

### 7.4．改善の伸びの鈍化

- n3-d222の到達率は，0.447（EXP-0011）から0.579（最良構成）まで上がった．
- しかし，エポック数・容量の調整による改善は1回あたり+0.06〜0.07で，伸びは鈍ってきている．
- 教師あり学習の調整だけで，oracleとの残りの差（約4割）を埋めるのは難しいと考える．

### 限界

- seedは3つ，データ量の比較はseed0のみである．
- 学習率の減衰など，最適化の設定は変えていない．
- 構成の効果はn3-d222とn2-d33で異なり，一般性は未確認である．

## 9．結論

- 拡張つき教師あり学習は，エポック数（5000）とネットワークの深さ（3層）を増やすとさらに改善した．n3-d222の到達率は0.579（$\Delta J=-15.0\%$）になった．幅とデータ量の拡大は効かなかった．
- 今後の標準構成は，全次元の行動空間，対称性による拡張，3層（256×256×256），5000エポック以上とする．
- 調整による改善は鈍ってきており，検証損失は追跡コストと連動しない．次は，追跡コストを直接使った微調整と規模拡大に進む．

## 10．次の実験

1. **コストを直接使った微調整**（実装が必要）
   - 本実験の最良構成の方策を初期値に，追跡コストを直接最適化する．候補はPPO，または同じ問題で複数の行動を比べる学習で，全次元の行動空間と対称性による拡張を使う．
   - あわせて，モデル選択を検証用問題での追跡コストで行う仕組みを入れる（7.3節）．
2. **規模拡大**（n3-d333，n4-d2222）
   - まずoracleで改善余地と探索予算への収束を確かめる．そのうえで，標準構成の教師あり学習を行う．
   - 教師データ生成は計算が重いため，1の実装と並行して進める．
