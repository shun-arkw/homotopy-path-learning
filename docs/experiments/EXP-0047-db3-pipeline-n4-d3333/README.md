## 2．目的

- 2026-10-16の報告では，n3-d333で$d_b=3$の方が$d_b=2$より1.4ポイント良く，n2-d33では差がなかった（補足資料S1）．「係数パスの表し方（$d_b$）」は，50%削減に届かない理由の候補の1つである（報告5節）．
- 報告の主な結果（$d_b=2$）を$d_b=3$でもそろえる最初の段階として，n4-d3333で，$d_b=3$の標準の手順（ゼロからの探索の教師データ → attentionの教師あり学習 → 微調整）を行い，$d_b=2$の標準の手順（EXP-0023）と比べる．
- $d_b=3$では探索する次元が2倍（40→80）になる．EXP-0018（n4-d3333，目的系100個）では，予算（目的系1つあたりの追跡の回数）500で$d_b=3$の探索が$d_b=2$より1.5ポイント悪く，予算1000で同等，予算3000で約1ポイント良かった．標準の手順の予算500では，「$d_b=3$の表現力」ではなく「探索の不足」を測ってしまうおそれがある．そこで，予算500と1000の2つの腕を比べる．
- 本実験の結果をもとに，n5（n5-d22222，n5-d33333）に$d_b=3$を広げるか，広げるならどちらの予算を使うかを決める（5節）．

## 3．多項式系

EXP-0023と同じn4-d3333（$n=4$，次数$(3,3,3,3)$，パスの数81）．

- 開始系：$g_i=x_i^3-1$（$i=1,\dots,4$）
- 目的系：$f_i=x_i^3+a_{i,1}x_1+a_{i,2}x_2+a_{i,3}x_3+a_{i,4}x_4+a_{i,5}$（$i=1,\dots,4$）．係数は実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．
- ベジェ次数$d_b=3$（中間制御点2つ）．動かす係数は20個なので，中間制御点1つあたりのずれは実数40次元，全体で80次元である（$d_b=2$では40次元）．
- ずれの範囲の決め方（直交行列$U$，`basis_seed: 0`，全次元）は$d_b=2$と同じで，中間制御点ごとに同じ$U$を使う．

### 4.3．手順（各腕で同じ）

1. **教師データ：** 学習データの1万個を20分割×500個にし，各分割で次を実行する．評価seedは$9000000+500k$（$k=0,\dots,19$）．
   ```text
   oracle.py --config exp-0018-n4-d3333-db3.yaml --latent-dim full --budget {500 または 1000} --n-random 100 --search-seed 0
             --evaluation-seed 9000000+500k --num-instances 500
   ```
   - 探索の中身（付録B）は$d_b=2$と同じ：線形パス1回，一様乱数の点99回，残りを(1+1)-ES（最初の歩幅0.3）．
2. **教師あり学習：** attention（$d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256），対称性による拡張あり，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．GPU．
3. **微調整：** 2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 9600000（200個，50反復ごと），訓練seed 9700000，seedは教師あり学習と同じ0〜2，8ワーカー．
4. **評価：** 教師あり学習後と微調整後の各3つのネットワーク（各腕6つ）を，開発集合で評価する（`evaluate.py`，最後の重み．微調整は検証で最良の反復の重みが`last.pt`に入る）．基準線（EXP-0023の教師あり学習後と微調整後，各3つ）も開発集合で評価する（評価のみ）．
5. **第1段の判断：** 5節の第1段を記録してから，第2段に進む．
6. **試験：** 両腕の12のネットワークを試験集合で評価する（1回だけ）．基準線の試験集合の値は，EXP-0023の既存の評価（`evaluation_test9300000`）を使う．

## 5．判断基準（実行前に固定）

差は「腕の削減率 − 比べる相手の削減率」（ポイント）で，正なら腕の方が良い（`compare_runs.py`が出す$\Delta J$の差の符号を反転したもの）．各比較を次の規則で判定する．

| 判定 | 条件 |
|---|---|
| 良い | 差が+1.0ポイント以上で，95%区間が0を含まない |
| 悪い | 差が−1.0ポイント以下で，95%区間が0を含まない |
| 差なし | それ以外 |

3つの比較はそれぞれ独立に判定し，多重比較の補正はしない（そのことを明記する）．
