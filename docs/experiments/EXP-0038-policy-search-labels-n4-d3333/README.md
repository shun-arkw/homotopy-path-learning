## 2．目的

- EXP-0037（n5）と同じ手順を，n4-d3333に当てる．方策＋探索で教師データを作り直すことが，n5に限らず有効かを確かめる．
- n4-d3333は，第0周の教師データ（ゼロからの探索，予算500）の平均$\Delta J$が$-22.5\%$で，それで学習した微調整後の方策（試験500問題で$-28.6\%$）より悪い．この点はn5と同じである．
- 追跡が軽いので，すべての段階をメインの環境で行う．EXP-0037とは計算資源を共有しない．

## 3．多項式系

EXP-0023と同じ（n4-d3333，$d_b=2$，行動40次元，81パス）．

## 4．方法（事前登録）

用語：第0周の方策は，EXP-0023のattention＋微調整（2000反復）の方策（seed 0〜2）である．

- **教師データの問題：** 第0周と同じ1万問題とする（評価seed 9000000〜9009999）．
- **教師データの作り方：** EXP-0037と同じである．
  - 問題ごとに，第0周の方策 seed $k$の行動を初期値にした探索を，探索seed $k$で行う（$k=0,1,2$）．
  - 各探索は予算100とする（`--n-random 2 --initial-sigma 0.05`）．
  - 問題ごとに，3回の探索のうち最良を教師データとする．
- **教師あり学習：** ネットワークを初期化して，新しい教師データだけで学習する．設定は第0周と同じ（attention，$d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256，対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2，GPU）．
- **微調整：** 第0周と同じ設定・同じ問題とする（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証200問題，検証seed 9600000，訓練seed 9700000）．追跡は1 runあたり8ワーカーで並列に行う（結果はワーカー数によらない）．
- **試験問題：** 第0周と同じ評価seed 9300000〜9300499（500問題）．到達率の分母は，EXP-0023の試験oracle（予算1000，探索seed 0）とし，参考の値とする．
- **比較：** `compare_runs.py`で，第1周と第0周の方策を比べる（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．
- **環境の確認（実行前）：**
  - 第0周の微調整後の方策 seed 0を初期値にした探索（予算2，`--n-random 2`）を，メインの環境で試験問題の先頭20問題に行う．1番目と2番目の評価（線形パスと方策の行動）のコストが，外部サーバでの評価（LinearとLearnedBezier）と問題ごとに完全に一致することを確かめる．
  - 教師データの線形パスのコストが，第0周の教師データの値と問題ごとに一致することを確かめる．

## 5．判断基準（実行前に固定）

- **主基準：** 試験500問題での，微調整後の$\Delta J$の差（第1周−第0周）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → 方策＋探索で教師データを作り直すことは，n4-d3333でも有効．
- **参考：**
  - 教師データの平均$\Delta J$（第0周の教師データの$-22.5\%$と比べる）．
  - 教師あり学習の段階での差（第1周−第0周）．
  - 第1周の微調整後と，EXP-0024の4000反復の微調整後（$-29.4\%$）の差（同じ程度の追加の計算で，どちらが有効か）．
