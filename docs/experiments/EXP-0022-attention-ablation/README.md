## 2．目的

EXP-0020で，attention方策（約80万パラメータ）はMLP（約15万パラメータ）を大きく上回った．この改善が何によるものかを，次の3つの比較で切り分ける．

1. **パラメータ数：** パラメータ数をそろえたMLPでも同じ改善が得られるか．
2. **置換の対称性を構造で満たすこと：** 同じ規模のTransformerで，置換の対称性を構造として持たないもの（系列Transformer）と比べる．
3. **モデルの大きさ：** 小さいattentionでも十分か．推論時間を短くできるかを見る（EXP-0020では，attentionの順伝播で推論が線形パスより48%遅くなった）．

## 3．多項式系

EXP-0020と同じ（n4-d2222，$f_i=x_i^2+\sum_{j=1}^4a_{i,j}x_j+a_{i,5}$，$d_b=2$，行動40次元）．

## 4．方法（事前登録）

### 4.1．比較する方策

| 方策 | 構成 | パラメータ数（actor） | 教師あり学習のエポック |
|---|---|---:|---:|
| MLP（基準，EXP-0017） | 全結合3層，256ユニット | 152,360 | 5000 |

- **系列Transformer：** 係数を決まった順に一列に並べ，位置埋め込みで変数と方程式の番号を区別するTransformerエンコーダーである．置換の対称性は構造として持たない．各層はattentionと同じく2つのattention副層とFFNからなるが，attentionは全トークンにかかる．詳細は`attention_policy.md`の10節．
- 教師データ・拡張・バッチ・学習率（$10^{-3}$）・検証の割合・seed（0〜2）はEXP-0017・EXP-0020と同じ．
- Transformer系は300エポックとする（EXP-0020で最良のエポックが50〜65だったため）．MLP-612は，基準のMLPと同じ5000エポックとする．
- 微調整は全方策で同じ設定（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 8600000，訓練seed 8700000）．

- **C1（パラメータ数）：** attention−MLP-612が$-1.0$ポイント以下で，95%区間が0を含まない → attentionの改善はパラメータ数だけでは説明できない．

- **C3（小さいモデル）：** 小さいattention−attentionの95%区間の上端が$+1.0$ポイント未満 → 小さいattentionで十分である．

## 8．観察

- 試験500問題での，微調整後の$\Delta J$は，attentionが$-24.20\%$，小さいattentionが$-23.35\%$，系列Transformerが$-19.39\%$，MLPが$-14.38\%$，MLP-612が$-13.67\%$だった．
- MLPを約80万パラメータに大きくしても良くならず，むしろわずかに悪化した（MLP比$+0.72$ポイント）．
- 系列Transformerは，教師あり学習の段階ではMLPと同程度だった（到達率0.387と0.402）．一方，微調整後はMLPを$5.0$ポイント上回った．
- attentionは，系列Transformerを，教師あり学習の段階でも微調整後でも上回った（微調整後で$-4.81$ポイント）．
- 小さいattentionは，パラメータが約1/8でも，attentionとの差は$+0.85$ポイントだった．事前登録した基準（区間の上端が$+1.0$未満）は満たさなかった（上端は$+1.46$）．
- 推論時間では，小さいattentionの順伝播（0.77 ms）は，attention（1.46 ms）の約半分だった．全体では線形パスの1.20倍で，まだ線形パスより遅い．追跡の部分（順伝播を除いた時間）は，attention系で線形パスより約13%短かった．

## 9．考察

- **パラメータ数では説明できない（C1）．** MLPは大きくしても良くならない．attentionの改善は，モデルの大きさによるものではない．
- **改善は2つの要素にほぼ半分ずつ分かれる．**
  1. Transformerの構造そのもの（MLP→系列Transformer）：約$-5.0$ポイント．この差は微調整の段階でのみ現れた．
  2. 置換の対称性を構造で満たすこと（系列Transformer→attention，C2）：約$-4.8$ポイント．教師あり学習と微調整の両方の段階で効く．
- 1．がなぜ微調整でだけ効くのかは，まだ分からない．候補は，トークンごとに出力する構造（係数ごとの摂動）が，コストの勾配による更新と相性がよいことである．
- **小さいモデルでも，ほぼ同じ性能が得られる．** 差$+0.85$ポイントは統計的には有意だが，MLPとの差（約10ポイント）に比べれば小さい．推論時間を重視する場合は，小さいattentionが実用上の候補になる．
- **追跡の時間の短縮は，ステップ数の削減の約6割にとどまる．** 1問題あたり約1 msの固定の時間（追跡の呼び出しや制御点の構成）があるためと見積もられる（2点からの粗い見積もり）．このため，追跡の軽いn4-d2222では，順伝播の時間を回収できない．

## 10．結論

- EXP-0020のattention方策の改善は，パラメータ数では説明できない（C1を満たす）．置換の対称性を構造で満たすことが寄与している（C2を満たす）．改善のおよそ半分はTransformerの構造そのもの，残りの半分は置換の対称性による．
- 小さいattentionは，事前登録した基準（C3）を満たさなかったが，差は$+0.85$ポイントと小さい．
