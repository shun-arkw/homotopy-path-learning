## 2．目的

- attention方策は，n3-d222，n3-d333，n4-d2222でMLPを大きく上回った（EXP-0020，EXP-0021）．
- これまで扱った系のうち，残るn2-d33でも比べる．n2-d33はMLPの到達率が既に高い（約0.96，EXP-0013）ので，改善余地の小さい系でも差が出るかを調べる．

## 3．多項式系

**n2-d33**（$n=2$，次数$(3,3)$，$N_{\mathrm{path}}=9$）

- 開始系：$g_i=x_i^3-1$（$i=1,2$）
- 目的系：$f_i=x_i^3+a_{i,1}x_1+a_{i,2}x_2+a_{i,3}$（$i=1,2$）

係数$a_{i,j}$は問題ごとに，実部と虚部をそれぞれ$[-1,1]$の一様分布から生成する．ベジェ次数は$d_b=3$（行動24次元）で，MLPの標準パイプラインと同じである．

## 4．方法（事前登録）

- **MLP（基準，既存）：** EXP-0012の拡張つき教師あり学習（3層256，5000エポック，seed 0〜2）と，EXP-0013の微調整（$\lambda=0$，2000反復，seed 0〜2）．
- **attention（本実験）：**
  - 教師あり学習：MLPと同じ教師データ（EXP-0011，1万件），対称性による拡張，300エポック，バッチ256，学習率$10^{-3}$，検証10%，seed 0〜2．既定の大きさ（$d_{\mathrm{model}}=128$，4ヘッド，4層，FFN 256）．
  - 微調整：MLPと同じ設定（2000反復，$K=32$，$P=4$，$\sigma=0.05$，学習率$10^{-4}$，$\lambda=0$，検証seed 5000000，訓練seed 6000000）．
- **試験問題：** これまで使っていない評価seed 9400000〜9400499の500問題．oracle（全次元，予算$B=1000$）を求め，到達率の分母にする．
- 比較は`compare_runs.py`で行う（3seedの方策のコストを問題ごとに平均し，対応のあるブートストラップ，95%，2000回）．

## 5．判断基準（実行前に固定）

- **主基準：** 微調整後の$\Delta J$の差（attention−MLP，試験500問題）が$-1.0$ポイント以下で，かつ95%区間が0を含まない → n2-d33でもattention方策は有効．
- **副基準：** 教師あり学習の段階の到達率の差（attention−MLP，試験500問題）が+0.05以上．
- 方策がoracleを上回り到達率が1を超えた場合は，$\Delta J$を主な指標として報告する．
